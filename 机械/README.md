# 机械工程文件

本目录保存整车机械 CAD 模型及参数记录。模型名称反映设计用途；具体尺寸、装配约束和可制造性应以 CAD 文件及后续复核为准。

| 文件 | 用途 |
| --- | --- |
| `车.SLDASM` | 整车 SolidWorks 装配模型。 |
| `炮台.SLDASM` | 炮台 SolidWorks 装配模型。 |
| `上轴承保持架.SLDPRT`、`下轴承保持架.SLDPRT` | 上、下轴承保持架零件模型。 |
| `下导轨.SLDPRT` | 下导轨零件模型。 |
| `侧平板.SLDPRT`、`左侧板.SLDPRT`、`右侧板.SLDPRT` | 侧面板件模型。 |
| `零件6.SLDPRT` | 未按用途命名的 SolidWorks 零件；具体作用需结合装配模型确认。 |
| `参数基线.json` | 记录机械、控制和感知参数基线及其来源和限制。 |

`标准件/` 存放标准件与配套零件模型，详见该目录的说明。CAD 文件受 Git LFS 管理；参数基线中的 CAD 质量与质心并非实物测量值。
