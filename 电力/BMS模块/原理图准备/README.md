# BMS 原理图准备

本目录保存BMS当前的原理图设计输入、接口/连接合同、BOM、编程与Layout交接材料。各文件是否为当前采用、候选或历史材料应按文件内容和[模块当前设计状态](../检查/当前设计状态.md)区分；本目录中的连接记录和计算材料不代表PCB、固件或实物验收。

## 直接文件

| [需求与系统边界.md](需求与系统边界.md) | 记录BMS现行需求、系统输入和设计边界。 |

| [功率与预充设计.md](功率与预充设计.md) | 说明9S4P主功率路径、保护与预充的原理设计。 |
