# BMS设计需求

更新：2026-10-29。本文件是BMS唯一现行需求入口；实现、原理连接、参数、计算、采购及未关闭项统一见[设计细节](设计细节.md)。当前没有样板，纸面计算与模型结果不代表实物验收。

| 项目 | 当前要求与边界 |
|---|---|
| 电池 | EVE INR18650-30P，9串5并、45颗、15Ah标称；沿用9S理论22.5–37.8V范围，实际能力按温度、压降与保护确定。 |
| 电芯费用 | 用户报价13元/颗；新增9颗按117元计算。渠道、税费、运费与MOQ未提供。 |
| 放电 | 保留两台电机同时各1.8kW输入峰值能力；空超容时允许限功率慢加速。连续60A沿用工程输入；130A峰值和1s是本轮比较候选，不能作为已经验证的额定。 |
| 净充电 | 电池包最大净充电16A；温度、SOC、单体电压、并联均流及测量/动态误差要求更低时必须降额。5并不自动提高此上界。日常6A仅沿用工程目标。 |
| 超容与稳压 | 独立稳压模块、8颗LICAP SC0350-270-RSS，8S1P。正常0V初充希望几十秒量级；不把超容满充设为车辆启动前提。BMS母线预充不是超容初充。 |
| 制动回生 | 车辆无机械刹车；超容优先承接电制动回生，电池拒绝充电/超容已满时须有规定工况内可用的电耗能路径。回生额度0、关PWM均不能当作停车保证。用户提出按M1A1的1∶10刹车作大致比较；比例推算及工况值由稳压设计细节标明。 |
| 太阳能 | 独立MPPT板接公共母线，太阳能设计输入30W（1W/5V单晶硅拼接）；BMS按净电流统一管理太阳能、回生、超容和负载叠加。 |
| 环境 | 用户确认0–60°C环境，须另外计器件自热、热点及传感器安装误差。 |

## 板级功能

- 一块BMS板、一张原理图；外置G431仅画接口排母。具体实物核心板的厂商、版本、针向、电源及跳线兼容性须核实。
- 保留电芯电压、电流、温度、必要本地保护、启动/母线预充、运行/停放和维护隔离。
- 保留相邻电感主动均衡。现有ETA3000方案是实现候选；不再要求任意远端C1↔C9净转移指标。BQ内置被动细修不能替代用户要求的主动均衡。
- 5V使用用户选定海凌科URB4805YMD-10WR3成品模块，替换自设计5V降压；不混用同名其他厂家参数。
- BMS通过CAN上传温度、有效性、故障与能力；独立冷却板自行判断风扇控制。BMS不设计风扇供电、调速、测速或专用连接器；取消加热。
- CAN承担协调与状态，不承担快速保护。总净充电能力仅分配一次，所有源须有本地闭环并对过期能力作确定处置。
- 日常OFF/STORE与长期维护隔离分开；长期隔离要覆盖主回路、采样和主动均衡的全部电芯取电路径。重新开启须重新检查/预充，不允许因供电恢复或复位自动接通主功率。

## 精简、成本与交付

- 优先精简芯片、功率MOS、电源、光耦、隔离器及其他高价值器件，同时计总数量、焊点、能耗、热与成本。禁止排阻及MA5421-ALD；不靠串并多颗电阻消除单个料号。
- 必要保护按故障场景判断；允许有证据的合并/删除，不把历史实现永久当成不可改要求。替代必须覆盖复位、失电、通信丢失与恢复默认态。
- 全项目共用库统一精确采购MPN；满足要求后优先国产，比较可核验到手价、MOQ、供货和验证成本。CAD载体与实际采购身份分开。
- BMS板内约200元目标保留；当前未证明达标。它不含外置核心板、PCB制造/焊接及板外配套，也不能用稳压已取消的500元预算替代。未知价格不填0。
- 用户于2026-10-29要求每块板仅有一个设计需求文档和一个设计细节文档。所有现行选型、接线、编程/PCB交接约束、计算、审查和成本结论在本模块这两份文档原位更新，不新增第三套设计报告。README只导航；JSON/CSV/原生/厂商原文/冻结模型快照作为附件。
- 原理图之后全部由人类完成：PCB设计与布局、制造交付、打样、装配、固件实现、台架和实车测试。代理负责原理图、选型、接口合同、计算与原理级验证，不能以没有样板为由停止可完成的纸面工作。
- EDA优先官方API；BMS只维护根EPRJ3及其sch配套，不新增其他EDA交付格式。用户此前禁止自行打开界面查看检查明细的要求保持。原理图功能块内优先真实导线，公共电源/跨块可用网名，避免只堆器件和网标。

## 未冻结而影响额定的输入

双机峰值持续时间、最终130A工作点/重复率、45颗包体均流和测温覆盖、主保险与线束短路配合、充电源最大响应延迟及超调仍需明确。M1A1比例参考不自动定义长下坡、失电停车和驻车保持。所有候选能力在原理核准、目标配置写入读回及后续人类验证完成前，不作为整车获准能力发布。
