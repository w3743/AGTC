# BMS 检查与回读

本目录混合保存当前原理图状态摘要、只读回读/核对工具、选型与设计审查材料，以及按轮次生成的证据。当前状态入口为[当前设计状态.md](当前设计状态.md)，并与[模块README](../README.md)、[项目要求](../项目要求.md)和[TODO](../TODO.md)一起使用；日期较早的报告、JSON、图像、原生API输出和重开快照不自动代表当前源状态。

## 当前入口与常规只读工具

| 文件 | 用途与边界 |
|---|---|
| [当前设计状态.md](当前设计状态.md) | 汇总现行EPRJ3/P1、官方网表逐针对比、DRC计数和开放资格项；以其当前状态章节及关联源哈希为准。 |
| [温度保护配置闭合.md](温度保护配置闭合.md) | 汇总温度保护输入、拟合/写入状态及尚未完成的固件和硬件闭合项。 |
| [需求覆盖与待验收.md](需求覆盖与待验收.md) | 将BMS工程需求映射到证据与未闭合事项；文件标注的日期用于判断其时效。 |
| [原理图构建与回读结论.md](原理图构建与回读结论.md) | 记录原理图构建与回读结论；该文件中明确标为历史快照的部分不作为当前状态。 |
| [只读原生回读.py](只读原生回读.py) | 按映射页读取放置器件、引脚/连线、网络端口、NC标记、MPN、BOM/PCB标志和封装UUID；脚本说明其不修改、删除或保存工程。 |
| [只读官方网表核对.py](只读官方网表核对.py) | 只用本地文件，将新鲜官方ENET与BMS构建清单逐项比较；需显式传入本轮导出，不能把旧快照当成新证据。 |
| [汇总本轮验证.py](汇总本轮验证.py) | 读取源文件、交叉核对BOM并绑定本轮证据哈希；运行前应确认输入文件确为当前工程导出。 |
| [复核正式工程重开.py](复核正式工程重开.py) | 通过官方CLI只读重开正式工程；文件注明不导出网表/BOM，且依赖同目录之外的布局辅助脚本。 |

目录中的其它工程构建、原理图修改、Layout交接、记录同步与证据生成脚本大多绑定特定会话、源哈希或历史步骤；应逐个检查其输入和写入路径后再使用，不能视为统一的自动发布命令。模块维护规则规定代理不创建/修改PCB，原理图之后的实施和实物验证由人类完成。
