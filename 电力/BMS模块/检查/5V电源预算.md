# 当前5V与REG1预算

2026-10-16。5V为海凌科URB4805YMD-10WR3，5V/2A、18–75V输入；22.5–37.8V包压在其名义范围内。输入与旁路正端为源端保险下游TAP_B9，不再给风扇供电。

| 负载 | 规划上界 |
|---|---:|
| 外置MCU及3.3V负载 | 100mA |
| CA-IS2062A | 150mA |
| LOAD_POWER_VALID LED | 11mA |
| 接口及增量预留 | 39mA |
| 基础合计 | 300mA |
| 7×510Ω最低负载 | 73mA预算，标称5V约68.6mA |
| 合计 | **373mA，1.865W** |

额定2A的算术余量1.627A不代表实测动态或全温裕量。均衡功率从抽头取电，不计5V；REG1独立供必要关断逻辑。最低负载电阻保留以满足现行模块最小负载输入，散热分布并远离NTC。模块应用页的EMC外围是推荐例，不无条件全加。

源端保险复用PV-5A10F及CHPV1U，先保险后全部细线，16AWG、≥60V；禁止热插拔。[PSU支路报告](PSU支路闭合.md)区分额定电流算术与尚未证明的DC分断、浪涌/I²t及故障配合。输入陶瓷旁路的偏压有效容量、模块启动/恢复/反灌和热/EMC仍待厂家数据或首板验证。

## REG1与REGIN

REG1设置3.3V，不给MCU或风扇供电。BQ厂商规格条件为REGIN≥4.1V、正常负载0–45mA；REG1输出范围3.0–3.6V。当前正常负载按10mA预留，不能将旧30mA含光耦负载预算当成当前实际耗电。

| 支路 | 3.6V规划上界/预留 |
|---|---:|
| 预充NPN基极1k | ≤3.6mA（未扣VBE） |
| 均衡MAIN_CLR_N NPN基极3.3k | ≤1.1mA |
| DFETOFF与LOAD_VALID两路1k栅极串联/100k下拉 | 静态规划≤0.073mA，按UMW AO3400A两颗各100nA栅漏电作25°C纸面估算 |
| DFETOFF 47k及PRE_CTRL一只100k | ≤0.113mA |
| LVC逻辑、POR、TPL及漏电/动态增量余量 | 约5.077mA规划（含MOS切换充电电流余量） |
| **正常合计规划** | **10mA** |

供电电阻现统一1kΩ±1%/2W。10mA下耗散约0.101W；22.5V输入、二极管压降1V、1010Ω时集电极11.4V，距5.8V规划要求有5.6V余量。37.8V/990Ω的静态串联模型给出FCX495最大耗散0.361W、电阻短路上界1.444W；考虑0～60°C的±200ppm/°C温漂，分别约0.364W/1.454W。厂商70°C前2W额定以规定安装条件为前提。故障时供电支路不会保持正常10mA/REG1电压，不能用这些解析值替代实际启动、短路和热确认。详见[1k2W电阻选型合并](1k2W电阻选型合并.md)。

来源：[BQ76952原厂手册](https://www.ti.com/lit/ds/symlink/bq76952.pdf)。REG1预算不证明主MOS关断时间、失电默认态或全板短路安全。
