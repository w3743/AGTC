# BMS 接口布局前核对

状态：纸面接口核对；不是器件实物验收，也不证明 EasyEDA 原理图已同步本轮改动。

## 本地启动与 CAN 边界

- 手动开关置 ON 后，BMS 由电芯供电，自行启动 MCU、完成本地自检和预充，再建立主输出并给上位机/FOC 供电。启动、预充、输出维持和本地故障恢复均不等待 CAN/上位机 ARM 或授权。
- CAN 用于能力/状态遥测及可选限值、管理请求。CAN 超时只影响这些请求的新鲜度与诊断，不改变 `BMS_LOCAL_OK`、不终止预充、不断开 BUS 或上位机供电，也不要求远端重新授权。
- MCU 用有效高 `BMS_LOCAL_OK` 表示本地 BMS 输出路径许可；该信号参与 `PRE_REQ` 硬件联锁、预充锁存复位和 `FET_RELEASE`。它由本地状态机控制，不是电机扭矩或 FOC 运行许可。
- 上位机/FOC 由 BMS 主输出供电；`VOUT_5V` 仅按接口设计为板载负载预算，不作为上位机辅助电源。

## ON/OFF 开关引脚

接口 JSON 的 `SW_RUN_STORE` 使用 NKK `MN22SS1G01`（金触点 DPDT、维持式 ON-ON）。接口符号和端子映射按该六端 DPDT 器件定义：

| 开关端子 | 网络 | 接点说明 |
|---|---|---|
| 2 | `SW_RUN` | 第一刀公共端 |
| 3 | `REG1` | 第一刀 ON 档；ON 档与 2 闭合 |
| 1 | `null` / NC | 第一刀另一档；与 2 闭合时不接外部网络 |
| 5 | `PRE_CTRL_3V3` | 第二刀公共端 |
| 6 | `REG1` | 第二刀 ON 档；ON 档与 5 闭合 |
| 4 | `null` / NC | 第二刀另一档；与 5 闭合时不接外部网络 |

面板 ON 档对应 `2–3`、`5–6` 闭合；另一档对应 `2–1`、`5–4`。两个刀路只切换 BQ `REG1` 低压信号，禁止把 CELL_B9、TAP_B1…TAP_B9、电池主电流或其它高压引到开关。按实物铭牌/端子图确定面板方向并标明 ON/OFF。

原厂资料： [NKK M2022SS1G01 产品页（列出 MN22SS1G01 推荐替代）](https://www.nkkswitches.com/wp-content/themes/impress-blank/search/inc/part.php?part_no=M2022SS1G01)；[NKK Toggle Sections DP 端子图](https://www.nkkswitches.com/pdf/MN_ToggleSections_DP.pdf)。该系列额定 0.4 VA、最高 28 V；在本接口中只作低压控制开关。型号与端子图已有纸面来源，实际采购与装配方向尚未验收。

## MCU 信号脚保持不变

本轮不移动现有 WeAct 核心板接口：`PB4/P1-19=BMS_LOCAL_OK`，`PB6/P1-21=PRE_REQ`，`PB7/P1-22=PRE_READY`；`BAL_RUN` 的既有分配也保持不变。开关端子号更新不改变 MCU 管脚。同步原理图时，逐一核对六个物理端子、符号引脚编号和表中网络的对应关系，并清除不属于该六端器件的遗留符号连接。
