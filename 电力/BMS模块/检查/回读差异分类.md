## 旧快照中的 450 项 footprint 差异

### 旧快照：429 项本地 UUID 差异

这 429 项实际与期望的 footprint 名称相同，且 `libraryUuid` 相同；实际对象的封装 UUID 是本地 16 位十六进制值，期望公共库对象是 32 位 UUID。这与项目内复制封装后重新分配本地 UUID 的表现一致。应从“封装对象身份差异”分类，不能单凭 UUID 不同推断焊盘、电气连接或封装尺寸错误。

只读检查 `.eprj2` 时，`documents`、`components`、`devices`、`schematics` 表当前为空，但项目并非空工程：`project_structures` 有 243 条记录、`history_data` 有 393 条、项目历史表有 63 条、`project_images` 有 38 条。结构表保存了页面/工程结构；历史数据字段呈不透明的编码内容。本次只读 SQL 没有写库，也未能从数据库中解出当前本地 footprint 的逐焊盘几何或 `Footprint` 属性对象。因此，本节不能证明 429 个本地封装几何与公共库几何完全相同；若需确认几何，应从 EasyEDA 官方 API 读出封装焊盘编号、中心、尺寸和钻孔，与原厂推荐 land pattern 比较。
