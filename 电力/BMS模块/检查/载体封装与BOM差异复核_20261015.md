# BMS 载体封装与 BOM 差异复核

日期：2026-10-15  
范围：区分 CAD carrier 的焊盘几何是否妨碍人工预布局，与 carrier/BOM 型号差异造成的电气签核问题。不是 ERC、DRC、热仿真或实物验收。

## 结论

三个 carrier 的封装几何与 BOM 目标料号相容，**不构成其他器件开始预布局的共同阻断项**。`L_PSU` 现有封装的中心距不符合原厂建议 land pattern，**只阻止该电感按当前封装落位**。三个 carrier 的值/型号差异仍须在原理图和 BOM 冻结前纠正；几何相容不代表电气等效，也不代表可互换采购。

| `R_PSU_FB_TOP` | `RT0603BRD0795K3L`，95.3 kΩ ±0.1% / carrier 源值30.1 kΩ | 目标与载体均为0603，两焊盘几何兼容 | 将真实阻值纳入反馈计算。按当前电源预算，95.3 kΩ上拉与30.1 kΩ下拉给出约4.942–5.057 V；若上下拉都为30.1 kΩ，输出约2.4 V，5 V与后续光耦电流预算不成立。见[5 V电源预算](5V电源预算.md)。 |

## `L_PSU` 封装修正

只读 API 回读的当前焊盘中心距为11.999976 mm，即中心位于约±5.999988 mm；原厂建议中心距为11.25 mm，即中心位于±5.625 mm。应将每个焊盘向内移动约0.374988 mm，同时保留焊盘尺寸、编号、层、方向和网络映射。

项目 `easyeda-api-skill` 将相关 `LIB_Footprint` 写入方法标为 BETA；本轮没有使用这些方法修改正式工程。EasyEDA 官方提供 GUI footprint/Project Library 工作流，可在项目库编辑本地副本并更新项目中的封装：[新建 Footprint](https://prodocs.easyeda.com/en/footprint/file-new-footprint/)、[Project Library](https://prodocs.easyeda.com/en/pcb/side-panel-bottom-project-library/)、[Update Project Library](https://prodocs.easyeda.com/en/schematic/design-update-project-library/)、[Footprint Manager](https://prodocs.easyeda.com/en/schematic/tools-footprint-manager/)。应使用项目库，不改共享系统库；保存后关闭并重开工程，再核对焊盘中心距、编号、尺寸与网络映射。API只读记录见[L_PSU封装回读](L_PSU封装官方API只读回读_20261015.json)。

本地 API 文档依据：[LIB_Footprint](../../.agents/skills/easyeda-api-skill/references/classes/LIB_Footprint.md)、[SCH_PrimitiveComponent](../../.agents/skills/easyeda-api-skill/references/classes/SCH_PrimitiveComponent.md)。`SCH_PrimitiveComponent.modify()`没有可用的库绑定替换字段；隔离副本上的普通属性保存/重开测试不等于 Device/footprint 换绑已经验证。此前试验见[EasyEDA器件替换持久化试验](EasyEDA器件替换持久化试验_20261015.md)。

## 本次布局边界

- 人工可以先布局已核对封装的其他元件；在修正并重开验证前，暂不落位 `L_PSU`。
- 三处 carrier 的值/型号校正须在器件冻结前完成，不能因封装兼容而直接照搬 carrier 参数或采购型号。
- 正式 EPRJ3、P1和PCB本轮均未修改或创建；官方网表一致仅证明CAD网络映射。浪涌、风扇电流、板级温升、当前ERC及整机保护仍未签核。
