# 共享电感功率级设计审查

日期：2026-10-13  
范围：只读核对现行共享电感功率级与控制保护连接、低压边界、器件选型及TI LM51772 Rev.D、Diodes SMBJ系列、Bourns SRP1265A、Panasonic EEE-FK1V470P原厂资料。此文记录设计计算和布局约束，不是仿真、测试或实物验收。

## 结论

**可按当前原理图开始原型PCB布局。** 在均衡窗口15–40°C、电芯输入不低于3.0V、独立12V BIAS及本地保护电源正常的范围内，当前连接已有关闭开关后的双向体二极管续流路径；输入、输出两侧也各有精确选定的本地储能电容。按最坏峰值门限、最大电感和额外2倍储能预算，所选每侧电容最低有效值37.6µF可将理想电压升幅限制在预算内，未发现必须再加耗能电阻、额外钳位器或等样机后才能布局的硬件缺项。

布局前应保持本报告确认的器件、极性、连接和小信号可返修空间。样机必须确认真实ESR/ESL、开关尖峰、环路稳定性、预偏置启动及硬停止时序；这些是布局后的验证/调参，不构成当前布局阻塞。2.5V电芯终止点不纳入本结论。

## 原理图与器件核对

- `D_BAL_TVS1`：Diodes `SMBJ12CA-13-F`双向TVS跨`L_BAL_PWR1`两端（`BAL_L1_A`—`BAL_SW2`）。精确SMBJ系列表列`VRWM=12V`、`VBR=13.3–15.3V`、`VC=19.9V @ 30.2A`。现行最高正常电感差分6.459V低于12V工作反向电压；原先6V档不满足该条件。TVS是剩余差分过冲的第二级钳位，不把19.9V当作5.7A时的保证钳位值，也不把整个电感储能都记作TVS耗散。
- `C_BAL_IN_BULK`：Panasonic `EEE-FK1V470P`，47µF、35V、±20%，pin 1正接`BAL_P`，pin 2负接`BAL_N`。`C_BAL_OUT_BULK`同型号、极性，pin 1接`BAL_VOUT_PWR`，pin 2接`BAL_N`。每侧容差下限为`47µF×0.8=37.6µF`，与现有10µF/25V X7R MLCC并联。MLCC作高频旁路，不能按标称10µF全额计入能量预算；外接约5F缓冲器位于平均电流分流器/Hall之后，也不计作本地快速续流电容。
- `Q_BAL_PWR1..4`关断时体二极管方向与本地电容构成两条闭合续流回路，见下节。`U_BAL_OC_CMP`（TLV1704）与`U_BAL_OC_LATCH`（SN74HCT74）由Hall测得的双向电流触发独立约±2.4185A硬停止：锁存撤销转换器`BAL_EN`，保持当时的`BAL_OE`矩阵选择，先停PWM再等待电流归零；不要求新增能量器件。若其他系统级故障同时要求打开矩阵，仍应保留本地功率轨电容，并在实物中确认开断前后路径和`BAL_P/BAL_N`状态。
- 反馈低档支路`R_BAL_FB_EXTRA=2.7MΩ±1%`已并在523kΩ上臂，与100kΩ下臂形成标称5.381322V低目标；这是本轮满足ISNS共模静态余量的最小已选更改，无需再增大或增添反馈器件。
- `C_BAL_ILIMCOMP1=0603B684K160CT`，680nF、16V X7R、0603，pin 1接`U_BAL_CTRL1` pin 16 `ILIMCOMP`，pin 2接`BAL_N`。保留此已选电容及可焊接调容空间，不增加未由应用连接支持的RC电阻网络。

## 硬停止后的电感能量路径与预算

两侧功率电容均在变换器本地功率轨：正电感电流`SW1 → R_BAL_CS1 → L_BAL_PWR1 → SW2`在四管关断后经`Q_BAL_PWR3`体二极管（`SW2→VOUT_PWR`）和`Q_BAL_PWR2`体二极管（`BAL_N→SW1`）续流，能量进入`C_BAL_OUT_BULK`及并联MLCC。反向电感电流经`Q_BAL_PWR1`体二极管（`SW1→BAL_P`）和`Q_BAL_PWR4`体二极管（`BAL_N→SW2`）续流，能量进入`C_BAL_IN_BULK`及并联MLCC。电容电压上升、绕组电阻、体二极管和电容ESR共同承接能量；这里是本地闭合换流/储能路径，不是假设把能量全部烧在TVS上。

按TI LM51772 Rev.D正向峰值门限上限55mV、负向门限最大幅值56mV、`R_BAL_CS1=10mΩ±1%`下限9.9mΩ，取更坏的负向门限作保守理想峰值估算：

- `Ipk,threshold = 56mV / 9.9mΩ = 5.657A`。这是检测门限换算，不含比较器/驱动传播延迟、消隐、寄生电感及开关尖峰，因此不是实物保证峰值。
- `Lmax = 22µH×1.20 = 26.4µH`；`E_L = ½×Lmax×Ipk² ≈ 0.422mJ`。该电流低于所选Bourns SRP1265A-220M的12A饱和规格，但延迟过冲、RMS/温升仍需实物核对。
- 另按工程裕度取2倍能量预算`Ebudget=0.845mJ`，不是厂商承诺的故障上限。每侧本地电容按最小37.6µF独立吸收该预算，并用最高静态反馈角落6.459V作保守起点：`Vend=√(6.459²+2×0.845mJ/37.6µF)≈9.31V`。这是理想电容能量换算，没包括ESL/布线尖峰，也不代替TVS和器件耐压核查。
- 若本地有效电容只有5µF，同一预算理想升至约19.5V，故“仅靠5µF”余量不足；当前两只47µF/35V精确选型使每侧容差下限达到37.6µF，不需要再添加能量器件。Panasonic规格中的纹波电流额定值不等于可长期承受5.66A脉冲；布局须让bulk承担局部能量、MLCC承担高频，首板测ESR/ESL、脉冲分担与温升。

## COMP、ILIMCOMP与FB余量

`U_BAL_CTRL1`为LM51772RHAR。现行`R_BAL_COMP1=1MΩ`（pin 13 COMP至RC节点）、`C_BAL_COMP1=3.3µF`（RC节点至BAL_N）、`C_BAL_COMP_HF1=1nF C0G`（COMP至BAL_N）可作为首版布局初值。按TI Rev.D §7.3.8.3方程，在3.0V输入、6.23V目标、3A、22µH、5F理想输出、10mΩ峰值取样的估算点，boost占空比约0.518，RHP零点约3.49kHz，带宽约14.8Hz，低于`fRHPZ/3≈1.16kHz`；该数值支持先布板，不证明真实5F缓冲器、ESR/ESL、buck方向或全负载稳定。`C_BAL_COMP1`须按有效偏压容量理解，并保留调容可达性。

`C_BAL_ILIMCOMP1`的680nF可作为当前首板初值，但不能标作已由TI公式验证的5F电容负载稳定值。TI Rev.D §7.3.12.2给出的简单积分补偿先按电阻负载及电压环带宽、取样电阻前后电容量推导；对电子CC/CR负载，TI指出可能需要Type-II网络。当前用6.23V/3A折为2.08Ω只作数量级参考，真实超级电容与方向切换并非该电阻负载。故原理图保留现有0603电容与可返修位，首板带真实buffer测量后再决定是否改值；现在不加无依据电阻。

`C_BAL_COMP_HF1`的1MΩ与1nF简化RC极点为`1/(2πRC)`≈159Hz（计入3.3µF支路后仍约159Hz）。旧约107Hz备注已在当前连接源、原生设计备注和导出工程中更正，电容值不变；这是算术备注更正，不代表环路已验收。

`R_BAL_FB_EXTRA=2.7MΩ`低档支路下，现有相关静态角落计算为：低目标5.178920–5.584696V，满档6.001615–6.459096V。TI Rev.D表5-5中`ILIM_THRESHOLD=0x64`的48–52mV精度条件要求两只ISNS脚≥5V且结温−10至70°C；按较低ISNS脚取低档最差5.178920V减52mV，得5.126920V，静态高于5V条件约126.9mV。该余量不覆盖动态纹波/瞬态和全部误差，且不把TI正向平均限流精度外推到负向；负向硬停止仍由独立Hall比较器负责。15–40°C窗口落在该表温度范围内。

## 布局约束与首板项目

布局时按TI Rev.D §9.9将输入、输出陶瓷/电解分别贴近相应半桥及低侧MOSFET回流，缩小两组开关高电流环；bulk与MLCC并联，避免长线/细颈分隔。四管门极和自举回路短且紧凑。`R_BAL_CS1` pin 1/2到`U_BAL_CTRL1` CSA pin 22、CSB pin 21作独立差分Kelvin；FB pin 14、COMP pin 13、ILIMCOMP pin 16及其回流远离SW1 pin 23、SW2 pin 33、HO/LO/HB，按安静模拟地回流。跨L的`D_BAL_TVS1`靠近电感两端布置，使其差分回路短。

布局后按实际板和5F缓冲器逐项验收：

1. 在输入≥3.0V、12V BIAS与保护电源有效条件下，EN保持关闭完成配置/复位，再分别以输出无预偏置及已预偏置状态启动；检查`VOUT_PWR`、`BAL_BUF_P`、`SW1/SW2`及电感电流。TI §7.3.7.2的“pre-bias”描述的是VCC2内部LDO低电流启动模式，不是对功率输出预偏置启动的承诺。
2. 真实buffer下分别测boost/充电、反向buck/放电及两反馈档位的COMP环路、ILIMCOMP平均限流、纹波和动态；按波形调换680nF及电压环电容，不以设计计算代替稳定性判据。
3. 触发独立Hall硬停止，确认PWM关断、选择矩阵在电流归零前保持、体二极管续流方向符合`Q2+Q3`/`Q4+Q1`，测每侧47µF本地轨、L两端TVS及MOSFET尖峰。随后才允许解除矩阵选择/重新使能；记录硬停止到零流的实测时间。
4. 测电解ESR/ESL、MLCC高频分流、局部峰值与温升、TVS脉冲和重复故障行为；按真实封装、极性和焊盘再做最终布局核验。
