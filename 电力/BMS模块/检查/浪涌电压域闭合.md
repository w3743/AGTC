# BMS 浪涌电压域核对

日期：2026-10-15。结论：**网络域核对 PASS；浪涌能力未闭合，不能投板放行。** 本轮只读检查当前官方网表，不修改原生工程。详见配套 JSON 的源文件 SHA256 和逐针证据。

## 真实连接与判据

| 电压域/对象 | 当前连接 | 本轮判断 |
|---|---|---|
| 输出 TVS | D_TVS 跨 PACK+ / PACK− | 只钳位输出差模电压；不是 CELL_B9 / B0 的独立钳位 |
| 5V 电源 | U_PSU VIN(2)=CELL_B9，GND(1)/EP(9)=B0；输入三颗电容同域 | 必须单独核查电池端热插拔/线束振铃。输出 TVS 不能证明该域受保护 |
| BQ 电源 | CELL_B9→D_BAT→R_BAT→BAT，U1 VSS=B0 | 二极管和100Ω不是已证明的浪涌钳位；需测 BAT、VC16 相对 B0 的峰值及相邻 VC 差分 |
| BQ 输出检测 | PACK+→各5.1kΩ→BQ_PACK/BQ_LD，U1 PACK(42)/LD(41) | 电阻限流不等于把引脚电压限制在额定内；应测 IC 端电压 |
| 功率 FET | 充电组源=BATT+_FUSED，放电组源=PACK+，共漏=FET_MID | 分别测每组 VDS/VGS；总线对地峰值不足以证明单管安全 |
| 地参考 | RSHUNT 跨 B0 / PACK− | 需计入分流器压降及寄生电感，PACK−不等于瞬态理想 B0 |

SCT2A26STER 原厂规定 VIN 绝对最大110V、推荐输入最高100V；BQ76952 的 BAT/PACK/LD 绝对最大为 VSS+85V，正常 BAT 最高80V。开启电荷泵时还须降低允许的BAT上限，以同时满足CP1/CHG/DSG的电压限制，不能只检查BAT。绝对最大值不是允许反复工作的目标。[SCT手册，第2页](https://www.silicontent.com/uploads/20250604/31b34e8344440b8ab90865778ff55ab0.pdf)，[TI手册，第7–9页](https://www.ti.com/lit/ds/symlink/bq76952.pdf)。

既有只读审查记录 SMCJ45A 的72.7V钳位是在20.6A、规定脉冲和温度条件下；本轮未重新取得原厂表格，沿用值仅供设计压力检查。[Littelfuse原厂SMCJ表](https://www.littelfuse.com/assetdocs/littelfuse_tvs_diode_smcj_datasheet?assetguid=37388813-0d6d-4329-969b-1aa8b7614ac1)供冻结时核查具体型号和10/1000µs条件。即使暂按72.7V计算，85−72.7=12.3V也只是静态数值差，未计地弹、布线过冲、钳位温漂及脉冲条件，不能判 BQ 端口 PASS。TVS 的1500W脉冲标称也不是母线60mF的能量吸收额定。

## 最小复杂度的后续闭合

保留现有 TVS 候选，先把源阻抗、线束电感、母线最大工作电压、外部充电/回馈来源及故障切断时间列为试验输入；没有这些输入，不以增大 TVS 功率或降低击穿电压代替系统闭合。外部回馈由本地 DC/DC/FOC 处理，不能把 BMS TVS 当持续制动耗能器。

在限流电源和受控能量下按正常启动、预充失败/超时、主 FET 关断、输出热插拔、外部充电/回馈分别测量：PACK+−PACK−、CELL_B9−B0、BAT−B0、BQ_PACK/LD−B0、FET 各 VDS/VGS、B0−PACK−。记录峰值、持续时间、脉冲电流、器件温度及实际关断状态。负向瞬态及 VC 引脚差分限制同样检查；不可只对正向绝对最大值打勾。
