# 水泵驱动模块

驱动一台21 V、运行最大约3 A的有刷水泵，从公共9S动力母线取电，单向PWM调速、电制动，CAN控制并回报电流、母线电压、板温和故障。不含阀门驱动。

## 图纸连接约定

网络端口按标准 `IN`、`OUT`、`BI` 类型放置：`IN`/`OUT` 表示相对所连接器件的输入/输出方向，双向或不适合单向定义的供电网络使用 `BI`。`GND_SYS` 使用 GND 符号/标志表示公共参考地。器件附近的局部连接优先直接画线；跨功能区的连接使用同名网络端口连接，端口名称相同表示同网。具体引脚到网络的对应关系以[原理图连接契约](原理图准备/原理图连接契约.json)和 ENET 逐脚核对为准。

本轮 BOM 共37行、58个标号，其中49个板内器件，其余9个为核心板、线束及外置保险。当前 ENET 对照 BOM 和连接契约的49器件、197引脚逐脚核对通过（PASS）。当前原生 DRC API 汇总为 `warn=24`，但逐项明细尚未取得，DRC 尚未闭环；不得沿用源版本不匹配的历史明细作为本轮结论。证据范围及状态以[当前状态](检查/当前状态.md)为准。原理图设计和网表核对不代表 PCB 或实物验收通过。后续在本目录原位更新，不新增修订版目录。

实际水泵制造商/型号及PWM峰值、启动/堵转和制动数据尚未取得，真实负载运行资格保持关闭；状态模型仅定义期望状态，不构成泵兼容性或停机性能验证。
