# 水泵驱动模块

驱动一台21 V、运行最大约3 A的有刷水泵，从公共9S动力母线取电，单向PWM调速、电制动，CAN控制并回报电流、母线电压、板温和故障。不含阀门驱动。

**当前分工与成本原则（2026-10-22）：**代理负责原理图、器件选型、接口合同、计算和原理级验证；原理图交接后的PCB、制造、打样、装配、固件、台架与整车测试由人类完成。全电力系统以最少选型、最低总成本取得最好性价比；本模块列出的型号和BOM不表示已采购，实际泵和当前报价仍需核验。

## 图纸连接约定

网络端口按标准 `IN`、`OUT`、`BI` 类型放置：`IN`/`OUT` 表示相对所连接器件的输入/输出方向，双向或不适合单向定义的供电网络使用 `BI`。`GND_SYS` 使用 GND 符号/标志表示公共参考地。器件附近的局部连接优先直接画线；跨功能区的连接使用同名网络端口连接，端口名称相同表示同网。具体引脚到网络的对应关系以[原理图连接契约](原理图准备/原理图连接契约.json)和 ENET 逐脚核对为准。
