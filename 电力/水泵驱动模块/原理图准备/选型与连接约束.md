# 水泵驱动主选与连接约束

本轮器件选型已用于原生原理图设计。更新：2026-10-21。当前检查状态见[当前状态](../检查/当前状态.md)：ENET逐脚核对49器件/197引脚通过；PCB和实物验收仍未完成。需求见[项目要求](../项目要求.md)，单模块用量见[BOM](BOM.csv)。实际水泵型号及电气参数未取得，故下述运行逻辑是参考契约，真实负载运行资格保持关闭。

## 主选方案

公共BUS经支路保险后供给DRV8262；DRV8262的两组H桥并联为一组，驱动一台水泵。控制电源从同一BUS经XL7015降至5 V，再由WeAct核心板得到3.3 V。MCU使用板载FDCAN控制器连接独立CAN收发器。

## 运行与制动

PWM设计初值20 kHz。定义驱动占空比D为正向加压时间比例，输入快慢命令u=0…1：

`D = u × min(0.95, 21 / VBUS)`。

因此满速命令在22.5 V母线时约93.33%，37.8 V时约55.56%。理想平均驱动电压受21 V命令限制，但电机端PWM峰值仍为22.5–37.8 V；平均值不能证明泵绕组/内部电子器件允许该峰值及20 kHz波形。无需增加额外63 W级21 V降压功率级；真实泵PWM兼容性确认前不得按满母线运行。

若按21 V、3 A设计点，泵端平均功率约63 W；忽略驱动损耗时，对应母线平均电流约2.80 A（22.5 V）至1.67 A（37.8 V）。这是功率换算，不替代启动/堵转电流和支路保险配合校核。

| 状态 | nSLEEP | IN1 | IN2 | 输出与用途 |
|---|---|---|---|---|
| 上电/复位/掉电默认 | 0 | 0 | 0 | 三个10 kΩ下拉使输出高阻滑行；不是主动制动 |
| 单向调速 | 1 | 1 | 反相PWM | IN2=0正向驱动，IN2=1高侧慢衰减 |
| 电制动 | 1 | 1 | 1 | 两输出同接高侧，短接电机端子制动 |
| MCU运行时主动滑行（当前策略不用于正常停机） | 1 | 0 | 0 | 两输出高阻；不同于复位默认休眠 |

参考控制契约：不开放反转。只有CAN使能、母线处于候选窗口且IPROPI诊断正常时才允许单向驱动。CAN心跳超时或有效停止命令转入`IN1=IN2=1`制动；CAN恢复不会自行恢复旧速度。只有健康电流读数低于实泵确认的`I_brake_done`并持续`T_brake_done`才拉低nSLEEP转入休眠。`u=0`是100%高侧短接制动，不代表0电流；PWM关断区本身也可能有绕组续流。IPROPI开路、短路、饱和/ADC异常、nFAULT或BUS越界时锁存故障并拉低nSLEEP，进入高阻滑行；传感器故障时不得把读数当作零电流。该故障策略不保证泵已停或BUS再生过压安全，且需要实泵数据验证是否满足机械停机要求。

名义斩波点`1.65 V/(1.5 kΩ×212 µA/A)=5.19 A`只是典型候选设定值，不是保证上限；DRV8262的运行斩波也不等同于高侧短接制动电流限制。模型不使用5.19 A作制动阈值。与该策略对应的可运行参考状态机及测试见[泵控制参考状态机](../检查/泵控制参考状态机.py)，测试中的制动电流和持续时间只为状态转换夹具值。

实际泵运行放行至少需要：精确厂家/型号及数据表；允许的母线/端子PWM峰值、频率和占空比；冷态/热态绕组电阻或堵转电流、启动波形；允许的短接制动电流/时间或电机制动条件；目标停止时间及连续制动周期。未知参数不由`5.19 A`、DRV OCP额定值或9S理论母线推定。

### 核心板引脚与启动约束

核心板采用WeAct Normal QFN48版，模块插座按核心板P1/P2逐脚同号连接。信号分配为：PA8接DRV_IN2_PWM（TIM1_CH1、AF6，固件生成反相占空比）；PB5接DRV_IN1；PB7接DRV_nSLEEP；PC10接CAN_STB；PC11接DRV_nFAULT；PB8接FDCAN_RX（AF9）；PB9接FDCAN_TX（AF9）；PA0采样电流，PA1采样母线电压，PA2采样NTC。完整针号及启动条件见[MCU引脚核对](../检查/MCU引脚核对.json)。

PB8同时复用BOOT0。固件烧录和启动配置必须设置并读回nSWBOOT0=0、nBOOT0=1，再进行独立上电和复位启动验证；这项配置与验证尚不能由引脚资料核对代替。

上电约束：5 V稳定后先保持`nSLEEP=0`并将IN1/IN2置低，完成时钟、ADC/电流与BUS量程、nFAULT和CAN初始化；PB8启动选项需按上文核实。只有收到新鲜CAN心跳及显式使能、且候选BUS范围和电流诊断有效后，才允许释放休眠进入驱动。复位、棕断或看门狗重启均回到硬件下拉定义的高阻滑行，启动后不得恢复旧速度命令。

## DRV8262预期连接

以下物理引脚仅针对**DDW底散热44脚**，不能套用到DDV。按Rev.C §4、§6.4–6.5和§7核对：

| 网络/配置 | 预期连接 |
|---|---|
| VM | 2、11、12、21接保险后的BUS_M；在两侧VM/PGND附近各放10 nF/250 V陶瓷（规格要求≥100 V），紧邻bulk |
| MOTOR_A | 4、5、6与17、18、19合并，接水泵端A |
| MOTOR_B | 7、8、9与14、15、16合并，接水泵端B；水泵两根线均接驱动输出 |
| PGND/GND | 3、10、13、20及22、23接GND_SYS；散热焊盘EP45接GND_SYS，并按原厂要求连接地铜及过孔 |
| 模式 | MODE1(28)与MODE2(29)明确接DVDD，选择single H-bridge + PWM；模式在使能时锁存 |
| 电流采样 | IPROPI 30、31合并，仅接**一个1.5 kΩ/1%**到GND_SYS；ADC支路经1 kΩ+10 nF低通，滤波不得放在比较器反馈主节点上 |
| 运行斩波阈值 | VREF 33、34合并；由核心板3V3经10 kΩ/10 kΩ分压得到名义1.65 V，节点加100 nF；不使用5 V一分为二冒充1.65 V |
| 故障策略 | OCPM(27)接GND，选择锁存故障；TOFF(35)接DVDD，初值16 µs；DECAY(37)接GND，慢衰减 |
| 控制 | IN1(41)、IN2(40)由MCU GPIO/定时器控制，并各加10 kΩ下拉；nSLEEP(42)由GPIO控制并加10 kΩ下拉 |
| nFAULT | 26接MCU输入，10 kΩ上拉到3V3；上报统一驱动器故障，不能仅凭该脚区分所有内部故障原因 |
| 电荷泵 | VCP(1)至VM接1 µF/16 V X7R；CPH(44)至CPL(43)接100 nF/100 V X7R |
| 逻辑电源 | VCC(25)接5 V并100 nF去耦；DVDD(24)仅按内部LDO输出处理，接1 µF/16 V去耦，不与5 V或核心板3V3短接 |
| 保留脚 | 32、36、38、39均悬空，不接任何网络；EP45接GND_SYS |

IPROPI镜像系数典型212 µA/A针对合并后的电机总电流；并桥分流后再合并镜像，不能把总增益错误翻倍。3 A对应0.954 V，名义斩波阈值为`1.65/(1500×212e-6)=5.19 A`。实际阈值受器件和阻容误差影响，不是保证不超过5 A的硬门槛。原厂[单桥限流答复](https://e2e.ti.com/support/motor-drivers-group/motor-drivers/f/motor-drivers-forum/1336342/drv8262-current-regulation-in-single-h-bridge-mode)中的两个电阻并联例，不应误认为镜像系数翻倍。

## 其他接口与外围

- BUS接口pin1=BUS+、pin2=GND_SYS；正极先通过外置[Littelfuse 0997005.WXN](https://www.littelfuse.com/assetdocs/littelfuse-datasheet-997-mini58v?assetguid=838cc4ad-f429-4185-a8e8-ccc70cd2b713) 5 A/58 VDC保险进入本板BUS_M。保险座为[0FHM0001ZXJ-RED](https://www.littelfuse.com/assetdocs/littelfuse-fuse-holder-mini-fhm-datasheet.pdf?assetguid=339fa35e-eabc-45c5-9093-8abceaa8a2cf)，明确选58 VDC版本，保险5 A为工程初值。SMCJ40A阴极接BUS_M、阳极接GND_SYS，靠近入口。
- MOTOR接口pin1=MOTOR_A、pin2=MOTOR_B。板端[2EDGVC](https://www.degson.com/content/details_552_882057.html?lang=en)和线端[2EDGK](https://www.degson.com/content/details_552_883287.html?lang=en)采用同系列2P/5.08 mm；原厂系列额定覆盖本设计，但官网系列页未逐字给出库内完整长后缀，采购须按BOM后缀确认。BUS与MOTOR是相同型式插头，装配时用明确标识、位置及线束管理防止互插；电机端子不得当作固定GND。
- 母线bulk采用[Nichicon UHW2A471MHD](https://www.nichicon.com/en-us/part/uhw2a471mhd/6256/)，470 µF/100 V、105 °C、12.5×40 mm。3 A恒定电流近似下，输入电容PWM纹波为`I×sqrt(D×(1−D))`，最大约1.5 Arms；原厂高频纹波额定2.860 Arms，布局阶段按实际频率、温度修正和走线再核对。100 V耐压与选定TVS的脉冲钳位值相容。
- XL7015参考[原厂5 V应用Fig.10](https://www.xlsemi.com/datasheet/XL7015-EN.pdf)连接。FB上臂10 kΩ、下臂3.3 kΩ得到名义5.038 V；上臂跨33 nF前馈电容，EN接GND常开（低电平使能）。输入电解选AiSHi EMK1KM330GB0D00T（33 µF/100 V，560 mArms）；输出选Nichicon UHE1C331MPD（330 µF/16 V，640 mArms）。官方未给输出ESR稳定窗口，启动、负载瞬态和环路在样机阶段验证。以5 V/0.3 A为本板设计预算，非承诺0.8 A全温持续输出。模块的`+5V`从J_MCU_A 1/2脚送到WeAct核心板`VCC`，GND_SYS接3/4脚；核心板原厂图标注VCC输入3.3–20 V，3V3由板载LDO生成，严禁把5 V接到3V3脚。正常整车供电只由BUS→XL7015供此5 V轨。

  **台架并供默认接法：**仅在9S/BUS断开且已隔离模块XL7015输出时，才可由限流外部5 V电源接`J_MCU_A.VCC(1/2)`与`GND_SYS(3/4)`；USB连接器只连D+、D−和GND，物理断开VBUS，不接3V3。WeAct官方QFN48图显示USB VBUS经D4接VCC，并有SB10跨接D4；官方图未证明手上核心板的D4/SB10装配状态。因此未检查实物前，禁止标准USB线与外部VCC并接；若VBUS未隔离，须先确认D4存在且方向正确、SB10开路。不要在XL7015仍连着有源BUS时从核心板VCC反向注入5 V，除非先验证电源路径无回灌。参考[WeAct核心板原理图](../../FOC驱动模块/参考资料/官方数据手册/WeAct_normal_QFN48_V1.0.pdf)。
- [TCAN1042HGVDRQ1](https://www.ti.com/lit/ds/symlink/tcan1042h-q1.pdf)：1=TXD、2=GND、3=5 V VCC、4=RXD、5=3V3 VIO、6=CANL、7=CANH、8=STB。VCC/VIO各100 nF；STB外部10 kΩ上拉到3V3，MCU初始化后拉低进入正常通信；TXD外部10 kΩ上拉至3V3。
- [PESD2CANFD24V-T](https://assets.nexperia.com/documents/data-sheet/PESD2CANFD24V-T.pdf)：pin1接CANH、pin2接CANL、pin3接GND_SYS，紧邻接口。复用库内完整订货名PESD2CANFD24V-TR，不按同名封装替代引脚核对。
- R_TERM为120 Ω电阻，直接跨接CANH与CANL，默认DNP；仅当本模块位于整车物理总线末端时装配，不设焊桥。波特率、报文ID及DBC待整车分配，不影响本板硬件选型。控制字段预留使能、快慢命令、停机/故障复位；状态包含电流、VBUS、板温、运行状态和故障位。心跳失联应在本地执行停机，不等待新的CAN指令。
- 母线ADC上臂由两只110 kΩ串联，下臂10 kΩ（建议0.1%），分压1/23，37.8 V对应1.643 V；ADC前加1 kΩ、节点100 nF。NTC采用3V3→10 kΩ精密上拉→ADC→NTC→GND，ADC节点10 nF；固件按该NTC原始R/T曲线校准。所测是本板温度，不标为绕组或芯片结温。
- 对上电、复位、失联、过温和nFAULT统一设计停机状态；故障消除后必须重新使能，不自动恢复原先速度。电流采样同步PWM，滑行/休眠时不可把无效IPROPI读数当完整电机电流测量。

## PCB与装配约束

- C_VM_BULK的本体高度为40 mm，PCB布局和整机结构须按该高度预留空间。
- 核心板插座按顶视图中的同号关系连接P1/P2，不镜像针号；插座朝向须与WeAct核心板实物和机械结构核对后再定版。
- 原生WeAct Normal QFN48 Rev.V1.0图的USB路径为VBUS→D4→VCC，SB10可旁路D4；板上实际装配未知。优先采用USB物理断开VBUS、只接D+/D−/GND并共地；否则先查实物D4及SB10。外部5 V仅在BUS断开、XL7015与5 V轨隔离时注入，禁止与未核实的USB VBUS或有效XL7015输出并供。

## 电压与散热校核范围

保留当前SMCJ40A，不换件。其`VRWM=40 V`对37.8 V理论母线只有2.2 V裕量；原厂规定脉冲条件下`Vc(max)=64.5 V @ Ipp=23.3 A`，高于DRV8262 60 V推荐工作上限、低于70 V绝对最大值。该数据没有证明未知线束、电机再生能量、布局寄生和温度下的实际TVS电流/钳位电压，也不保证器件始终留在推荐区；XL7015可承受的持续输入范围与TVS脉冲吸能不能混为一谈。需按实际泵与线束测量VM瞬态后再放行，不将纸面额定比较写成整车瞬态通过。来源：[Littelfuse SMCJ系列](https://www.littelfuse.com/assetdocs/tvs-diodes-smcj-datasheet?assetguid=37388813-0d6d-4329-969b-1aa8b7614ac1)、[TI DRV8262 Rev.C](https://www.ti.com/lit/ds/symlink/drv8262.pdf)。

在37.8 V、3 Arms、20 kHz下，按手册热态典型导通电阻和典型开关参数估算，驱动器损耗约1.25 W；套用手册JEDEC四层板22.2 °C/W，60 °C环境时估计结温约87.7 °C。这是散热方案起点，实际PCB必须焊接底部散热焊盘、扩大铜面并布散热过孔。不能用芯片16 A峰值标签代替3 A持续热校核。详见[可复现计算](../检查/选型计算.json)。
