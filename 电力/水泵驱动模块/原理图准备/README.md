# 水泵驱动原理图准备

本目录保存当前水泵驱动的选型与连接输入。实际水泵型号及启动、堵转、PWM 和制动参数尚未取得；本目录内容不构成实泵资格、采购或板级验收。

## 本目录直接文件

| 文件 | 用途 |
|---|---|
| [选型与连接约束.md](选型与连接约束.md) | 记录当前驱动器、接口、外围器件候选和原理图连接/待验证约束；候选参数不代表已采购或实泵适配。 |
| [原理图连接契约.json](原理图连接契约.json) | 以结构化数据列出原理图器件身份、引脚到网络的映射及未连接脚；用于与原生工程和导出的 ENET 做逐脚对照。 |
| [BOM.csv](BOM.csv) | 保存本模块的当前设计物料清单输入，含板内器件及相关外置/线束物项；数量和采购状态应按行内字段核对。 |
