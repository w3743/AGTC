# 水泵模块 EDA 自动化脚本说明

本目录保留本模块原理图构建、排版、导出及查询过程脚本。它们不是可任意重跑的无副作用工具；多数脚本通过官方 EasyEDA CLI 访问当前会话，部分会直接改动并保存当前原理图。当前设计状态和证据入口见[模块 README](../README.md)与[当前检查状态](../检查/当前状态.md)。

## 当前检查入口

- `../检查/验证原理图.py`：离线只读比较当前导出的ENET、BOM和`原理图准备/原理图连接契约.json`；不调用EDA、不改原理图，但会生成或覆盖`../检查/网表逐脚核对.json`。运行前确认输入文件是当前版本，结果需连同报告中的ENET SHA256核对。
- `导出核对.py`：当前原生导出/DRC检查流程。它会保存并重新打开固定文档、运行DRC、覆盖`../检查/原生DRC.json`及`../检查/原生器件绑定.json`，并覆盖当前ENET导出。它会接触活动EDA会话，不能作为离线/只读检查；运行前必须确认会话正打开本模块当前原生工程且该文档允许保存、重开和导出。
- `导出图纸.py`：通过官方API导出并覆盖当前交付目录中的PDF；会接触活动EDA会话并写文件。
- `载体快查.py`、`读取载体.py`：只查询库载体/封装元数据并写入`../检查/`查询结果，不创建或修改原理图对象。`eda.py`是底层CLI适配器，不是安全的通用入口：它也能执行任意调用者传入的JavaScript。

## 当前图纸后处理脚本

以下脚本用于当前布局的端口与文字整理，都会修改并保存活动原理图；仅在确认活动文档和目标布局后使用，执行后应重新导出并复核图纸及网表。

- `端口显示修整.js`：调整各 netport 的 Name 文字位置，设置为可见，并使用 API 默认字号（`fontSize: null`）。
- `隐藏重复线名.js`：隐藏线对象自身重复显示的 Name 属性，不删除连线或更改网络连接。
- `CAN文字修整.js`：整理 CAN_STB 端口名及 J_CAN 的 Name/Value 文字位置。

## 历史构建与实验脚本

下列脚本属于已完成原理图的构建/实验过程，不作为当前工程的标准重复施工步骤；任何复用前都需先逐行审查目标文档、输入和写入范围：

- `连接设计.py`从BOM生成并覆盖连接契约；`绑定准备.py`、`补齐载体.py`会更新绑定数据并向EDA会话写入全局数据，后者还会删除/重建器件。
- `主芯片.js`、`放置外围.js`、`放置外围.py`、`连接.js`、`连接.py`、`肖特基绑定.js`会放置/绑定器件或创建网络对象，并保存活动原理图。
- `图纸说明.js`会写入说明文字并保存；`极性朝向.py`会旋转电容，并改写`连接.js`文件。
- `网络标签朝向.js`、`标签文字排版.js`会删除并重建网络端口或改动线网标签后保存；`排版坐标修正.js`会删除全部连线、文字和非器件原理图对象后保存，属于破坏性排版实验，禁止直接对当前工程重跑。
- `逻辑接线.js`按 `pumpLayoutStage` 分阶段移动器件、重建并保存当前原理图；第 1–4 阶段末会统一将全部 netport 的 Name 设为可见并采用 API 默认字号（`fontSize: null`），同时更新图纸日期与标题。它不是只读核查脚本，执行前须确认活动文档、阶段和备份。
- `画布核查.py`是历史只读画布探查脚本；它读取活动会话，不代替已保存的ENET/BOM/契约逐脚核对。

本说明只整理用途和风险，不删除脚本、不执行脚本，也不表示任何未注明的产物已重新生成。
