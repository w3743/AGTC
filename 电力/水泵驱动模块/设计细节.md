## 功率级、调速与电流检测

当前主功率级为TI `DRV8262DDWR`（HTSSOP-44 DDW底部散热封装），两组半桥并联作为一组H桥，驱动一台有刷水泵。功率路径为BUS经外置支路保险进入`BUS_M`，再到驱动器VM；电机两根线分别接`MOTOR_A`、`MOTOR_B`，不把任一电机端子当作地。

| DRV8262功能/脚号 | 当前设计网络或连接 |
|---|---|
| VM：2、11、12、21 | 保险后`BUS_M`；在VM/PGND附近设置高频去耦并靠近bulk电容。 |
| MOTOR_A：4、5、6、17、18、19 | 并接至水泵端A。 |
| MOTOR_B：7、8、9、14、15、16 | 并接至水泵端B。 |
| GND/PGND：3、10、13、20、22、23；EP45 | 接`GND_SYS`；EP45为散热焊盘，应按原厂要求接地铜并布热过孔。 |
| MODE1：28、MODE2：29 | 接`DVDD`，选择单H桥+PWM模式；模式在使能时锁存。 |
| IPROPI：30、31 | 两路合并，仅接一个`R_IPROPI=1.5 kΩ/1%`到`GND_SYS`。MCU支路另经1 kΩ和10 nF滤波；滤波不串入比较器反馈主节点。 |
| VREF：33、34 | 并接名义1.65 V节点：3V3经10 kΩ/10 kΩ分压并加100 nF。 |
| OCPM：27、TOFF：35、DECAY：37 | OCPM接GND选择锁存故障；TOFF接DVDD、当前初值16 µs；DECAY接GND选择慢衰减。 |
| IN1：41、IN2：40、nSLEEP：42 | MCU控制，各输入有10 kΩ下拉。 |
| nFAULT：26 | 上拉到3V3并接MCU输入；不能据该脚区分全部内部故障原因。 |
| VCP：1、CPH：44、CPL：43 | VCP–VM接1 µF/16 V；CPH–CPL接100 nF/100 V。 |
| VCC：25、DVDD：24 | VCC接5 V并去耦；DVDD仅作内部LDO输出并按要求接1 µF去耦，不与5 V或核心板3V3短接。 |
| NC：32、36、38、39 | 悬空；不接网络。 |

当前PWM初值为20 kHz，命令`u=0…1`的理想驱动平均电压按`D=u×min(0.95,21/VBUS)`限制。理论母线22.5 V时满命令`D≈93.33%`，37.8 V时`D≈55.56%`。**这只限制平均值，PWM导通脉冲仍直接达到母线电压**；不能凭21 V理想平均值断定未知泵允许37.8 V重复脉冲。

21 V×3 A对应约63 W泵端平均功率；忽略驱动损耗时理论BUS电流约2.80 A（22.5 V）至1.67 A（37.8 V）。该计算不覆盖启动、堵转、泵电感或电制动。

IPROPI镜像系数212 µA/A为典型值；合并的H桥电流镜不因两桥并接而把总增益翻倍。3 A对应约0.954 V；`VREF=1.65 V`、1.5 kΩ电阻给出的运行斩波名义点约为5.19 A。这是候选工作点，不是有保证的硬电流上限；也不限制`IN1=IN2=1`时的高侧短接制动电流。

## 控制、复位及水泵制动行为

| 模式 | nSLEEP | IN1 | IN2 | 预期输出 |
|---|---:|---:|---:|---|
| 上电、复位或掉电默认 | 0 | 0 | 0 | 输出高阻、泵滑行；不是主动制动。 |
| 单向调速 | 1 | 1 | 反相PWM | 不开放反转；IN2=0为正向驱动，IN2=1为高侧慢衰减。 |
| 正常电机制动 | 1 | 1 | 1 | 两输出高侧短接，电机端子短接制动；电流/能量仍需实泵确认。 |
| MCU运行中滑行 | 1 | 0 | 0 | 输出高阻；与硬件复位/掉电默认状态不同。 |

参考控制策略要求CAN新鲜心跳、显式使能、BUS在候选窗口且IPROPI诊断正常后方可驱动；有效停止命令或CAN超时在测量健康时进入电机制动，CAN恢复不自动恢复旧速度。只有电流低于实泵确定的`I_brake_done`并满足驻留时间`T_brake_done`后才允许转入休眠。

IPROPI/ADC异常、nFAULT或BUS越界时，当前参考策略锁存故障并拉低nSLEEP，输出成为高阻滑行。此时不能声称泵一定快速停转；它是已记录的故障策略与“快速电机制动”需求之间的开放项，须结合真实泵能量和安全条件决定故障时能否、如何维持制动。`u=0`在此策略中表示高侧短接，不代表电流为零。详细策略模型为[泵控制参考状态机.py](检查/泵控制参考状态机.py)，只验证状态转换；其中阈值/驻留测试值不是量产固件参数或实泵验收结果。
