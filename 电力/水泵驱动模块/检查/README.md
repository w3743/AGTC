# 水泵驱动检查入口

本目录混合保存当前检查结论/核查脚本和逐次 API 读取产生的 JSON、PNG 及会话快照。当前结论优先看模块 README 指向的正式报告与状态文件；零散快照用于复核其记录的范围和输入版本，不单独代表当前源或实物验收。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [当前状态.md](当前状态.md) | 汇总当前原理图状态、未闭合警告和后续资格边界。 |
| [原理图全功能与逐脚复核.md](原理图全功能与逐脚复核.md) | 记录原理图功能/逐脚复核的结论和仍开放的事项。 |
| [选型核对.md](选型核对.md) | 说明本模块器件选型核对及未取得的水泵参数。 |
| [验证原理图.py](验证原理图.py) | 离线核对导出的 ENET、BOM 和连接契约；运行会写入逐脚核对 JSON，输入版本需先核实。 |
| [选型计算.py](选型计算.py) | 计算本模块候选的选型参数；对应结果在 [选型计算.json](选型计算.json)。 |
| [泵控制参考状态机.py](泵控制参考状态机.py) | 提供非量产固件的控制状态参考模型；模型用例不证明实泵停机或硬件保护。 |

其余直接 JSON/PNG 主要是当次网表、引脚、端口、库绑定、原理图修改、DRC、图纸局部和会话读取证据。阅读时用文件内的源哈希、时间和检查范围绑定结论；不得把旧布局阶段或中间状态当作当前状态。
