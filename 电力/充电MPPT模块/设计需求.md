# 充电 MPPT 模块设计需求

## 范围与验收

第六块独立板采用方案 A：三路独立同步 Boost 接收光伏片，一路 `BQ25756RRVR` 四开关同步升降压接收 USB-C PD 或 XT60 备用电源。冻结的 FOC、稳压、BMS、水泵四套原理图、四份施工合同和整车采购 BOM 均为只读输入；本次仅同步第六板 Markdown。

车端固件须采用面向目标平台编译的 C/C++ 或 Rust；本轮 Python 仅用于开发机检查与仿真。语言合规不代表板端性能验收通过。固件控制周期、延迟与资源预算、目标设备基线和实测须单独记录；未完成板端测量前不作性能通过结论。

## 功能需求

| 功能 | 目标与验收边界 |
|---|---|
| 三路光伏 | 总预留 120 W，三路独立采集电压、电流并追踪最大功率；冷态 `Voc ≤ 22 V`、`XT30` 口严禁反接大功率蓄电池。全板功率 N-MOS 统一 `HYG080N10LS1C2`，三路高侧检流统一 `INA293A1IDBVR`。供方仍须给出每片 `Vmp`、`Isc` 与温度系数，之后完成封板核算。 |
| USB-C PD / XT60 | 受电端目标覆盖 5–48 V，并按源实际公布的 SPR/EPR、PPS/AVS 能力协商；12 V 不假定为固定档。输入限流不得超过协商、电缆、转换器或 BMS 分配边界，两路互锁并防反灌。`J_XT60_CHG` 外部线束必须串联 **10–15 A 保险丝**，并在外部电源关闭/预升压或限流条件下接入，严禁 48 V 无保护带电硬插空载母线电容。模型筛查不是协议、电缆或热态实测。 |
| 对车供电 | 经既有 BMS 下游 `PACK+ / PACK−` 和分流器。光伏允许边充边工作；有线源在线默认禁止运动。CAN 节点目标 `0x06`，须与整车登记、超时及启动状态共同验证。 |
| USB 5 V 冷启动与门驱 | 在 `U_BUCK_PRE=SCT2A23ASTER`（LCSC `C2901894`，`Vref=1.200 V`；绝非 `C10425`）基础上新增 USB 5 V 低压冷启动辅助级：`Q_COLD_PASS (MMBT5401)` + `U_COLD_REF (TLV431AIDBZR C56765，由 PRE_3V6 供电)` + `Q_COLD_DRV/OV/SHUNT (MMBT5551)` + `Q_COLD_ERR (MMBT5401)`。`one_shot_risk_screens` ngspice-47 仿真（`PASS_MODEL`）显示，低至 `4.50 V` USB 输入仍可维持 `PRE_3V6 ≈ 3.463 V`（`4.75 V` 时 `3.469 V / 0.088 W`），经 `D_PD_VIN33_PRE` / `D_TPD_VPWR_PRE (BAT46W)` 直接唤醒 `PD_VIN3V3` 与 `PD_VPWR_3V3 ≈ 3.237 V > 2.99 V` 释放 `U_EPR_POR (Q_EPR_BLK)`（不串联依赖 `MCU_3V3`），高于 `~6.8 V` 后自动零功耗关断（至 `82 V` 浪涌 `Q_COLD_DRV` 基极 `~0.027 V`）。`C_PD_VBUS_LV` 旁保留 zero-cost DNP 空贴退路 `C_PD_VBUS_LV_DNP (1 µF/100 V)`（无 0 Ω 跳线）。后级目标 `10V_DRV=11.406 V`；须验证启动、真实 `VGS ≥ 10 V` 及 EN 关闭后 5 ms 内降至 50 mV 以下。 |
| BQ25756 CV 与回生退让 | 锁定 `230 kΩ / 10 kΩ`（`FBG≈33 Ω`）：默认 `VFB_REG=1.536 V` 对应 `36.748 V` 标称值，停车逐台 DAC 校准目标 `37.20–37.45 V`，硬上限 `≤37.80 V`。跨接 `BQ_FB–BQ_FBG` 保留 zero-cost DNP 兜底焊盘 `R_BQ_FB_TRIM_DNP (1 MΩ ±0.1%)`：正常板不焊；仅当极端 `-0.7% / 55 Ω` 单元未调上限掉至约 `37.054 V` 时补焊即可拉升至 `~37.407 V`（DAC `1.546 V` 可调至 `37.20 V`，硬上限内 `max 37.671 V`），否则拒收。`TLV6700` 二级硬件 OV 静态角落 `38.253–39.215 V`（高于 `37.80 V`、低于 BMS BOV `40.30 V`）；保护动作、续流、过冲及恢复仍待台架验证。 |
| BQ ACUV 输入门限 | `R_BQ_ACUV_TOP=100 kΩ ±0.1%`，下臂 `R_BQ_ACUV_BOT1=30.1 kΩ ±0.1%` 与 **`R_BQ_ACUV_BOT2=10 kΩ ±0.1%`** 串联为 **`40.1 kΩ ±0.1%`**，以 `1.15 V` typ 得标称 ACUV 上升阈值 **`4.018 V`**（按 `1.20 V` 上界算最坏角落 **`4.199 V`**，较 `4.75 V` USB 保留 `+0.551 V` 裕量）。全温 ACUV 迟滞与角落最终仍须台架核验。 |
| 温控加热 | 仅在低温且有效温度低于 2 °C 时允许；包内监测点全部高于 5 °C 且 BMS 有正充电额度后才可充电。温度故障、`CCL=0`、缺光或过热均关闭加热。**不改 PCB 的板外硬保护**：`J_HEATER` 外部线束必须串联 **45–50 °C 常闭机械温控开关（如 KSD9700 贴附电芯表面）+ 支路保险丝**，在 MCU 死机或 NTC 脱落失效时提供纯硬件超温/短路兜底断开。 |
| 休眠与看门狗 | 第六板 Tier 0 目标 `<5 mW`，尚未实测。冻结 BMS `RUN` 时 CAN 仍接 `VOUT_5V`，整车 80–130 mW 为估算；BMS Rev2 `<50 mW` 为未实现规划。独立 RK 心跳驱动硬件看门狗，不允许 MPPT MCU 代喂。 |
| 接口与固件调试边界 | 光伏 XT30、备用 XT60、`J_HEATER` 5.08 mm 2P、隔离 CAN XH 3P（`1=GND_CAN, 2=CANH, 3=CANL`）；弱电 2P 排针（`J_SYS_SLEEP_CTL`、`J_SYS_PWR_CTL`、`J_NTC_HEATER`）无板载 ESD 管，装车点胶固定避免带电频繁热插拔。STM32G431 车端固件须启用 `TIM1` 硬件死区、最小/最大占空比硬限幅及 **ADC 模拟看门狗（AWD）硬件中断触发刹车**；首版 PWM 调试须使用限流可调直流电源。发板前逐颗核对物理封装焊盘/1 脚方向；回板测通后建议刷三防漆并对大电感/电解电容/接插件点胶加固。 |
