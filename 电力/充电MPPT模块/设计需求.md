# 充电 MPPT 模块设计需求

## 范围

第六块独立板采用方案 A。三路独立同步 Boost 接收可展开的光伏片，一路 `BQ25756` 四开关同步升降压接收 USB-C PD 或 XT60 备用电源。冻结的 FOC、稳压、BMS、水泵四套原理图、四份施工合同和整车采购 BOM 作为只读输入。

| 功能 | 目标与验收边界 |
|---|---|
| 三路光伏 | 总预留 120 W，每路以约 60 W、4–5 A 输入做选型比较。三路独立采集输入电压、电流和追踪最大功率。冷态 `Voc ≤ 22 V`，待供方给出 `Vmp`、`Isc` 和温度系数后封板。较低工作电压按电流限额降功率。 |
| USB-C PD / XT60 | 受电端验证 5–48 V，覆盖可用 SPR/EPR、PPS/AVS 档。12 V 必须由源端实际公布的能力提供。净输入限流不得超过协商、电缆、转换器或 BMS 分配的边界。XT60 允许额定 48 V 电源或工作范围已核实的高压光伏。两路输入互锁并防反灌。 |
| 对车供电 | 正常充电经既有 BMS 下游 `PACK+ / PACK−` 端口和 BMS 分流器。光伏可边充边工作，有线源在线默认禁止运动。CAN 节点目标 `0x06`，与整车项目登记、超时和启动状态一起验证。 |
| 回生退让 | 行进模式充电输出名义 CV 为 37.6 V，停车充满目标最高 37.8 V。母线上升时充电器退出注入，保留现有稳压和泄放功能。实测从过阈值到支路电流接近零的时间，连同温漂、静态容差和回生叠加验收。 |
| 欠压恢复 | 母线 0 V 时，光伏独立启动第六板控制偏置。用户批准另定义 BMS 唤醒和充电授权接口，四板 PCB 继续冻结。主充电输出在 BMS 正式许可前保持断开。 |
| 低温预热 | 由光伏供电，目标薄膜加热片 30–50 W。BMS 明确报告低温且有效温度低于 2 °C 时可进入加热。包内监测温度全部高于 5 °C 且 BMS 给出正充电额度后才能开始充电。温度失效、原因不明的 `CCL=0`、缺光及过热均关闭加热。 |
| 深度休眠和看门狗 | Tier 0 整车电池端静态功耗 `<50 mW`。Tier 1 仅启用必要的采样、充电和加热控制，Tier 2 才启用任务负载。硬件看门狗经独立、可量测的控电路径强制复位 RK3588 电源轨。 |
| 通用接口 | 光伏高电流位统一 XT30，备用电源 XT60。`J_HEATER` 用 5.08 mm 2P 插拔端子。隔离 CAN 使用 XH 3P，`1=GND_CAN, 2=CANH, 3=CANL`。复用 STM32G431 平台、通用排母及已冻结的普通阻容。 |

第六板的设备端控制采用目标平台编译的 C/C++ 或 Rust。本轮的 Python 只用于开发机仿真和验算。车载固件性能、CAN 充电协议实现、16 KB CAN Bootloader/OTA 和实物验收须有目标设备测量证据。
