# 充电 MPPT 模块设计需求

## 范围与验收

第六块独立板采用方案 A：三路独立同步 Boost 接收光伏片，一路 `BQ25756RRVR` 四开关同步升降压接收 USB-C PD 或 XT60 备用电源。冻结的 FOC、稳压、BMS、水泵四套原理图、四份施工合同和整车采购 BOM 均为只读输入；本次仅同步第六板 Markdown。

车端固件须采用面向目标平台编译的 C/C++ 或 Rust；本轮 Python 仅用于开发机检查与仿真。语言合规不代表板端性能验收通过。固件控制周期、延迟与资源预算、目标设备基线和实测须单独记录；未完成板端测量前不作性能通过结论。

## 功能需求

| 功能 | 目标与验收边界 |
|---|---|
| 三路光伏 | 总预留 120 W，三路独立采集电压、电流并追踪最大功率；冷态 `Voc ≤ 22 V`。供方仍须给出每片 `Vmp`、`Isc` 与温度系数，之后完成封板核算。 |
| USB-C PD / XT60 | 受电端目标覆盖 5–48 V，并按源实际公布的 SPR/EPR、PPS/AVS 能力协商；12 V 不假定为固定档。输入限流不得超过协商、电缆、转换器或 BMS 分配边界，两路互锁并防反灌。模型筛查不是协议、电缆或热态实测。 |
| 对车供电 | 经既有 BMS 下游 `PACK+ / PACK−` 和分流器。光伏允许边充边工作；有线源在线默认禁止运动。CAN 节点目标 `0x06`，须与整车登记、超时及启动状态共同验证。 |
| USB 5 V 冷启动与门驱 | `U_BUCK_PRE=SCT2A23ASTER`（LCSC `C2901894`，`Vref=1.200 V`；绝非 `C10425`）由 `R_AUX_EN_TOP=150 kΩ (C728671)`、`R_AUX_EN_BOT=100 kΩ (C25803)` 和 `Z3V6` 设定启动；`AUX_HV_IN=4.65 V` 时 `AUX_BUCK_EN=1.86 V`，远高于 `1.24 V` EN 阈值。`R_PRE_FB_TOP=20 kΩ` / `R_PRE_FB_BOT=10 kΩ` 产生 `PRE_3V6=3.600 V` 标称值。`PRE_3V6` 经 `D_PD_VIN33_PRE (BAT46W)` 直接供 `PD_VIN3V3`，经 `D_TPD_VPWR_PRE (BAT46W)` 直接供 `PD_VPWR_3V3`，分别与 `3V3_STBY (D_PD_VIN33_OR)`、`PD_3V3 (D_PD_VIN33_SELF / D_TPD_VPWR_OR)` 并联；同时 `PRE_3V6` 供给 `5V_SYS -> MCU_3V3`。因此两路 PD 电源可从 `PRE_3V6` 直接唤醒（约 `3.25 V`），释放 `U_EPR_POR (Q_EPR_BLK)`，不依赖 MCU_3V3 串联启动。低输入 Type-C VBUS 冷启动裕量（约 `4.75 V - VF`，接近 `SCT2A23ASTER` `4.5 V` 最低 VIN）仍由台架 bring-up 验证。后级目标 `10V_DRV=11.406 V`；须验证启动、真实 `VGS ≥ 10 V`、驱动输入额定值，并验证 EN 关闭后 `10V_DRV` 于 5 ms 内降至 50 mV 以下。 |
| BQ25756 CV 与回生退让 | 锁定 `230 kΩ / 10 kΩ`（`FBG≈33 Ω`）：默认 `VFB_REG=1.536 V` 对应 `36.748 V` 标称值。停车逐台 DAC 校准目标 `37.20–37.45 V`，硬上限 `≤37.80 V`；不可盲写最大码 `1.566 V`，也不得宣称目标为 `37.65–37.70 V`。在极端 `-0.7%` / `55 Ω` FBG 较低容差下，最大码对应未校准下界约 `37.054 V`，因此 bring-up 必须逐台校准并拒收无法在 `≤37.80 V` 内达到 `≥37.20 V` 的单元。`TLV6700` 二级硬件 OV 静态角落 `38.253–39.215 V`，高于硬上限且低于冻结 BMS BOV `40.30 V`；保护动作、续流、过冲及恢复仍待台架验证。 |
| BQ ACUV 输入门限 | `R_BQ_ACUV_TOP=100 kΩ ±0.1%`，下臂 `R_BQ_ACUV_BOT1=30.1 kΩ ±0.1%` 与 `R_BQ_ACUV_BOT2=4.7 kΩ ±1%` 串联为 `34.8 kΩ`，以 `1.15 V` typ 得约 `4.455 V` 标称 ACUV 上升阈值，修正先前 `4.971–5.004 V`、对 USB 5 V 无裕量的问题。全温 ACUV 迟滞与角落最终仍须台架核验。 |
| 温控加热 | 仅在低温且有效温度低于 2 °C 时允许；包内监测点全部高于 5 °C 且 BMS 有正充电额度后才可充电。温度故障、`CCL=0`、缺光或过热均关闭加热。 |
| 休眠与看门狗 | 第六板 Tier 0 目标 `<5 mW`，尚未实测。冻结 BMS `RUN` 时 CAN 仍接 `VOUT_5V`，整车 80–130 mW 为估算；BMS Rev2 `<50 mW` 为未实现规划。独立 RK 心跳驱动硬件看门狗，不允许 MPPT MCU 代喂。 |
| 接口 | 光伏高电流统一 XT30，备用电源 XT60；`J_HEATER` 为 5.08 mm 2P；隔离 CAN XH 3P：`1=GND_CAN, 2=CANH, 3=CANL`。复用 STM32G431 平台。 |
