# 稳压模块设计需求

更新：2026-10-29。本文为稳压模块唯一现行需求入口；全部选型、接线、保护、计算、成本和待关闭项统一在[设计细节](设计细节.md)维护。原理图与采购BOM未随本轮目标自动变化。

## 已确认要求

| 项目 | 要求 |
|---|---|
| 独立模块 | 必须保留独立本地控制和CAN，不允许并入FOC控制器。CAN只协调，快速调节与必要保护在本地完成。 |
| 超容 | 保留8颗LICAP SC0350-270-RSS，8S1P；不增加到16颗。不因未验证旧800–1000W/1s场景而擅自扩容。 |
| 电池与母线 | 用户选定9S5P EVE INR18650-30P，45颗、15Ah标称，沿用9S理论22.5–37.8V范围。130A/1s仅为BMS增强比较点，实际可用能力由BMS按温度、电压、均流和资格发布。 |
| 双机峰值 | 保留两台N5065同时各1.8kW母线输入峰值能力，峰值时长尚未新指定；无超容余电时允许限功率、缓慢加速。 |
| 优先用途 | 超容首要承接电制动回生；启动有余电时补能。待机应预留吸能空间，不把满充设为车辆启动前提。 |
| 正常0V初充 | 从电容组完全0V开始由车载功率级正常受控充电，期望几十秒量级；不得用日常外接服务电源或mA级长时间充电替代。精确最大秒数、就绪电压/能量是设计比较项，不伪装用户已指定。 |
| 净充电 | 电池包最大净充电16A；太阳能、双FOC回生、超容放电和其他负载按净值聚合，能力仅分配一次。 |
| 制动 | 用户确认没有机械刹车。电池/超容不吸能时，必须在定义工况内有电耗能/电制动路径；额度0、关PWM不是停车保证。 |
| 制动参照 | 用户要求按M1A1的1∶10刹车作大致比较。原车公开减速度、本车质量/速度和比例推算均在细节标注；不能按尺寸比例直接缩放制动力，也不自动承诺原车失电/驻车性能。 |
| 可编程策略 | 使用参数加预置策略；按可信电流/电压/温度和各路径余量限幅，允许配置工作窗口、限流、功率、斜率和控制参数。 |
| 环境与测温 | 全车0–60°C环境；本板必须测温，并计超容最高温度、器件自热、热点及传感器安装/响应误差。 |

## 必须覆盖的原理边界

- 逐节测量与过压/欠压监测从0V状态可用；最高/最低单体决定允许行为，总压不能替代逐节保护。均衡只处理慢失衡，不能承接主充电流。
- 覆盖上电、复位、掉电、数据陈旧、比较器/AFE异常、通信失联和恢复默认态；故障释放不能无条件自动重新启动主功率。
- 主桥停栅极与真实故障隔离分别核对。QH/QL短路、两方向电流、关断磁能、残压、保险分断和失电状态须有明确路径。
- 超容隔着DC/DC，不能计入公共BUS直连瞬时电容。功率/吸能能力必须同时满足电流、转换器、温度、单体电压和剩余能量约束。
- 满电池/满超容、单路径退出和两侧同时制动均须核算；TVS不作为持续制动电阻。未冻结的长下坡、重复率、失电停车和驻车保持不得自行承诺。

## 精简、成本与分工

- 优先复用已有精确MPN和整功能块，兼顾芯片及高价值器件、总数量、焊点、能耗与稳定性。新增、删除、替换与移用分别列清；不能用局部净件数代表完整整改。
- 稳压原500元上限已由用户取消，成本优化要求保留。报告完整BOM及MOQ现金影响；报价缺项留未知，核心芯片小计不能冒充整板总额。
- 用户要求每块板只保留《设计需求.md》和《设计细节.md》两份现行设计文档，后续原位更新；README仅导航，JSON/CSV、厂家原文和冻结模型证据为附件。
- 原理图之后的PCB设计、制造、装配、固件实现及实物测试均由人类完成；代理完成原理图、选型、接口、计算与原理级验证。没有样板不阻碍继续纸面设计，模型通过也不能写成实物通过。
