# 三板共用修复复查

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [仿真复查.md](仿真复查.md) | 记录三板共用修改后仿真复查范围和结论。 |
| [仿真复查.json](仿真复查.json) | 保存仿真复查结果和结构化条件。 |
