# 稳压模块检查入口

本目录保存当前官方原理图审查、逐脚合同和支持证据。使用时优先看[全功能与逐脚复核.md](全功能与逐脚复核.md)及其绑定的源哈希；零散报告和截图只覆盖各自记录的对象/版本。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [全功能与逐脚复核.md](全功能与逐脚复核.md) | 当前正式原理图的功能和逐脚复核报告。 |
| [全功能与逐脚复核.json](全功能与逐脚复核.json) | 对应复核范围和结果的结构化记录。 |
| [原理图复核结论.md](原理图复核结论.md) | 稳压原理图的简要复核结论及限制。 |
| [全部引脚合同核对.csv](全部引脚合同核对.csv) | 逐引脚预期网络合同表，用于对照当前工程读回。 |
| [当前官方网表.enet](当前官方网表.enet) | 官方工具导出的当前原理图网络表快照；须按复核报告中的哈希识别版本。 |
| [超级电容封装核对.json](超级电容封装核对.json) | 超级电容相关封装的核对记录。 |
| [当前原理图证据.json](当前原理图证据.json) | 2026-10-21 旧 166 器件/450 脚原理图快照；报告明确不作为当前源结论。 |
| [BOM恢复证据.json](BOM恢复证据.json) | BOM 恢复过程的机器记录。 |
| [文件整理记录.json](文件整理记录.json) | 本目录相关文件整理过程记录。 |
| [当前图面总览.png](当前图面总览.png) | 当前源图面整体截图，适合视觉定位，不能代替网表检查。 |
| [当前图面局部_BUS输入.png](当前图面局部_BUS输入.png) | BUS 输入区域局部截图。 |

## 子目录

| 目录 | 内容 |
|---|---|
| `未通过项修复/` | BUSFIX 逐节保护复查报告和绑定证据，含只读会话/原生哈希/归档读回记录；详见其目录说明。 |
| `原理整改/` | 分压修正、封装属性变更、改前后读回和修改源归档等原理整改记录；条目按自身哈希和时间解释。 |
| [三板共用修复/](三板共用修复/README.md) | 共享器件修复的官方网表、DRC和仿真复查材料，不替代模块当前复核。 |
