## 接线及电源

VC0从SC_MINUS经100Ω引入，对GND_SYS加220nF；VC1…VC7分别从T1…T7经100Ω引入，各220nF跨相邻测量端；VC8…VC15短接VC7；VC16从SC_PLUS经100Ω引入，220nF跨VC16与VC15。有效通道掩码为0x807F，禁止测量或均衡不存在的中间组。VSS接GND_SYS；SC_MINUS与系统地之间仍只有原功率分流器，不能用AFE供电地短接分流器。

AFE现由超容本身供电。BAT与NPN预稳压集电极使用两条独立的BAT46W供电支路，分别保留滤波/限流；预稳压采用FCX495TA、1kΩ/2W、10MΩ、22nF；REG1 3.3V只供健康信号与AND门，REG18仅本地旁路。当前候选配置的CP1为1µF/25V，CPEN=0，CHG/DSG/PCHG/PDSG未接功率MOS。HiLink URB4812YMD-10WR3则从BUS_EXT输入产生12V_DRV，不是BQ的BAT电源，也不是超容自举电源。

TI[BQ76952数据表](https://www.ti.com/lit/ds/symlink/bq76952.pdf)将BAT正常工作下限规定为4.7V；BAT上电复位上升门限3–4V不等于该范围以下已保证正常。TI还规定VCx、x≥5的输入下限为max(VCx−1−0.2V, VSS+2.0V)，因此逐节通道有效还要满足VC5相对VSS至少2.0V。电芯ADC的全规格精度条件为单节差分电压2V至5V之间；本合同用每节外部确认≥2.05V作为BQ接管的候选下限，留出门限余量。单看总压不能替代逐节及VC5检查。现行运行窗仍按每组2.2–2.45V；现有软件/AFE软硬保护门限不代表0V初充阶段具备精度。

### 初充路径与电流/时间边界

现成HiLink 12V不能单独充到8S组的BQ全精度起点。若未来要求车辆母线存在时自启动，低复杂度候选路径是 `BUS_EXT → D_PRE（BAT46W，阳极接BUS_EXT、阴极朝SC_FUSED）→ R_PRE1 2.4kΩ → R_PRE2 2.4kΩ → SC_FUSED → 原F_SC → SC_PLUS → 8S电容 → SC_MINUS`。它必须保留原F_SC串联通路，不能跨接/旁路F_SC。D_PRE可复用BAT46W已有精确料号，但这是新增的实体器件实例；两只2.4kΩ电阻是额外实装件，至少要求1%且在最高工作温度下单只允许功耗不低于0.61W，封装和料号尚未选定。忽略二极管压降并按1%低阻角计算，BUS=37.8V时正常电流≤7.95mA；任一串联电阻短路时≤15.9mA。两只完好时每只约0.15W，单只短路时幸存电阻约0.60W。正常时该电流低于25°C下120Ω泄放支路的约20.7mA能力，但这不是全温硬保护证明。

8只350F串联的初始最小等效电容为43.75F。以4.8kΩ名义串联电阻作无负载RC估算，时间常数约58.3h：从22.5V/37.8V母线升到BQ BAT=4.7V约13.7h/7.7h；升到每节平均2.0V（总16V）约72.5h/32.1h；升到现行最低工作总压17.6V约88.9h/36.5h。LICAP初始容量容差为0/+20%，因此实装时间可更长；BQ、均衡及变换器待机负载会进一步延长或使电压停滞。这是数日级、非快速启动路径。

该电阻支路本身不主动截止，且若长期并接会在主隔离FET关闭时仍给超容提供微小充电电流；必须串入失电默认关闭的启动开关并由逐节监测授权，不能把固定电阻支路直接常接当作产品初充。BUS_EXT=0时车辆母线没有初充能源。外部逐节限流服务充电器只保留为台架调试、故障恢复和维修应急工具，不作为正常产品启动前提，也不能用它替代产品内的逐节监测。

### 最小可行路径与自动启动前置件

车辆正常使用不能依赖用户先接服务充电器。当前 BQ7695202 在0V阶段不能提供有效逐节闭锁；正常自动启动应在低电流启动支路接入由辅助电源供电、对0V单节仍有规格的独立监测器，在每次释放限流支路前完成八组扫描。扫描无效、任一组超窗、抽头开路/顺序异常、AFE通信超时或控制器复位时，串联预充开关必须默认关断。启动电流仍由硬件阻值限制，不能把软件电流请求作为唯一限流手段。

当前两只2.4kΩ串联电阻从0V到总压16.4V的一阶估算时间约为76.1小时（BUS=22.5V）至33.2小时（BUS=37.8V），按8S1P等效43.75F、总电阻4.8kΩ、忽略二极管/待机负载计算。它可以构成无需人工逐节接线的受控初充候选，但速度是数十小时量级；如果产品不接受该时长，需另行按电容厂商充电额定条件、分支故障功耗和逐节硬关断能力重算启动电流，当前不能擅自减小电阻。

**仍未闭合的独立保护条件：**LTC6811的UV/OV结果由主机读取，没有直接硬件过压关断输出。因此，“LTC6811+MCU”能构成受限电流的受控初充监测链，但不能单凭该芯片证明MCU软件故障时的独立OV切断。若产品安全要求把初充阶段也纳入MCU失效后的独立硬件保护，就需在该架构上增加一条硬件撤销路径（例如经规格确认的8路BW LED隔离汇总，或另选具有明确硬故障输出且支持全0V共模的AFE/保护器），并验证预充开关默认态、看门狗、栅极下拉与控制器卡死场景。现行0V初充保持HOLD，LTC6811侧车只是待后续设计的监测候选，不能替代现有BQ的FET驱动/保护链，也尚未构成完整自动初充方案；外部逐节服务设备只用于台架调试和故障应急。

以上是原厂规格边界和架构比较，不表示已改原理图、已采购器件或实物验证通过。依据：[ADI LTC6811-1/-2原厂数据表](https://www.analog.com/media/en/technical-documentation/data-sheets/LTC6811-1-6811-2.pdf)、[ADI LTC6811-1产品页](https://www.analog.com/en/products/LTC6811-1.html)、[ADI LTC6803-2/-4原厂数据表](https://www.analog.com/media/en/technical-documentation/data-sheets/680324fa.pdf)、[ADI LTC6803-4产品页](https://www.analog.com/en/products/ltc6803-4.html)、[ST STM32G431原厂数据表](https://www.st.com/resource/en/datasheet/stm32g431mb.pdf)。
### BQ接管、栅极泵与故障规则

候选BQ串联FET设置为FET Options `0x2D`（FET_INIT_OFF、FET_CTRL_EN、HOST_FET_EN、SFET置位；不启用PDSG/SLEEPCHG），Chg Pump Control `0x01`（CPEN=1、LVEN=0高过驱动、SFMODE_SLEEP=0），CP1用470nF。TI数据表对CP启动给出最大100ms条件：CP1=470nF、CHG/DSG负载各按20nF表征；若选MOS门极负载超出条件，不沿用该时间。配置、FET_EN、保护映射读回通过后再启泵，等待至少100ms并实测CHG/DSG栅源电压与关断电平。`AFE启动配置.json`是未烧写的数字许可候选配置；本轮已按8S1P、8颗修正。FET Options=0x08和CP关闭仍对应未连接CHG/DSG功率FET的候选，不代表上述串联双FET方案已经配置。

BQ接管条件必须同时满足：BAT≥4.7V；VC5≥VSS+2.0V；八个真实通道均映射且每节外部确认在2.05–2.45V、BQ读数有效且在其2–5V精度规格范围内；配置寄存器和保护状态读回一致；I2C/CRC、MCU、温度、总压交叉检查、硬件许可和PWM空闲态均有效。主变换器大电流许可要等每节都处在当前运行窗2.2–2.45V，并通过低电流方向和电流斜率检查后才逐步释放。

| 状态/故障 | 两只共漏N-MOS及变换器的要求 |
| --- | --- |
| 0V、无BUS、BQ掉电、MCU复位、配置/通信/测温无效 | 两只FET栅源下拉保持关断；硬件PWM许可为低，双向主电流均禁止。不能靠软件启动默认值。 |
| 正常充电/放电 | 完整监测、保护读回、CP稳定和许可链成立后才开通；先低电流斜坡。 |
| COV/充电过压 | BQ配置应关闭CHG方向；是否允许DSG方向作安全释放需符合产品策略。若该故障要求两向隔离，则额外撤销共用许可并关两只FET。 |
| CUV/放电欠压 | BQ配置应关闭DSG方向；若要求两向隔离，同样关两只FET并禁止变换器。 |
| AFE/REG1掉电、VC抽头开路、CRC超时、温度/总压不一致、驱动故障 | 不得只靠MCU PWM停机；硬件许可需失电默认关断并锁存。RGS和驱动节点必须覆盖AFE掉电/高阻状态。 |
| 单只主FET短路或体二极管导通 | 双FET并非对单只短路的双向冗余；BQ在串联FET模式可能为避免体二极管损坏而在特定电流条件重新打开另一只FET。需要关变换器并以短路注入/电流方向实测确认失效行为，不能宣称单点器件故障仍双向隔离。 |

**当前结论：**可确定的低复杂度路线是外部逐节限流服务预充，之后由独立BQ7695202与双N共漏FET接管；它不增加板上自动初充电路，但需要逐节服务电源/监测设备。现有HiLink12V和BW6101 LED不足以证明自动0V硬切断。若必须在车辆母线存在时自动启动，须新增隔离的8路BW报警接口或另一个能从低压独立启动的逐节监控/切断级，加上常态关闭的预充开关；需要原厂补齐BW LED电气接口并完成全温/单路断线/短路试验后才可定案，当前仍HOLD。不得让主DC/DC绕过未工作的BQ逐节监测直接高电流充电。

## 健康许可链

DCHG和DDSG配置0xAA是候选配置，各自定义为健康时高、故障或禁止时低，尚未烧写/读回。候选方案拟将两路与MCU许可输入送入SN74LVC1G11三输入AND，输出经680Ω接DRV8161共用nFAULT/nDRVOFF，保留10kΩ下拉；每个AND输入拟加47kΩ下拉。明确当前与候选边界：当前原生U_SC_OV pin 6（TLV6700 OUTB）仍接DRV_FAULT_N；将OUTB改接MCU_PERMIT_AFE并与MCU许可合并只是候选接法，尚未落图。候选MCU输入串联4.7kΩ，避免与AND推挽输出争用；不得把这条候选路由写成当前已实施连接。

680Ω与10kΩ已计入电阻初始容差及100°C、100ppm/°C温度敏感度。以AND最低保证VOH=2.4V计算，DRV输入最低约2.24V，高于2.2V输入门限；DRV拉低至0.4V时电流约4.8mA，低于其5mA测试负载。余量小，必须检查实际电源最低值与噪声，不得把名义3.3V代入替代保证角。

数字健康输出依赖内部保护状态配置。现有`AFE启动配置.json`仍保留FET Options=0x08、SFET=0和CPEN=0的旧候选，适用于原先没有CHG/DSG功率FET的图，不适用于本节新增的串联双N-MOS方案。若采用串联双FET，应以本合同候选FET Options=0x2D、Chg Pump Control=0x01为一组整体配置并重新读回保护映射；不得混用“SFET关闭、泵关闭”的旧设置。CHG FET Protections A=0x98、DSG FET Protections A=0xE4仍须与故障输出映射在芯片读回及台架注入时核实。依据[TI数字故障输出配置说明](https://e2e.ti.com/support/power-management-group/battery-management/f/power-management-forum/1237508/faq-bq76952-do-the-dchg-and-ddsg-signals-on-the-bq769x2-follow-the-chg-and-dsg-fet-driver-pin-states)。完整寄存器与启动顺序见[AFE启动配置](AFE启动配置.json)。不在本轮烧写OTP。

## 快速过流路径

本地快速关断使用两个比较器形成电流窗口，不通过CAN、I2C、软件中断或AFE的毫秒级保护：PB1→COMP1正输入，DAC3_CH1→COMP1负输入，正常极性作上限；PA7→COMP2正输入，DAC3_CH2→COMP2负输入，反相输出作下限。两个比较器内部输出均接TIM1 Break1，触发后清MOE并保持锁存，关闭自动恢复。PA8/TIM1_CH1与PB13/TIM1_CH1N的空闲电平都设低；仅靠互补PWM占空比为0不能证明两个门极都低。

[ST的G431器件定义](https://github.com/STMicroelectronics/cmsis-device-g4/blob/master/Include/stm32g431xx.h)具有TIM1_AF1的BKCMP1E、BKCMP2E路由；[ST比较器驱动定义](https://github.com/STMicroelectronics/stm32g4xx-hal-driver/blob/master/Inc/stm32g4xx_hal_comp.h)及RM0440确认上述输入与DAC3双通道。初始化须先DAC自校准、设置门限、等待稳定，再开启比较器并锁定配置，最后才允许MOE和MCU许可。Break输入不加数字滤波/blanking；若实测开关毛刺导致误触，先修采样布局与模拟滤波，修改blanking前必须重算峰值上冲。

建议首板以±72A比较器门限调试，零点/增益及两个实际翻转门限校准后的总误差目标≤1A，电流越限到两路门极停止继续增流的总响应目标≤2.5µs。按BUS≤46V、SC≥13.6V、热态电感≥12µH，最坏充电斜率(46−13.6)/12µH=2.7A/µs，上界72+1+2.7×2.5=79.75A。原“800W峰值约69.65A、低于最低71A触发点”的数字来自已取消的2P模型，不适用于8颗现行方案。8S1P必须使用单颗280F寿命末期容量与对应串联ESR重算；若电流筛选超过候选比较器最低动作点，应降低可用功率/电流额度或调整受验证的控制边界，不能因此恢复16颗增容。以上是可执行的标定与响应验收指标，不是已取得的最大延迟保证；DRV CSA数据中的典型漂移和典型建立时间不能代替全温最大值。BUS超出该范围、磁件饱和、功率管短路等故障不能沿用这个80A上界。

## 逐节电压与功率额度

软件正常停机阈值取每组1.74V/2.50V；单组总测量误差分配25mV，其中AFE规格15mV，余下10mV分给连接、滤波、噪声与建立。包含数据年龄在内，软件检测到PWM停止的预算50ms。按8S1P每组单颗350F、寿命末期80%即280F、80A计算，50ms内额外电压变化14.286mV；欠压真实下界约1.7007V，上压真实上界约2.5393V。原560F/7.14mV使用了已取消的2P容量，本轮修正，不能再用于现行方案。该低压边界只有约0.7mV名义余量，25mV误差与50ms响应均未实测，不能视为已留足工程裕量。AFE独立紧急门限为1.518V/2.5806V，99ms名义延迟，完整响应须验证≤150ms。两级故障都撤销许可；恢复需新有效扫描及重新使能请求。

此前17.45V待机、800W/1s双向筛选通过的结果来自已取消的16颗/2P容量与ESR，属于历史结果，不适用于现行8颗。当前验证输入固定8S1P，按明确标注的测试时程计算瞬态灵敏度；测试时程不代表用户新增的持续时间要求，具体结果以当前脚本和结果JSON为准。实际启动峰值电流与持续时间待按真实过程核定，保护门限和电流额度仍须据此重算。25mV组间偏差包括受载后的ESR及电容差异，必须通过配组、测量与运行降额维持，不能靠空载均衡值替代。

可复算结果见[AFE保护边界验证](../仿真/结果/AFE保护边界验证.json)。仍需解决主功率MOS短路后的熔断/隔离配合、电感热态偏置、外置泄放电阻脉冲能力及整车能量出口；这份局部计算不把这些问题标为通过。
