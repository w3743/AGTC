# 可编程稳压控制

日期：2026-10-10。版本：V1.3。状态：软件功能需求定义，尚未实现或联合验证；当前先完成硬件原理图，程序实施暂缓。

## 配置与预置策略

系统基线为 9S4P INR18650/30P 电池直连 BUS（规格 22.5–37.8 V，标称 32.4 V）和 8S1P 超容。控制器采用 WeAct Normal QFN48 STM32G431CBU6 核心板，VCC 使用 5 V、板载 3.3 V 供 MCU/TCAN332/逻辑；优先核定复用本地候选 PSU5_EXT（URB4805YMD-10WR3，5 V/2 A、10 W），额定 2 A 不代表可用余量。12 V 辅助电源优先评估 URB4812YMD-10WR3（12 V/833 mA、10 W），尚未定型；RECOM 仅作规格备选参考。电池可用功率由 BMS 按 SOC、温度、电压和成组限值提供，37.8 V 电芯规格端点不是 BUS 保护阈值。

用户已选择“参数＋预置策略可配置”。可配置项包括策略 ID、瞬态 BUS 参考/动态基线偏置、支撑与吸收死区、电流及功率上限、超容储能目标/工作电压窗、温度降额、软启动斜率，以及 PI 系数或分段曲线。范围必须来自已验证值。新增参数包括 BUS 电阻软件泄放动作/释放门限、功率上限、温度降额和正常能量预算。DRV8161 故障关断、电流快速保护、驱动 UVLO、保险和单体额定仍由相应硬件/器件边界约束；本版不保留独立硬件 BUS_OV dump。

| 首版预置策略 | 请求与条件 |
|---|---|
| 电压死区缓冲 | 以 e=Vref−Vbus 为例；e>ΔV 时 BUS 偏低，请求 SC 向 BUS 放电；e<−ΔV 时 BUS 偏高，请求 BUS 向 SC 充电；死区内不额外补偿 |
| 可信功率差额补偿 | 只有 BMS 可用功率和负载功率数据都有效时才补差；不能只凭 BUS 电压推断电池功率缺口 |
| 受控储能恢复 | 根据逐节电压、目标储能、温度、电池可用功率和硬限值逐步恢复；主充电受最高单体限制 |
| 待机 | 清除远程/常规功率请求；仍运行 BUS ADC/NTC 监测并按本地预置过压策略控制软件 dump，保留 SC 总压比较和驱动故障关断。无独立 BUS_OV dump 兜底 |

所有策略请求先经过 SC 单节/总压、温度、超容工作窗、MCU 测得的 BUS 状态和可用功率限值执行层。正常制动回馈优先由电池与超容按各自允许功率和剩余吸收余量吸收，未能吸收的剩余回馈再由软件 dump 处理。当经资格的电池、超容及其他吸收路径总额度不足以承接回馈时，通过 CAN 请求 FOC 限制剩余回馈；缺失、无效或过期额度按0处理。满充、温度、测量故障、供电故障及路径退出都可能造成能力不足，不要求电池和超容同时接近满充。整车总额度须先分配至两块FOC，分配之和不能超过总量；不把SC的1 kW/1 s设计目标直接设为每板可用额度。该请求属于协调策略，不承担快速保护。正常工作限制为 SC 电压低于 BUS；两端电压交叉时须按经验证的停变换和隔离顺序处理，不将预置策略扩展为跨压连续控制。

## 本地实现与通信边界

核心板上的 STM32G431CBU6 使用 TIM1 互补 PWM（PA8/PB13）驱动 DRV8161，另用 PB7/TIM4_CH2/AF2 输出独立 MCU_DUMP_PWM，直接控制 UCC27511A IN+；UCC IN−接 GND，PB7 外部下拉、串联电阻值待定。GPIO 按核心板名称映射，不使用裸芯片封装脚号；CAN RX=PA11、TX=PA12（AF9），SWD 用 PA13/PA14 下载与调试，PB8/PB9 不用且不改 BOOT 按键/option bytes。PA11/PA12 与 USB 数据复用，CAN 连线时不同时连接 USB 数据线。桥臂选 2-pin PWM 及硬件死区。PWM 频率、采样同步、限流策略和交越停机时序待确定。DRV8161 的 2-pin 模式在 INH/INL 同为低或同为高时都关闭两路栅极输出，并带防直通；Independent PWM 会旁路防直通，本方案不选用。P-MOS 由 PB6 独立控制，不能和 PWM 关断同时硬切电感回路。

功率/电流闭环由 G431 本地周期执行；CAN 只用于成组参数下发、选策略、回报状态及拒绝原因，不承担快速保护，也不接收运行时代码。参数组需校验版本、CRC、单位、范围和相互约束，并回 ACK。参数先在 RAM 应用；只有收到明确保存请求才写现有 MCU Flash，避免频繁擦写，不新增 EEPROM。参数生效采用斜率限制或无扰切换；需停机更改的类别待定义。

掉电或参数损坏时恢复已验证默认组或最近有效组；CAN 失联时清除远程请求，若本地 BUS ADC/NTC 有效则按预置过压/降额策略处理；测量无效时撤销常规功率请求并告警。IWDG 仅在新鲜逐节数据、有效电流/温度读数和保护条件通过时喂狗。BUS 泄放没有独立硬件过压触发；MCU/ADC/定时器故障、GPIO 卡高或 PWM 卡滞可能导致无泄放或持续泄放，IWDG 不保证覆盖这些故障。

## 尚未闭合

BUS 由电池直接供电，Vref 仅供瞬态缓冲/能量分配，不能保证任意恒压。软件电流/功率请求到 DRV8161 CSA、G431 ADC/COMP 与 PWM 的映射、双向零点/符号、量程、调制和环路稳定性待联合定型；CSA 可观测电流不等于已实现双向硬限流。低压初充（包括从0 V开始）属于正常受控充电流程，不是修复/激活，也不是用户提出的额外自动恢复功能。优先评估现有双向DC/DC实施受控限流充电，逐节测量和过压保护仍必需。现AFE/驱动从0 V上电后的测量、自举、最小脉宽及门控尚未证明，资格闭合前禁止未经验证的自动PWM。外部限流电源仅作为装配/台架调试手段，不是用户指定的日常使用条件；本轮不增加独立恢复功能/模块，正常充电实现待原理核准。

软件正常 dump 估算可用 Pavg≈D×Vbus²/R，仅近似电阻导通损耗；没有新增电流采样，不承诺精确恒功率。策略应协调电池与超容的吸收额度，避免正常支撑和 dump 同时耗能；dump 降额或关闭时须重算系统可用吸收余量，任何有效吸收额度不足时均通过 CAN 请求 FOC 限制剩余回馈，缺失、无效或过期额度按0处理。BUS 软件门限和电阻热设计未定。软件功能、代码、控制频率、掉电恢复、预置策略切换及硬软件联合验证均未完成；所有功率能力均保持候选状态。
