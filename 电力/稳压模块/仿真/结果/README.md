# 稳压模块仿真结果

本目录保存模型运行的结构化输出。结果须和对应源码、输入、绑定哈希及资格门一起阅读；历史候选结果不作为当前方案性能或硬件验收结论。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [12至16颗数量筛选.json](12至16颗数量筛选.json) | 记录当时的超级电容数量候选筛选；16 颗/8S2P 已取消，当前方案不引用该结果作为资格结论。 |
| [增容筛选.json](增容筛选.json) | 增容与功率窗模型输出，所对应候选已取消，仅供历史计算复核。 |
| [AFE保护边界验证.json](AFE保护边界验证.json) | AFE/逐节保护边界模型输出，使用时须按其输入与报告核验适用范围。 |
