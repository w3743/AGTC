# 稳压模块仿真源码

本目录及其 `V1.6-BUSFIX/` 子目录保存用于复算稳压模块设计问题的 Python 源码。脚本结果不等同于原理图、功率级或实物验证。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [增容筛选.py](增容筛选.py) | 计算超级电容数量/工作窗候选的能量与功率筛选；包含的 16 颗候选已取消，相关结果只作历史计算。 |
| [AFE保护边界验证.py](AFE保护边界验证.py) | 对 AFE/逐节保护相关输入作模型检查；结果须与对应输入 JSON 及报告一起解释。 |

当前 BUSFIX 逐节保护模型见 [V1.6-BUSFIX/](V1.6-BUSFIX/README.md)。模型输入及旧源快照由上级 `输入/` 保存，模型结果由上级 `结果/` 保存。
