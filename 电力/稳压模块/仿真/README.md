# 稳压模块仿真材料

本目录将计算源码、模型输入和结果分开保存。部分目录内容对应已取消的增容候选或历史模型；当前方案固定为 8 颗、8S1P，不能将旧模型结果写成当前硬件通过。

## 子目录

| 目录 | 用途 |
|---|---|
| [源码/](源码/README.md) | 保存稳压模块的计算与保护边界模型脚本。当前 BUSFIX 逐节保护模型位于 `源码/V1.6-BUSFIX/`。 |
| [输入/](输入/README.md) | 保存模型参数和输入源快照；`V1.6-BUSFIX/source_snapshot/` 是该次模型使用的冻结输入副本，仅供追溯，不是当前原生工程入口。 |
| [结果/](结果/README.md) | 保存模型运行输出 JSON；结果必须结合对应输入、源码、报告和资格门状态阅读，不能替代电路、硬件或实测验收。 |

## 本目录直接文件

本目录不含直接文件；模型内容按上表分置于 `源码/`、`输入/` 和 `结果/`。
