# 稳压模块原理图辅助工具

本目录保存针对稳压模块原理图的读取、器件/库查询、候选测试和整改脚本。许多脚本绑定指定 EDA 页面并会写入当前会话或输出证据；运行前应检查代码中的页面 ID、执行开关、输入路径和保存行为。模块当前工程与结论以[模块 README](../README.md)为准。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [读取当前.js](读取当前.js) | 读取并输出当前 EDA 项目/指定原理图页面信息。 |
| [读取关键引脚.js](读取关键引脚.js) | 读取原理图中选定器件的关键引脚信息。 |
| [读取全部现存引脚.js](读取全部现存引脚.js) | 读取当前页面各器件的现存引脚号、坐标和未连接标记。 |
| [读取AFE新增前关键引脚.js](读取AFE新增前关键引脚.js) | 读取 AFE 方案添加前的关键引脚基线。 |
| [查询新增库.js](查询新增库.js) | 查询新增候选器件的库条目。 |
| [查询整改器件.js](查询整改器件.js) | 查询指定整改页面、项目和器件信息。 |
| [查询BQ和电容.js](查询BQ和电容.js) | 查询 BQ 与电容候选的库条目。 |
| [查询4u7电容.js](查询4u7电容.js) | 搜索指定容值/型号的电容库候选。 |
| [测试端口几何.js](测试端口几何.js) | 在指定页面创建临时网络端口以检查端口几何 API 行为，会改变活动会话。 |
| [测试BQ符号.js](测试BQ符号.js) | 在指定页面放置 BQ 器件以检查符号创建行为，会改变活动会话。 |
| [测试GND标识.js](测试GND标识.js) | 在指定页面创建 GND 标志以检查 API 行为，会改变活动会话。 |
| [待审AFE方案.json](待审AFE方案.json) | 保存一份标为待审、尚未实施的 8S1P AFE 候选方案输入。 |
| [待审AFE批次0_库搜索.js](待审AFE批次0_库搜索.js) | 读取候选 AFE/器件库搜索结果；脚本注释标为只读。 |
| [待审AFE批次1_精确删除旧采样.js](待审AFE批次1_精确删除旧采样.js) | 旧采样移除的 dry-run 批次模板；`EXECUTE` 默认为 `false`，不能视为已实施更改。 |
| [待审AFE批次2_精确排针与RAW端口.js](待审AFE批次2_精确排针与RAW端口.js) | 排针/RAW 端口候选批次模板，须符合文件注释前置条件，默认不执行。 |
| [待审AFE批次3_完整搜索项临时pin探测.js](待审AFE批次3_完整搜索项临时pin探测.js) | 禁用的临时器件引脚探测模板；默认不执行，文件注释要求先审查。 |
| [整改批次1-清理旧采样与接口.js](整改批次1-清理旧采样与接口.js) | 作废脚本；文件以 `throw` 阻止运行，并明确标记禁止执行。 |
| [全图原理复核.py](全图原理复核.py) | 按当前 ENET 和设计合同进行离线逐脚/功能复核并保存审查结果。 |
| [整改EDA.py](整改EDA.py) | 官方 EDA CLI 整改适配器，会执行传入 API 操作并保存返回证据。 |
| [恢复整改基线.py](恢复整改基线.py) | 按本轮记录恢复整改前的原生文件；会写文件，仅在确认目标文件和备份基线后使用。 |
