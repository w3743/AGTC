# 跨板统一审查记录

本目录保存跨模块原理图审查、跨板并料复核、全库同步检查和执行记录。当前摘要以 [审查结论.md](审查结论.md) 为入口，源哈希和覆盖范围以相应机器记录为准。历史备份、候选源及命令输出仅用于追溯，不替代模块当前源。

## 本目录直接文件

| 文件或文件族 | 用途与边界 |
|---|---|
| [审查结论.md](审查结论.md) | 汇总电力模块统一审查范围、当前入口和开放边界。 |
| [电驱原理可实现性审查.md](电驱原理可实现性审查.md) | 记录电驱原理可实现性层面的审查意见。 |
| [稳压_SC隔离_A_B_只读比较.md](稳压_SC隔离_A_B_只读比较.md) | 保存稳压/超容隔离候选的只读比较记录。 |
| [跨板并料复核.json](跨板并料复核.json) | 记录跨板并料后各模块源、BOM、网表和检查数据的绑定。 |
| [全部原理图检查覆盖.json](全部原理图检查覆盖.json) | 记录各现行原理图的检查覆盖范围。 |
| [全库同步与只读校验.json](全库同步与只读校验.json) | 保存原理图器件库同步及只读一致性检查摘要。 |
| [inventory.json](inventory.json) | 记录本轮文件盘点范围及文件分类。 |

| `BMS_跨板并料_CAD_BOM.csv`、`FOC_跨板并料_CAD_BOM.csv`、`PUMP_跨板并料_CAD_BOM.csv`、`REG_跨板并料_CAD_BOM.csv` | 保存跨板并料所用的各模块 CAD/BOM 对照表。 |

| `FOC_当前原理图连接_改动前.json`、`FOC_当前原理图连接_MMBT候选_替换前.json` | 保存 FOC 原理图连接的修改前/候选前读回快照。 |

| `最终覆盖刷新首轮错误.txt`、`最终覆盖刷新执行记录.json`、`最终覆盖刷新最终输出.txt`、`最终覆盖刷新最终输出错误.txt`、`最终覆盖刷新最终预览.txt`、`最终覆盖刷新最终预览错误.txt` | 覆盖刷新脚本的首次错误、执行记录、最终预览/输出及错误流日志。 |
