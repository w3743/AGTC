## 首版制动与低压启动审阅证据

本轮目标为平地 15 km/h 自制动请求至停稳 3 m，先处理双拒充，同时核对启动到 15 km/h 的低压补能。建扭延时计入总距离。以下证据为 **HOLD** 审阅材料，候选与 `main` 的历史发布图分列。所有电路、联合与热资格闭合后才交人工 PCB。 [整车要求](../基本设计.md#首版平地制动和低压启动审阅)

- [独立硬门槛](联合仿真/双拒充硬门槛核算.json)及[源码](联合仿真/双拒充硬门槛核算.py)。50 ms 建扭比较约需 389 W 初峰。143.6 kΩ 对照的静态开阈 38.164–38.738 V，最低释放角到 37.8 V 的零回生比较窗约 96 µs。参考启动、失电反灌和实体时序仍待闭合。
- [中央早泄放头 1 ms ngspice 结果](联合仿真/双拒充泄放电路复跑.json)及[源码](联合仿真/双拒充泄放电路复跑.py)。390 W、38.50 V、1 Ω／40 µH、理想有效开通 30 µs 时，BUS 约 38.534 V，线束峰流约 28.28 A。比较不计实际开关尖峰、门驱电平与热。
- [起步及停车敏感性](联合仿真/起步停车与下坡包络.json)及[源码](联合仿真/起步停车与下坡包络.py)。旧 1 s 和仅制动段距离用于比较，首版验收以整车要求为准。
- 22.5 V 下，电池按 100 A 比较时，双机全峰值缺 1350 W，超出本模型的 80 A 峰值角。电池按 130 A 候选，缺口 675 W。以超容每节 2.0 V 静置、35 F／44.8 mΩ 整组寿命角、12.8 µH／20 kHz 及 95% 效率，恒补约 1.55 s 触及 80 A 峰值比较线。两档电池、80 A 与 95% 均为筛查量，实际全启动时长仍取决于负载与热态动力。 [低压供电时域结果](联合仿真/起步停车与下坡包络.json)
- [低压补能与停车共用窗口](联合仿真/低压启动补能复核.json)及[源码](联合仿真/低压启动补能复核.py)。计充放电 ESR 与纹波后，从 2.0 V／节起约 1.53 s 碰到峰值比较线。在 50 ms 建扭且只给超容吸能的敏感性中，1.0 s 全峰值后的 3 m 制动存在 2.15–2.20 V／节起始窗口，10 mV 网格从 1.39 s 起未找到共同窗口。该筛查用于权衡既有 8S1P 的电流和余量，独立中央吸能资格以及实体牵引与热仍待证。随附结果绑定本地集成设计和厂商资料。
- [各板联合行为结果](联合仿真/联合行为模型结果.json)及[复跑入口](联合仿真/联合行为模型.mjs)。按 50 ms 建扭比较，从产生制动扭矩算起约 6.5 ms 越过母线比较线，约 13.6 ms 才触发旧硬泄放。随附 JSON 是本地集成图纸哈希匹配时的快照。审阅分支沿用 GitHub 主分支的历史图作为发布基线，单独重跑时会显示源差异，不能把该差异用作新图验收。
- [双拒充整段结果](联合仿真/15kmh_3m_双拒充早泄放结果.json)及[独立复跑入口](联合仿真/15kmh_3m_双拒充早泄放.mjs)。八组建扭延时／外部源敏感性中，LPV 与 CORE 保持有效且给定 PB0／PB7 时序时，BUS 最高约 38.54 V。LPV／CORE 撤销时仅旧硬后备可用，仍无法证明 3 m。中央 12 V 失电后的车体停车与实际回灌未关闭。 [波形](联合仿真/15kmh_3m_双拒充PB0_PB7_100ms_30W波形.csv)
- [AO3400A 隔离原生换料图](../稳压模块/检查/候选_AO3400A软件泄放对照/sc-regulator/sc-regulator.eprj3)及[官方重开差异](../稳压模块/检查/候选_AO3400A软件泄放对照/官方重开与逐针差异.json)。以本地 R1 为源，三个换料、器件总数仍为 224。官方 0 错误、133 条既有告警。原理图候选保持 HOLD，动态、热和局部图面资格待证；LPV 或 CORE 失效时软件支路不参与接管。

在仓库根以 `python -X utf8` 运行对应源码即可重建 JSON。Windows ngspice 复跑使用 Git LFS 中的 `ngspice_con.exe`。 [独立反馈早泄放概念图](../稳压模块/检查/候选_精密比较器接管/独立反馈早泄放_隔离概念.svg)

运行`python -X utf8 -B 电力/.agents/tools/统一目录说明.py`可只读核对每板是否仅保留两份现行设计文档；该工具已停止旧的README/TODO生成行为。

### 双拒充叠加断电复跑

- [各板联合断电模型](联合仿真/双拒充叠加断电联合仿真.mjs)、[输入](联合仿真/双拒充叠加断电联合仿真输入.json)和[结果](联合仿真/双拒充叠加断电联合仿真结果.json)。在仓库根用 `node 电力/检查/联合仿真/双拒充叠加断电联合仿真.mjs` 复跑。19,440 组参数组合覆盖 BMS 主路与旧供电撤销顺序、下游母线、辅助负载及退出、单/双 FOC 候选扭矩、失电和过压保护。22.5 V 同时断电、FOC 欠压取 18 V 的对照中，70 W 负载保留时约 69 ms 先到欠压。若 50 ms 内把辅助降到 5 W、两块 FOC 在 100 ms 内建立所设扭矩，则条件停距约 3.00 m、移动时母线约 19.09–38.80 V。该点没有停距余量，实际设计尚无可分配的失电制动扭矩，维持 HOLD。
- [器件级候选图](../稳压模块/检查/候选_母线自供电硬件接管/双域隔离_保留旧GUARD_器件候选.svg)及[针网和增量](../稳压模块/检查/候选_母线自供电硬件接管/双域隔离_针网与净增.json)。复用原功率器件，保留旧请求的 GUARD，原生工程、启动安全及全温时序待证。旧直接绕过 GUARD 的图已否决。
- [低压起步轨迹](联合仿真/低压起步接管.py)及[结果](联合仿真/低压起步接管.json)。分别记录原生 9S4P、9S5P/130 A 候选和当前 FOC 30 V 软件下限。无超容限功率比较仍缺电机、整车与热态电池输入。

- [FOC 两板本地保持电路筛查](联合仿真/FOC本地保持电路筛查.json)及[源码](联合仿真/FOC本地保持电路筛查.py)。24 组比较覆盖共享许可撤销、A 板保持 B 板撤销、双板保持、复位与 GPIO 卡高。现有 Buck 保持路径的器件级筛查为 HOLD。
- [单光耦减件候选](../稳压模块/检查/候选_母线自供电硬件接管/单光耦_三输入门_器件候选.svg)及[本地 Buck 保持图](../稳压模块/检查/候选_母线自供电硬件接管/FOC保持支路_器件候选.svg)。减件清单与每项必要性的证据在各板设计细节。当前均为隔离候选。
