# 三板授权修复、仿真复查与元器件精简评估

> 本页保留上一轮解析修复与仿真复查基线。继续修复后的当前模型、DRC和共用限制见[最新复查结论](../未通过项修复/本轮结论.md)；本页旧风扇和模型结果不代表后续设计已验证。

2026-10-15，范围为当前已保存的BMS、FOC驱动、稳压三块原理图及各自现行BOM。已修复可确认的解析和检查程序错误，重新执行官方只读DRC、模型复算和共用选型筛查。三板原生页与正式BOM本轮未改；没有新增批准的器件替换或保护功能删除。

## 已修复并验证

1. **中央库误继承采购身份**：实例明确留空的MPN、供应商、供应料号及Value现在保持为空；只有缺少字段时继承载体默认。Symbol/Footprint空值按CAD结构规则回退，防止错误丢失绑定。FOC的J_BRAKE_R本来就是PCB=no的外部SB50组件，XH只是CAD载体，先前误报已撤回。见[修复说明](解析属性覆盖修复说明.md)及[回归证据](解析属性覆盖回归.json)。
2. **采购CSV空料号导出错误**：支持原生MPN为null，CSV留空；写入改为临时文件原子替换，模拟替换失败时旧文件完整保留。见[回归证据](采购补充空MPN回归.json)。
3. **BMS保护精简检查使用旧风扇拓扑**：移除对已退出的U_FAN_SW/R_FAN_ILIM仍须存在的过时断言，改为核对当前四线风扇直供网络、已删除项缺席、现行BOM/网表哈希、控制和故障恢复策略。独立支路限流已移除这一事实及首板短路/温升/恢复要求仍明确保留。
4. **FOC汇总脚本依赖缺失旧模型结果**：三个当前开关级工况仍为必需输入；无效的旧即时PWM前馈模型结果改为可选历史对照，不伪造旧结果，不更改当前工况的通过阈值。

修改前材料先保全为副本，再追加至对应模块的历史与调试ZIP并按SHA256读回核验；本轮模型在隔离副本运行，关键结果保存于各模块检查目录。BMS既存ZIP另有9个成员的本地头与目录索引路径分隔符不一致，已保全原包并只修复18个分隔符字节；1184个原成员的内容SHA256、CRC与大小全部不变，追加后1187项通过标准ZIP检查。见[BMS归档修复与追加核验](../../../BMS模块/归档/历史与调试.zip)（历史成员：`20261016_目录整理/BMS模块/检查/三板共用修复/仿真复查证据/归档修复与追加核验.json`）及[FOC归档读回核验](../../../FOC驱动模块/检查/三板共用修复/仿真复查证据/归档读回核验.json)。

## 精简与共用评估

完整[可能共用型号表](../../索引/可能共用型号.md)列出18组：8组芯片、高价值器件或连接器方向，以及10组阻容补充筛查，保留全部位号、数量、厂家差异和资格条件。先满足电气、封装、机械与保护边界，再优先国产，并比较实际单价、MOQ、供货与验证成本。缺价均标待询价，没有声称已节约金额。

- **先看N01驱动器、N02核心板排母**：N01单向换成UCC27511ADBVR有TI兼容说明、逐针网络、SAFE_5V默认态及DBV焊盘对照支持，可减少1种MPN；真实驱动器模型尚未在项目ngspice运行，正式换绑和同档报价未完成，仍是强候选。见[N01专项核对](N01单向替代核对.json)。N02还缺完整机械图和实物互配证据。
- **N04国产主MOS潜在价值高**：华羿与现FOC料的最大导通电阻、动态特性及原生焊盘组织不同，必须重算损耗/热/SOA并逐针核网，不能直接统一。
- **阻容优先沿用已采用的国产精确型号**：风华、毫欧等方向均列明用途、耐压、容差、偏压容量及保护误差门槛；不能仅凭标称值或0603封装合并。
- **BMS光耦资格仍开放**：实际VO617A-2X007T与VO617A-4载体的CTR等级不同，按实际-2料核最坏LED电流、温度及外部负载，不能套用-4的CTR下限。

现中央库522个实例、197个保守身份（包含缺厂家/缺MPN按位号独立保留的条目，不能称197种采购MPN）；405份当前引用原生资产；采购511行中463行与原生关联、48行仅在采购补充中。已有5组严格跨板同型号身份；另5组同名MPN存在厂家字段差异，别名和真实多厂家供货分开核对。没有因精简而额外删保护。
