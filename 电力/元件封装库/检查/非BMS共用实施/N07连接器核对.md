# N07 三芯 CAN 连接器核对

**结论：** FOC 与稳压统一为 JST `B3B-XH-A(LF)(SN)`，FOC `J_CAN` 已由官方 API 保存并独立重开核验。FOC 的三脚网络作完整循环调整，线束定义为 1=GND_SYS、2=CANH_CONN、3=CANL_CONN。此结论只覆盖原理图/器件绑定与静态封装数据，不构成 PCB 或实物线束资格。

## 选型与线束定义

- FOC 与稳压均用精确型号 `B3B-XH-A(LF)(SN)`，制造商 JST，供应商料号 C144394。FOC 旧件为 `XY-XH2.54-3A11-R`；未找到该旧型号可与 JST XH 线端组件互插的原厂证明，不按“XH”字样相同推定兼容。
- 线端建议使用 JST `XHP-3` 三芯壳与三只 `SXH-001T-P0.6` 压接端子。建议线束两端直通：腔位1↔1 GND_SYS、2↔2 CANH_CONN、3↔3 CANL_CONN。具体线色、线规和出线方向尚未指定；线束图应标清腔位编号、对插面视图、锁扣/键位朝向和压接工具。
- JST手册给出的该端子线规为 AWG28–22（0.08–0.33 mm²），绝缘外径0.9–1.9 mm。最终线规应按线束长度、电气要求与压接工艺决定。优先普通 `SXH-001T-P0.6`；JST说明低插入力版本 `SXH-001T-P0.6N` 的抗振性较低。
- 目前没有证据证明国产方案完整兼容该壳体、端子、锁扣和键位，也没有可核验的价格/MOQ比较。当前 JST 统一方案是可落地的精确系统方案；国产或更低价替代须先提供完整配对尺寸及电气资料。

## 三脚网络与API资产

| 脚号 | FOC旧网络 | FOC当前网络 | 线束定义 |
|---|---|---|---|
| 1 | CANH_CONN | GND_SYS | GND_SYS ↔ GND_SYS |
| 2 | CANL_CONN | CANH_CONN | CANH_CONN ↔ CANH_CONN |
| 3 | GND_SYS | CANL_CONN | CANL_CONN ↔ CANL_CONN |

这是三循环，1、2、3脚都变更，不能只把1脚与3脚对调。正式实施记录覆盖474个引脚，其中仅上述三脚不同，其余引脚全部相等。FOC官方重开读回中 `J_CAN` 保留原生 uniqueId `gge217`，元件ID `1f8d013033343c0b`；symbol `8b65df20ae2c4f84`、device `178750ef1ee79890`、footprint `a1cadde5aff48cef`。源封装资产UUID为 `9054811df59a44d793d623424f169ff2`，JST源device UUID为 `6e805ec5cb864bd19e328ebbf2e17903`。所在页UUID `90aa6c46493624cf`，位号 `J_CAN`。

FOC `J_CAN` API 引脚锚点为1=(3070,1490)、2=(3070,1480)、3=(3070,1470)。稳压 `J_CAN` 当前索引实例同样绑定精确MPN及供应商料号C144394；当前索引的FOOTPRINT/DEVICE/SYMBOL ID与FOC本地ID可能因库实例而不同，应以各板实例记录为准。

## 封装与尺寸核对

JST官方XH资料给出2.5 mm pitch；三芯及以上顶部插入型焊盘图参考孔径为Ø0.9 +0.1/−0 mm、孔距2.5±0.05 mm，图样从连接器安装面观察。JST说明孔径是参考值，应结合PCB材料和钻孔方式确定，硬质玻纤板可能需要增大孔径。

| FOC封装 | 孔中心 | 通孔 | 铜焊盘外径 |
|---|---:|---:|---:|
| 旧 XY footprint `ed28599d6a167c90` | −98.425 / 0 / +98.425 mil | 35.434 mil ≈ 0.900 mm | 60 mil = 1.524 mm |
| 新 JST footprint `a1cadde5aff48cef` | −98.425 / 0 / +98.425 mil | 35.434 mil ≈ 0.900 mm | 61.024 mil ≈ 1.550 mm |

新孔径等于JST参考推荐值的下限，孔距与推荐值名义相同；旧、新封装的孔径/孔距没有发现静态尺寸冲突。两者铜环外径相差约0.026 mm。该比较不能证明板边净空、器件高度、实际钻孔偏差、焊接或插拔可靠性。FOC PCB在正式记录中保持原SHA，本轮未修改布局；PCB所有者仍须核对更新后的封装、焊盘编号/网络和实际板厂规则。
