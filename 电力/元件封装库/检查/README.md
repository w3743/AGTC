# 共用元件库检查入口

本目录汇集来源同步、共用器件候选、库包索引、跨板数量/成本和旧共享库整理的核对记录。当前库状态以[同步证据.json](同步证据.json)绑定的来源/哈希为入口；每份报告只覆盖自身记录的工程、BOM、器件身份和时间。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [同步证据.json](同步证据.json) | 记录从显式来源读取的当前工程/器件资产同步范围和哈希。 |
| [包索引.json](包索引.json) | 机器可读的 EasyEDA 库包来源、哈希、CRC 与包内对象索引。 |
| [包索引.csv](包索引.csv) | 包索引的表格视图。 |
| [被动件共用核对.md](被动件共用核对.md) | 说明跨板被动件共用候选与核对结论/未决项。 |
| [被动件共用核对.json](被动件共用核对.json) | 被动件核对的结构化记录。 |
| [有源与连接器共用核对.md](有源与连接器共用核对.md) | 说明有源器件和连接器跨板共用候选/边界。 |
| [有源与连接器共用核对.json](有源与连接器共用核对.json) | 有源器件和连接器核对的结构化记录。 |
| [三板基线与板外核对.md](三板基线与板外核对.md) | 汇总三板原生器件基线与板外采购物项的核对边界。 |
| [三板基线与板外核对.json](三板基线与板外核对.json) | 上述基线和板外物项记录的结构化版本。 |
| [三板共用覆盖验证.json](三板共用覆盖验证.json) | 记录三板共用器件候选的覆盖检查。 |
| [三板共用选型候选.json](三板共用选型候选.json) | 保存三板共用选型候选和来源状态。 |
| [四板复用与成本核对.json](四板复用与成本核对.json) | 记录四板复用关系及成本核对输入/结果。 |
| [共享仓库清理.json](共享仓库清理.json) | 记录旧共享仓库迁移/清理过程，不代表当前器件库内容。 |
| [共享仓库发布.json](共享仓库发布.json) | 记录旧共享仓库兼容发布过程。 |
| [缓存归档.json](缓存归档.json) | 记录缓存/归档整理操作及文件清单。 |
| [稳压BOM精确恢复.json](稳压BOM精确恢复.json) | 记录稳压模块 BOM 恢复核对。 |
| [协作状态.json](协作状态.json) | 保存当时跨文件协作/实施状态记录。 |

## 子目录

| 目录 | 内容 |
|---|---|
| [商城核价/](商城核价/README.md) | 按模块归档的商城报价核对输入；下级 `已核价批次/` 保存报价批次快照，须按记录时间核实适用性。 |
| `非BMS共用实施/` | 非 BMS 模块共用器件变更的实施、读回和交付证据；保留过程级文件。 |
| `三板共用修复/` | 三板共用修改及其读回核对记录。 |
| `未通过项修复/` | 未通过候选及其修正/复查过程记录。 |

三个实施/修复子目录内的逐次机器快照仅对其记录的步骤负责；当前器件身份以库根配置、索引和同步证据为准。
