# 分模块商城核价记录

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [BMS.json](BMS.json) | 保存 BMS 模块相关商城商品/报价核对输入。 |
| [FOC.json](FOC.json) | 保存 FOC 模块相关商城商品/报价核对输入。 |
| [水泵.json](水泵.json) | 保存水泵模块相关商城商品/报价核对输入。 |
| [稳压.json](稳压.json) | 保存稳压模块相关商城商品/报价核对输入。 |

这些文件是带来源/观察时间的报价核对记录，采购成本结果还需以共用库的报价输入、精确制造商/MPN/商品号匹配及 MOQ 字段为准。

## 子目录

| 目录 | 内容 |
|---|---|
| `已核价批次/` | 按批次编号保存历史报价核对数据；不自动覆盖本目录的当前输入。 |
