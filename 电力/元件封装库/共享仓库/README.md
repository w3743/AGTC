# 历史共享库兼容快照与元件资料

本目录保留旧公共导出的器件索引、原生资产快照、厂商资料和封装导入候选。它现作为AGTC项目中的普通数据目录，用于兼容既有验收和追溯；不是独立Git仓库，也不再独立提交或推送。原独立仓库的Git元数据已移到项目根`.git/legacy-component-git/`以便恢复。

## 快照内容

- [当前型号与原生资产](库/当前型号与原生资产.json)：旧导出时的194个按制造商与完整MPN保守区分的器件身份，引用405份原生资产；另列当时记录的原生BOM之外采购型号及候选状态。当前状态以中央[来源配置](../来源配置.json)、[元件总表](../索引/元件总表.json)和同步证据为准。
- `库/原生片段/`：旧导出的器件、符号与封装内容，文件名为内容SHA256。JSONL片段用于精确追溯，不能直接当作独立可导入库包；当前资产入口在上级目录的`../原生片段/`。
- `库/元器件目录.json`、`库/元器件目录.csv`、`库/封装补充依据.json`、`库/型号封装关联.json`及`数据手册/索引.json`：按当时型号引用筛选的历史补充证据，与当前原生资产状态分开。
- `库/可导入封装库.zip`、`库/嘉立创库数据.zip`及`数据手册/`：保留导入材料和厂商资料。ZIP成员保留原字节，关联记录保留原SHA256。

## 复用规则

满足各板电气、封装及机械要求后优先统一精确型号；新差异先登记候选，核对通过再替换。相同封装名、相同数值或相近型号不能作为等效证明。共用候选优先考虑国产，同时接受经核对的低价方案，比较到手单价、MOQ、供货和验证成本。未核实的厂家属性或价格明确标待核实/待询价。

实际采用MPN与CAD载体MPN分别记录；`target_differs_from_carrier`为真时，载体符号、焊盘或参数不得直接视为目标器件已验证。同一MPN若制造商字段不同或缺失，保守保留独立身份。不同UUID或不同内容的资产不按名字合并。

数据手册、供应商原始数据和封装候选用于查证。其存在不表示器件选型、电气功能、机械装配或实物验收通过；厂商资料的权利和适用条件归原来源。本次筛选未取得新的价格或国产来源证明。

## 维护

当前唯一维护入口为上级[来源配置](../来源配置.json)和[同步全部](../工具/同步全部.py)，从已保存原生工程与现行BOM更新中央索引，并以只读检查核验源SHA256和引用覆盖。旧导出工具仍保留在上级`../工具/`，供既有门禁命令及历史证据按需复核；日常同步不更新本快照，也不以此目录执行单独发布。

原Layout准入核验的只读命令仍依赖本目录内的快照以及上级旧导出工具，所以保留原路径和资料。历史清理与发布证据见上级`../检查/共享仓库清理.json`和`../检查/共享仓库发布.json`。

历史版本中的封装图和模型集合不代表本分支当前采用状态；当前以准确型号索引、资产内容与保留的来源证据为准。
