# 共用元件索引

本目录保存由当前电力模块原生工程、采购补充和报价输入整理出的索引文件，以及人工维护的复用/选型说明。主入口与生成规则见[元件封装库说明](../README.md)。派生文件通过 `工具/` 中的更新脚本刷新，不应绕过来源配置手工改写。

## 本目录直接文件

| 文件 | 用途 |
|---|---|
| [元件总表.json](元件总表.json) | 机器可读的原生器件身份、来源及工程绑定总表。 |
| [元件总表.csv](元件总表.csv) | 元件总表的表格化版本，便于查看和筛选。 |
| [板级用量.csv](板级用量.csv) | 按模块/板统计原生工程中的器件位号与用量。 |
| [采购补充.json](采购补充.json) | 采购 BOM 关联、板外物项和来源字段差异的结构化记录。 |
| [采购补充.csv](采购补充.csv) | 采购补充记录的表格视图。 |
| [项目器件主档.json](项目器件主档.json) | 机器可读的整车器件主档，将原生器件实例与采购/补充项目关联。 |
| [项目器件主档.md](项目器件主档.md) | 整车器件主档的可读摘要。 |
| [商城商品映射.json](商城商品映射.json) | 保存报价输入中商品身份与器件条目的映射资料。 |
| [商城成本.json](商城成本.json) | 保存按当前 BOM 和报价输入计算的采购成本情景结果。 |
| [当前商城成本.md](当前商城成本.md) | 以人可读形式说明当前成本情景与报价限制。 |
| [全项目元件目录.md](全项目元件目录.md) | 汇总电力项目器件目录及其来源/分类入口。 |
| [可能共用型号.md](可能共用型号.md) | 列出可供跨板核对的共用型号候选及状态边界。 |
| [复用与待核对.md](复用与待核对.md) | 记录当前复用关系、差异与待核对事项。 |

报价和采购数据按文件中的身份、MOQ、来源和时间字段解释；候选映射或成本情景不等同于已采购。
