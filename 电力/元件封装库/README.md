# 全项目共用元件与封装库

本目录统一管理电力项目各板的器件身份、符号、封装、采购补充和复用关系。后续选型先查这里，满足各板电气、机械和成本要求时优先采用已有精确型号。当前覆盖BMS、FOC驱动、稳压模块和水泵驱动模块的原生来源；水泵图页已建立49个板内器件的CAD绑定，另有9个核心板、线束与板外保险等外部选型纳入采购关联。采购MPN与CAD几何载体MPN分别记录，几何载体不代表采购料号替换。

从[全项目元件目录](索引/全项目元件目录.md)开始；查看[现有跨板复用和待核对项](索引/复用与待核对.md)及[可能共用型号表](索引/可能共用型号.md)。

现行采用型号、用量与采购差异以[来源配置](来源配置.json)、[同步证据](检查/同步证据.json)和索引为准。跨板共用候选不等于已经替换或完成电气验证。

FOC电机的唯一选型与输入记录见[N5065 参数证据](../FOC驱动模块/参考资料/电机资料/N5065参数证据.md)；后续FOC工作先读该入口。

BMS当前原生入口为模块根EPRJ3及配套sch，电气与布局准入状态以[BMS当前设计状态](../BMS模块/检查/当前设计状态.md)和[BMS准入核对](../BMS模块/检查/Layout验证/layout-entry-check.json)为准；原生源SHA256、数量和BOM关联以本库最新[同步证据](检查/同步证据.json)为准，不在本页固化历史数值。BMS目标采购身份与4X载体的区别仍须保留，不得按载体采购。`共享仓库/库/当前型号与原生资产.json`是旧公共导出的兼容快照，仅供既有验收与追溯；当前状态以中央索引和同步证据为准。本库一致性检查不替代电气、布局或实物验收。

## 复用与选型

1. 搜索精确制造商、MPN或供应商料号，已有满足要求的器件优先复用。同一完整型号统一登记，板级位号和用量各自关联。

2. 相同封装名不代表同一器件，也不代表焊盘内容相同。普通阻容核对数值、精度、功率、耐压、温漂及偏压后容量；半导体与连接器同时核对引脚、等级、工作范围和机械尺寸。

3. 实际采购MPN与CAD载体MPN分开记录。载体不能替代真实订货号；符号到焊盘的映射、极性或等级未闭合时保留待核对状态。

4. 跨板存在相同型号表示可共用一个器件身份。新用途和新替代仍要满足使用条件，再通过官方API或受支持的库编辑流程更新工程，保存、重开和回读后刷新中央索引。

5. 当前差异先列候选，核对通过才替换。只维护当前入口，历史证据不升级为现行验证。所有模块的原理图后工作由人类完成，包括PCB设计与布局、制造交付、打样、装配、固件实现及实物测试；本库的原理图、选型和成本证据不表示这些工作已完成。

6. 满足各板要求的共用候选优先考虑国产，同时接受经核对的低价方案。比较可核验的到手单价、MOQ、供货与替换验证成本；缺少厂商或报价证据时标待核实/待询价，不把国产身份或低价直接视为等效依据。

7. 商城报价只把商品页明确标注的“最小起订量”记录为 `moq`；价格阶梯首档和包装量/卷量单独记录，不能互相推断。页面未明确MOQ时保留 `null`，成本结果须标明MOQ未知，不把阶梯首档当成可下单数量。

BMS的`L_PSU`、`R_PSU_FB_TOP`已随自设计降压电路退出，`U_FAN_SW`也已删除；现存`U_LOAD_POWER_VALID`的采购目标为VO617A-2X007T，CAD载体为VO617A-4X007T。pin-to-pad 1–4与Vishay SMD-4 Option 7几何核对PASS；CTR、接收器兼容和准确订货仍须核对，不得按4X载体采购，见[当前设计状态](../BMS模块/检查/当前设计状态.md)。稳压模块的超容参考库仍是原库，当前工程已修订负极铜盘，复用时以当前工程的已修订内容核对，机械适配待实物验证。

## 更新与校验

在电力根目录执行：

```powershell
python -B .\元件封装库\工具\同步全部.py
python -B .\元件封装库\工具\同步全部.py --check
```

第一条从已保存工程、现行BOM、现成库包和手工整车补充刷新索引与项目器件主档，不回写板级工程，不修改原库。第二条只读检查来源是否变化、资产、库包和主档覆盖是否完整；非零退出码表示需处理后重同步。关闭或保存相关编辑后同步，未保存的客户端修改不在文件读取范围内。

原生元件总表、采购补充和项目器件主档由脚本生成；`整车器件补充.json`与`商城报价.json`是受来源/观测记录约束的维护输入，不要手改派生主档。来源调整在`来源配置.json`中登记；BMS当前原生源为`BMS模块/sch/Schematic1/P1.esch2`，旧EPRJ2工程已归档且不作为入口。需要增加现成库包时修改`工具/收集现成库.py`的显式来源清单。BMS现行工程为根目录EPRJ3及配套`sch/`；FOC和稳压模块仍在各自`eda工程文件/`中。

数量按各模块单板或单模块列示，FOC未乘整车两板。采购补充保留原始数量和单位，与原生重合的行只关联、不重复计件；BOM独有项保留其候选、板外或条件安装状态。整车级物项和未冻结需求只维护在`整车器件补充.json`，须绑定来源和SHA；未知厂家、MPN或数量留`null`。`项目器件主档.json`由生成器派生，每个原生实例链接一个`part_id`，采购数量原文不加到原生用量，板外候选不伪装为当前已选物料。商城报价由`商城报价.json`提供，每条观测自身须包含已核实厂家、MPN、供应商料号和可追溯页面；主档有来源供应商料号时要求精确一致，来源未登记时只作为`supplier_code_verified_from_quote`补充映射且不覆盖空来源字段。报价阶梯不自动折算成当前单价。

## GitHub与兼容快照

本项目唯一GitHub远端为[AGTC](https://github.com/w3743/AGTC)。电力模块、中央器件索引和资料随项目在同一仓库维护。`共享仓库/`保留旧公共导出的兼容快照与导入资料，现为AGTC内的普通数据目录，不再作为独立Git仓库提交或推送；旧独立仓库的Git元数据可在项目根`.git/legacy-component-git/`恢复。

当前唯一维护入口是[来源配置](来源配置.json)和[同步全部](工具/同步全部.py)。从`电力/`目录运行：

```powershell
python -B .\元件封装库\工具\同步全部.py
python -B .\元件封装库\工具\同步全部.py --check
```

当前原生器件索引见[元件总表](索引/元件总表.json)和[资产索引](资产索引.json)。旧导出工具`导出当前公共库.py`与`整理共享仓库.py`仍保留，供既有验收命令和历史证据按需复核；它们不属于日常更新入口，也不代表发布步骤。原有兼容快照及其[说明](共享仓库/README.md)、[清理记录](检查/共享仓库清理.json)和[历史发布记录](检查/共享仓库发布.json)继续保留以便追溯。
