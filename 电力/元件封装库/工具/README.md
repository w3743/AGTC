# 共用元件库工具

本目录的脚本读取电力项目的现行原生工程、BOM、采购补充和报价资料，用于生成中央索引、链接或只读核对。脚本的输入/输出以源码为准；不会因文件存在而自动证明各工程的电气、机械或采购状态。日常统一入口为 [同步全部.py](同步全部.py)，单独运行其他脚本前先核对其参数与写入范围。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [同步全部.py](同步全部.py) | 依序调用原生库、现成库包、采购补充、整车器件主档和成本数据更新脚本；`--check` 将检查模式传给这些步骤。 |
| [更新元件库.py](更新元件库.py) | 从显式配置的现行原理图导出原生器件清单和可复用资产片段。 |
| [收集现成库.py](收集现成库.py) | 按脚本内显式清单收集 EasyEDA 库归档，并生成包索引；脚本说明其不会改写归档内容。 |
| [更新采购补充.py](更新采购补充.py) | 将当前采购 BOM 和原生器件按模块、位号关联，同时保留板外物项和字段差异。 |
| [更新项目主档.py](更新项目主档.py) | 由原生索引、采购补充、显式整车补充和商城报价生成整车器件主档。 |
| [商城成本.py](商城成本.py) | 根据当前 BOM 和身份核实的报价数据计算采购成本情景；`--check` 只读比较生成物。 |
| [收集商城商品链接.py](收集商城商品链接.py) | 从当前目录收集并核对立创商城商品链接/商品身份；脚本说明不读取价格和库存字段。 |
| [导入商城报价.py](导入商城报价.py) | 验证报价批次并合并进报价输入 JSON；输入的制造商、MPN、供应商商品号须通过身份核对。 |
| [导出当前公共库.py](导出当前公共库.py) | 将当前共用型号和原生库资产导出到指定发布目录，不导出板级位号和原理图；不是日常同步入口。 |
| [整理共享仓库.py](整理共享仓库.py) | 按精确 MPN 证据从历史共享库筛选内容并写入独立目录；用于既有兼容/发布复核，不是当前索引维护入口。 |

脚本的执行说明和当前来源配置见[库说明](../README.md)。只读检查不写回各板工程；会写索引、报价或导出文件的脚本，运行前应确认目标文件和来源版本。
