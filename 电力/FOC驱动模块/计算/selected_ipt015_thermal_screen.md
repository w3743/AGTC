# IPT015N10N5ATMA1 六管桥条件热筛查

本说明只核对已选 Infineon IPT015N10N5ATMA1 六管桥，与旧 IRLB4030 计算分开。可复算脚本：[selected_ipt015_thermal_screen.py](selected_ipt015_thermal_screen.py)；数值输出：[selected_ipt015_thermal_screen.json](selected_ipt015_thermal_screen.json)。运行脚本会重建 JSON 并断言关键结果。

条件：每板 6 只 MOSFET；相电流峰值 Ipk=120 A；开关频率 fsw=20 kHz；标称边沿时间 tr+tf=500 ns。数据表最大 RDS(on)=2 mΩ，条件为 VGS=6 V、ID=75 A、25 °C；乘项目筛查热倍率 2.5，取 Rhot=5 mΩ。2.5 是筛查假设，不是厂家保证值。数据表 RθJC 最大 0.4 °C/W，Tj 最大 175 °C。热筛查假定脉冲起始 Tj≤60 °C、全程壳温 Tc≤60 °C。用户新确认最高环境60 °C；环境与壳温是不同边界，旧数值保留为条件筛查，60 °C环境下的自热、界面与散热器预算尚未完成。

计算式：桥导通 Pcond=1.5×Ipk²×Rhot=108 W；六管桥保守重叠 Psw=(6/π)×VBUS×Ipk×(tr+tf)×fsw；最热单管按全周期 120 A 取 Pcond=Ipk²×Rhot=72 W，并加 Psw,device=VBUS×Ipk/2×(tr+tf)×fsw；条件温升上界 Tj=60 °C+(Pcond,device+Psw,device)×0.4 °C/W；一秒能量 E=P×1 s。

六管桥的 6/π 系数按所有器件正弦电流绝对值重叠求和，是保守上筛；未采用互补换流可能带来的约一半修正。单管导通项也采用全周期峰值电流，作为局部热点上筛，不将损耗平均分摊给六管。
