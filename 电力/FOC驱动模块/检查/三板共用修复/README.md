# FOC 跨板共用与电流环复查

本目录保留FOC跨板共用修改后的模型复查、DRC/网表证据和电流环限幅筛查。当前可读报告入口为[仿真复查.md](仿真复查.md)和[FOC电流环限幅候选复查.md](FOC电流环限幅候选复查.md)；证据只对各文件记录的源版本和假设有效，不等同于固件或硬件验收。

## 直接文件

| 文件 | 用途与边界 |
|---|---|
| [仿真复查.md](仿真复查.md) | 解释跨板器件修订后的仿真复查范围和模型限制。 |
| [仿真复查.json](仿真复查.json) | 保存上述仿真复查的结构化结果及源绑定信息。 |
| [FOC电流环限幅候选复查.md](FOC电流环限幅候选复查.md) | 说明FOC电流环限幅候选的计算/模型复查、结论与未闭合项。 |
| [FOC电流环限幅候选复查.json](FOC电流环限幅候选复查.json) | 保存电流环限幅候选复查的机器可读输入、结果和源哈希。 |
| [官方DRC与网表.json](官方DRC与网表.json) | 保存官方API返回的DRC和网表读回；使用时核对报告绑定的工程哈希。 |
| [修改前文件SHA256.json](修改前文件SHA256.json) | 记录修改前源文件哈希，用于过程追溯。 |
| [修改前API器件.json](修改前API器件.json) | 保存修改前官方API器件读取记录，供差异追溯。 |
| [只读原生SHA256.json](只读原生SHA256.json) | 保存一次只读工程源哈希核验记录。 |
| [FOC历史归档追加读回核验.json](FOC历史归档追加读回核验.json) | 记录历史归档成员追加后的读回核验；不是当前电气或项目归档完整性结论。 |
| [session.json](session.json) | 保存生成过程使用的EDA会话元信息，不作为工程状态证明。 |

其余原始读回和哈希记录均属于各次复查的佐证；当前结论以模块README所指向的报告和现行源版本为准。
