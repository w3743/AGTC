# FOC电流环限幅候选复查

2026-10-15。本轮修复并复跑FOC参考控制模型；201个工况运行成功。结果支持一个可测试的 **±100 A q轴指令上限、5000 A/s斜率、PI电压矢量饱和/反算抗积分饱和** 工作包络。它通过模型筛查，但尚未在固件或硬件上实现和验证。120 A仍是模型筛查线，不是已确认的电机或硬件绝对最大值。

## 控制和接口约定

`simulate_current_loop_and_5v.py`中的候选配置先将q轴请求限幅到±100 A，再按5000 A/s限斜率；20 kHz时参考变化不超过0.25 A/PWM周期。电压指令做矢量饱和，PI使用反算抗积分饱和。模型以12位ADC量化、每个PWM周期一次抽象同步采样和一个PWM周期的控制延迟运行；没有真实开关级采样、死区、Hall角误差、CSA漂移和端到端快速关断实现。

建议上层能力消息的接收处理只在收到新消息时调用`resolve_regen_capability(..., last_accepted_generation=...)`检查generation，并将有效的单板功率、generation和接收时间缓存。每个PWM周期依据缓存年龄调用`resolve_cached_regen_capability(...)`，或将缓存功率、generation、age、TTL传入`limit_q_current_request(...)` / `current_loop(..., require_fresh_regen_capability=True)`；这些PWM接口不接受`last_accepted_generation`，避免把同一个仍新鲜的generation误当作重放。超过TTL后回馈参考限为零，实际电流仍按被控对象动态衰减；必须为这段残余能量提供真实本地吸收/隔离路径。

双板预算分配前调用`validate_shared_sink_allocations(...)`校验两板分配总和不超过已资格确认的共享吸收预算。预算未知、为零或未资格时两板分配均为零。当前共享吸收资格为`false`；每板1800 W不是整车默认预算，600 W也仅为敏感性输入。

## 电流保护边界和剩余输入

现有0.5 mΩ分流器、DRV8353 CSA GAIN10和比较器/DAC角落估算给出正向最低触发约+131.51 A、负向最低幅值约130.62 A；相对120 A模型筛查线的静态裕量分别只有11.51 A和10.62 A。这些角落不包含CSA漂移最大保证、参考瞬态、PWM纹波、最大比较器/Break/门极关断延迟和板级寄生，不能证明硬件存在低于120 A的快速硬限流。新增100 A命令上限是固件参考包络，不等价于硬件峰值限制。

要闭合实物设计，最小输入集合如下：

1. 电机相电阻、随转子角/电流/温度变化的有效电感、最高转速/反电势，以及卖家80 A与1.8 kW指标的电流口径、持续时间和温升条件。
2. 实际分流器/CSA/参考/ADC增益与偏置、滤波和采样相位，已部署PWM/ISR/驱动器关断延时，实测PWM纹波/最大电流斜率，以及与MOSFET、分流器、连接器和电机SOA对应的真实峰值限制。
3. 跨两板分配的电池/DC-DC吸收功率与能量资格数据、generation/TTL发布源，以及SAFE_5V掉电时真实能量源和独立供电的吸收/隔离行为、热边界与母线电压限制。
4. 官方API没有返回的5条DRC逐项警告明细。
