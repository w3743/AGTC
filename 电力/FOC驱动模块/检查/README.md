# FOC 检查材料

本目录保存当前原理图电气复核报告、与特定源版本绑定的机器证据，以及跨板/整改过程材料。现行状态和源SHA以[FOC模块说明](../README.md)及[原理图电气复核结论.md](原理图电气复核结论.md)为准；单独的历史JSON、PDF或日志快照不自动代表当前源。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [原理图电气复核结论.md](原理图电气复核结论.md) | 汇总FOC原理图电气复核范围、结论和未关闭事项；与模块README的当前源哈希一并使用。 |
| [当前原理图证据.json](当前原理图证据.json) | 保存一次原理图复核使用的结构化证据；引用前核对其源文件哈希与日期是否对应当前工程。 |
| [当前原理图证据_20261015工程历史.json](当前原理图证据_20261015工程历史.json) | 保存2026-10-15工程历史节点的原理图证据，按文件名仅作历史追溯。 |
| [文件整理记录.json](文件整理记录.json) | 记录本目录文件整理过程，不是电气验证或工程源文件。 |

## 子目录

| 子目录 | 用途与边界 |
|---|---|
| [当前源](当前源/) | 保存与整改/导出轮次绑定的源文件、API或导出记录。 |
| [三板共用修复](三板共用修复/) | 保存跨板共用修改后的FOC复核报告及对应检查记录；模块README链接到其中当前有效的复核入口。 |
| [未通过项修复](未通过项修复/) | 保存FOC未关闭项的局部方案、结果和历史试修证据；不等于项目已放行。 |

本目录未提供通用PCB或实物验收结论；FOC PCB、制造、固件及测试由人类完成。
