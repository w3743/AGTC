# FOC 软件接口材料

本目录保存速度请求与驱动反馈协议、配套的纯C编码/解码实现及主机侧测试材料。它们定义接口和验证数据，不包含G431目标固件、HAL、速度控制环、PWM或目标板上的CAN运行实现；固件仍由人类完成。

## 直接文件

| 文件 | 用途 |
|---|---|
| [速度反馈协议.md](速度反馈协议.md) | 定义当前履带速度请求和驱动反馈CAN协议。 |
| [速度反馈接口.h](速度反馈接口.h) | 声明纯C接口的数据结构、常量和函数。 |
| [速度反馈接口.c](速度反馈接口.c) | 实现协议帧的纯C编解码逻辑。 |
| [速度反馈接口测试.c](速度反馈接口测试.c) | 主机侧C测试程序，覆盖协议编解码实现。 |
| [golden_vectors.json](golden_vectors.json) | 保存供实现和测试比对的协议参考向量。 |
| [运行主机测试.ps1](运行主机测试.ps1) | 用PowerShell创建临时构建目录并调用本机GCC编译/运行主机侧测试。 |
