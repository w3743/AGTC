## 历史状态快照（2026-10-15；不代表当前源）

本轮已实施三组跨板共用：U4采用UCC27511ADBVR；J_CAN采用JST B3B-XH-A(LF)(SN)，1脚GND、2脚CANH、3脚CANL；R_OVBOT与R_OVREF_BOT采用毫欧HoAR0603-1/10W-10KR-0.1%-TCR25。正式工程、BOM、PDF与ZIP已原位更新并独立重开核对，PCB原字节保留。结果和限制见[电气复核结论](检查/原理图电气复核结论.md)与[全项目共用型号表](../元件封装库/索引/可能共用型号.md)。

电流环参考模型现含±100 A命令限幅、5000 A/s参考斜率限制、PI电压矢量饱和及反算抗积分饱和；回馈电流上限必须由接收层提供新鲜的**单板分配功率能力**。共享吸能预算未资格确认，因而模型中的1.8 kW能力只用于敏感性/逻辑测试，不是可用硬件预算。两板分配检查拒绝超额分配。

最新模型运行201个工况。指定假设电机R/L条件下，±100 A受限驱动/回馈的加纹波包络约112.578 A，30角落筛查最大112.880 A，低于120 A模型筛查线；120 A不是已确认的电机或硬件绝对最大值。原110 A应力工况保留为失败：硬阶跃含纹波131.377 A，5000 A/s工况含纹波120.902 A。收到的回馈能力在100 ms TTL过期时，命令虽被置零，电流不会立即消失：至500 ms的过期后尾段仍回灌18.179 J，模型峰值约1.774 kW；这只是敏感性尾能量，不是完整硬件吸收额定。当地能量吸收/隔离路径尚未资格确认。

SAFE_5V失电后的能量出口仍未闭合；现有行为模型显示条件性母线过压风险。本轮重开官方 API 返回0 error、6组 warning 的原始明细，详见当前重开复核；这些规则警告尚未关闭。模型、DRC和硬件放行边界均见当前复查报告；不能把局部模型通过等同为固件、原理图、PCB或实物通过。
