# FOC硬件候选核对

更新于2026年10月11日。当前主候选为WeAct Normal QFN48 G431核心板、DRV8353RS、TCAN1042HGV；本记录核对公开原理图和数据手册，未冻结实物接线或PCB。

## 开源参考与改动

[VESC6_OPEN](https://github.com/craigg96/VESC6_OPEN_HARDWARE/tree/1a11171913bd54e77269862e8c9f013df70e8481)固定参考提交为`1a11171913bd54e77269862e8c9f013df70e8481`，采用其Release1制造资料。原板六只STL130N6F7、三只0.5 mΩ相线分流器、三颗AD8418、四只220 µF/63 V母线电解；完整IC共8颗，包括F405、DRV8301、三AD8418、CAN、电源和IMU。

本候选保留六开关桥及散热/开关回路设计原则；控制改为G431核心板，门驱改为DRV8353RS，电流采样改为低边三分流。三颗外置相电流放大器和IMU可删除，但采样窗口与软件须重新适配；原板额定和作者的2 kW现场使用声明不转移为新板性能证据。

原[BOM](https://github.com/craigg96/VESC6_OPEN_HARDWARE/blob/1a11171913bd54e77269862e8c9f013df70e8481/FABRICATION/RELEASE1/bom/VESC6_OPEN_HARDWARE-bom.csv)按位号展开为128个，其中2个DNP；126是非DNP位号数，含4个安装孔和5个电源/相线焊盘，不能直接当作采购件数。Qty列与部分位号数不一致，新板总件数以自身完整BOM为准。

## 门驱与供电

依据[TI DRV8353数据手册](https://www.ti.com/lit/ds/symlink/drv8353.pdf)，选**DRV8353RS**：R表示集成降压，S表示SPI。工作范围VM为9–75 V、VDRAIN为9–100 V；VM接BUS，集成降压设5 V接核心板VCC。门驱内部线性电源及电荷泵供栅极，省去外部12 V。BUCK仍需电感、二极管、反馈和去耦；非R的DRV8353S没有该BUCK。

[Normal QFN48 V10原理图](https://github.com/WeActStudio/WeActStudio.STM32G431CoreBoard/blob/master/Hardware/QFN48/WeAct-STM32G431CxUxCoreBoard_V10_SchDoc.pdf)只有G431和一颗3.3 V LDO，LDO标注ME6216A33XG／ME6239A33M3G两种选项，无外置Flash或USB串口芯片。初始无外置保护基线为4颗IC；当前加TLV1704、UCC27511、TPS7A4001后为7颗。核心板内两颗IC分别计数。两种LDO耐压/电流不同，均须核实实装批次；VCC仅按5 V使用，不按图上3.3–20 V文字给任意批次输入高压。[Microne规格](https://www.microne.com.cn/en/ldo-linear-regulator)

| 5 V负载预算 | 假设电流 |
|---|---:|
| G431及核心板负载 | 60 mA |
| TCAN332正常dominant测点 | 60 mA |
| 三路霍尔，每只暂估10 mA | 30 mA |
| 工程余量 | 50 mA |
| 正常合计 | 200 mA |
| 将CAN测点替换为总线故障180 mA | 320 mA |

BUCK标称350 mA；[TCAN332](https://www.ti.com/lit/ds/symlink/tcan332.pdf)上述电流是数据手册测点，不是最大值保证。霍尔型号、故障工况及实际负载未核，不能据预算冻结电源；同时核实核心板LDO电流与温升。3.3 V负载135 mA时LDO耗散约0.23 W，若总线故障导致供电下跌，必须验证复位后门极默认关闭及受控恢复。余量不足时增加独立5 V供电，并重新统计IC/BOM。

## 引脚候选

下表依据[STM32G431CB数据手册](https://www.st.com/resource/en/datasheet/stm32g431cb.pdf)与Normal原理图；需在CubeMX、所用MCSDK配置和实物焊桥状态再次确认。

| 功能 | 候选引脚 | 约束 |
|---|---|---|
| TIM1六PWM | PA8/9/10、PB13/14/15 | CH1/2/3及CH1N/2N/3N；死区与采样同步配置另核 |
| 三路电流ADC/COMP | PA1/PA3/PA0 | 对应COMP1/2/3正输入；两ADC的同步组合、通道切换及低边有效窗口另核 |
| 霍尔TIM2 | PA15、PB3、PB10 | 同一TIM2的CH1/2/3，供Hall XOR；释放JTAG/SWO，保留PA13/14 SWD |
| FDCAN1 | PA11 RX、PA12 TX | 与核心板USB D−/D+共线，CAN模式不接普通USB数据线 |
| SPI1 | PA4 CS、PA5 SCK、PA6 MISO、PA7 MOSI | 读回门驱配置与故障 |
| 门驱ENABLE | PB11 | 默认下拉，复位与失电行为须验证 |
| nFAULT及TIM1 Break | PB12 | 开漏3.3 V上拉、低有效Break；软件可读取同一引脚 |
| BUS、MOS/电机温度 | 余下ADC通道 | 与COMP、本板焊桥及核心板引出一并分配 |

PB8涉及BOOT0及板载按键，避免接霍尔。PB6/7/9分别为TIM4 CH1/2/4，不能直接作为标准Hall CH1–3 XOR接口。PA15/PB3改作霍尔后不用完整JTAG或SWO；PA13/14仍可SWD调试。核心板USB供电与BUCK回灌路径另核，不能由USB数据功能不可用推断双电源可安全并接。

## 采样与保护

- CSA配置双向模式，VREF=3.3 V、中心1.65 V；0.5 mΩ、20倍增益下±120 A约为0.45–2.85 V，输出允许范围约0.25–3.05 V。须计入偏置、增益、阻值误差、滤波延迟和零点校准。
- SEN_OCP最低阈值0.25 V，0.5 mΩ对应约500 A；VDS保护也随MOS温度/阻值变化。两者都不能称为精准±120 A限流。正常电流调节由FOC电流环完成，硬件VDS保护锁存并通过nFAULT触发Break；正负过流覆盖、故障能量与恢复须验证，当前已补三路G431正阈值比较和TLV1704负阈值比较，接入TIM1 Break；阈值误差、低边窗口与故障延迟仍须验证。
- 本地BUS采样/比较与温度保护不可由CAN替代。支持负电流调节不等于已有回馈吸收能力；PWM关闭后仍有体二极管回灌路径，物理隔离及整车泄放另核。
- 栅极、BUS电解/陶瓷、VM、VDRAIN和TVS应整体协调耐压。IRLB4030栅极绝对上限16 V，栅极过冲须测；100 V漏极耐压不代表整个母线节点可到100 V。

本轮原理图选型和供电/引脚值以[外围选型表](../原理图准备/外围选型候选.json)、[设计构想](../FOC驱动设计构想.md)及[保护与固件约束](../保护与固件约束.md)为准；本记录保留开源参考核对证据。


最终CAN改为[TCAN1042HGVDRQ1](https://www.ti.com/lit/ds/symlink/tcan1042-q1.pdf)：VCC接BUCK5V、VIO接核心3.3V，STB用PB5且默认上拉待机。此前TCAN332供电预算保留作更改前对照，不能用作最终BOM/接线。BUS采样改PC4，PB2保留核心板USB-VBUS检测；DRV VREF及负阈值分压统一接模块P2-8的VREF_CORE。
