# FOC 原生工程与交付文件

本目录集中保存FOC嘉立创EDA原生项目及导出的交付文件；当前入口和文件哈希绑定关系以[FOC模块说明](../README.md)为准。

## 直接子目录

| 子目录 | 内容 |
|---|---|
| [FOC_G431_Driver](FOC_G431_Driver/) | 当前EPRJ3原生项目，内含`sch/Schematic1/P1.esch2`原理图源、`Schematic1.ecfg`配置，以及项目树中的`pcb/PCB1.epcb2`文件。原生文件对象不在此逐项枚举；存有PCB格式文件不代表PCB已完成设计或验收。 |
| [导出](导出/) | 保存原理图PDF、ENET、BOM和双板装配补充等项目导出物；交付子目录中的文件是否与当前源一致，以模块说明中记录的版本状态为准。 |

该目录下的原生工程文件和导出物用于EDA源维护与原理图交接。它们不证明制造、装配、固件或实物测试已经完成。
