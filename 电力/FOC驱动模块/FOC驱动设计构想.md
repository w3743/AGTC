# FOC驱动设计构想

V0.8｜2026-10-11｜原理图电气复核修订。两块同版FOC主板，各驱动一台N5065、270 KV、五线霍尔电机；G431核心板保留插接。每台按母线电输入1.8 kW选型，1 s用于单次脉冲核算，实际运行由供能、电流和温度共同限幅。环境参数按用户确认记录为0–60°C。

**现行分工（2026-10-22）：**代理负责原理图、选型、接口合同、计算与原理级验证；原理图交接后的PCB设计、布局布线、散热实现、制造/打样/装配、固件及台架/整车测试由人类完成。全电力系统按最少选型、最低总成本取得最好性价比。本文中的纸面散热计算是设计输入，不替代人类完成的板级实现和实测。见[交付说明](交付说明.md)。

**历史设计基线：** 本文中的SAFE_5V供电BOV、旧比较器门限及Dump能量结果已被当前P1的U7 TLV6700内部参考方案和[2026-10-21全图复核](检查/原理图电气复核结论.md)取代。用户确认的是电机母线输入1.8 kW选型值；本文的1 s是设计筛查条件，不是已确认的Dump吸能硬指标或实物能力。两板3.6 kW仅为同时达到1.8 kW筛查点的算术外推。

**每板7颗IC**：G431、核心板LDO、DRV8353、TCAN1042H、TPS7A4001、TLV1704、UCC27511。参考[VESC6_OPEN Release1](https://github.com/craigg96/VESC6_OPEN_HARDWARE/tree/1a11171913bd54e77269862e8c9f013df70e8481)的六MOS桥与功率布局，删去IMU、三颗独立采样放大器和另加的USB电路。F405固件不能直接用于G431；MCSDK霍尔FOC作为后续固件基础。

板上六只M5端子分别接熔断后的BUS+、GND、U/V/W和DUMP_SW；每只四焊脚同网。主保险位于电池至板端的线束；三颗BUS电容、泄放保险、两只电阻及SB50接插件为板外装配，必须按选型表接线。

原理图合为一页：母线与外置装配→三相功率桥→电机；门驱与栅极网络紧邻桥，电流采样从分流器返回门驱/主控。主控、CAN和霍尔集中；独立SAFE供电、过压比较、Break与泄放组成可追踪的保护链。块内用实线表达电路，跨块保留明确网名；PCB布局与散热另行完成。

## 策略速度与只读反馈接口

当前上位机契约见[速度反馈协议](软件/速度反馈协议.md)。策略的左、右履带速度分别映射为各自电机轴机械 RPM 请求；不能将旧实验协议的转矩请求与速度上限混为当前动作。CAN继续复用现有TCAN1042连接。反馈独立上报有符号 q 轴电流（0.01 A/计数）和电机机械 RPM，并以 sample sequence、质量位、CRC 和本地接收超时配对。BMS电池电流/预算仍走原接口。云台IMU及关节反馈由上位机采集，不增加FOC UART。

当前实现仅含协议文档、纯 C 主机 codec 和 host tests；目标板 boot epoch、G431 HAL/FOC、CAN 实际状态发送、速度环、PWM、传感器校准和台架验证均待后续完成。现有原理图具备 CAN、ADC三相电流采样和 Hall 路径；本接口工作没有修改原理图或 PCB，也没有授权 ARM 或放宽现有保护。

当前已保存并回读的原理图为158个器件、474引脚（461连接＋13NC）、97个网络、7颗IC。SAFE_ADC现接PB0/P2-9（COMP4_INP/ADC1_IN15），TEMP_MOS_ADC移至PA2/P2-18（ADC1_IN3）；分压为27.4 kΩ/10 kΩ、滤波电容1 nF C0G。另已修正RT/SD接线，补SDO上拉、VM本地电解及三路比较器输入1 kΩ限流。最终交付ZIP重开核对PASS，3份原生文件SHA与源一致。重开API DRC为0致命、0错误、5警告，API未提供明细；旧12:01 GUI报告早于本轮修订，严格零警告未通过。回读统计只证明原理图连通性；SAFE失电回馈、保护动作、回收闭环、PCB和实物能力仍未通过。实际网表、DRC与证据见[电气复核结论](检查/原理图电气复核结论.md)。

霍尔已确认：H-JSY 5pin 2.0（卖家型号）、5 V、50 mA、60°；线序5V/U/V/W/GND，板端候选依次为1/2/3/4/5。U/V/W为霍尔信号，技术网名沿用HALL_A/B/C_RAW，与功率相线区分。Pin 1观察方向和外壳配合到货核对。50 mA按每台电机整套五线霍尔计入预算，记录见[用户确认参数](参考资料/电机资料/电机接口用户确认.json)。固件可改相序、极性、60°/120°状态表及电气偏移；电压和输出类型须配硬件：3.3 V推挽走直通，开漏按规格装3.3 V上拉，5 V推挽装10 kΩ/18 kΩ分压并换跳帽。三路都预留选择，不把串联1 kΩ当作5 V保护；分压电平裕量、边沿和掉电注入仍待验证。

每板1 s需1.8 kJ，两板同时需3.6 kJ；低速、启动和堵转不能沿用上表。相瞬时120 A、源端输入100 A作为筛查包络。电流环/回馈/5 V联合模型共197项筛查；其中20 kHz平均闭环电流环在±100 A指令、5000 A/s斜率、20 µH条件下的最坏峰值包络为112.880 A，部分正向低母线角落仍受电压限制，不能跟踪到命令。110 A未冻结：只有实测有效相电感在饱和、温度及转子角度影响后仍≥44 µH，且实际电流纹波/波形不超过模型包络时，才保留为条件候选。

- **条件热计算：** 120 A、20 kHz、重叠时间500 ns时桥损耗160–195 W。最热单管94.7 W；起始结温及全程壳温均≤60°C、最大结壳热阻0.4°C/W时，结温上界97.9°C。用户新确认环境上限60°C；上述壳温条件不能直接由环境温度代替。此计算是原理阶段给人类PCB散热实现的输入，不构成热验证。反向恢复、布局、门驱温升和重复脉冲尚未证明。
- **驱动开关模型：** 32.4 V、假设电机参数、2.2 ms总窗/1.8 ms带载，桥端输入1.83 kW、相峰111 A、VDS峰41.4 V；源端电流峰51 A，桥开关瞬时电流峰124 A由本地电容共同提供。该短窗不能证明1 s整板输出能力。
- **回收能量模型：** 向BUS等效注入1.8 kW/1 s、源端不吸能时，标称阈值模型得到BUS峰43.43 V；两只电阻合计吸收1767.6 J、Q7约19.9 J。电阻各884 J，满足公开单次过载条件的筛查，仍须验证安装、热态重复及TVS/泄放全温协调。
- **回收开关模型未闭合：** 同一假设下开环回馈实际1.44 kW，相峰146 A，超过120 A包络；需电流环、同步采样及限幅。PWM前馈已加100 µs模型滤波，修正了原先非实物的瞬时母线代数反馈；TVS有限斜率模型在修正工况未导通。

所选IPT公式见[条件热筛查](计算/selected_ipt015_thermal_screen.md)，模型与失败场景见[仿真记录](仿真/仿真说明.md)。卖家图给出7极对/14极、60°霍尔、推荐24–36 V；80 A口径未知，不能据此允许120 A相峰。9S满充37.8 V超推荐，电机限压与转速边界待确认；R/L、霍尔输出及电气偏移待实测，60°不能代作电气零位。证据不等于实物1.8 kW通过。

## 回收与保护

六MOS桥回馈公共9S BUS（22.5–37.8 V）；电池和中央超容双向DC/DC优先吸能，CAN协调两板回馈额度。本地负责电流环、过温、欠压、瞬态与硬保护。隔着DC/DC的超容不能替代直连BUS电容。

正负过流窗口标称±150 A：内部DAC3同码2979/4096，已列静态误差角最小+131.5/−130.6 A；延时、噪声和低边盲区待验证。DRV的SEN保护最低500 A，不能代替窗口；VDS候选0.9 V、2 µs、锁存。默认gate关闭，故障后显式ARM，不自动重启。

泄放标称43.4 V开、41.4 V停；已列静态角落42.10–44.73 V开、40.08–42.97 V停。过压经两只BJT及4.7 kΩ驱动限流电阻单向拉低Break，其他Break故障不会反向误开启泄放；补限流后模型中的PNP集电极峰值由145 mA降至0.92 mA。主5 V掉电时保留SAFE路径；SAFE或电阻支路失效仍可能过压。SMCJ40A只处理短瞬态。

关gate后体二极管仍可回灌；泄放MOS短路约32 A时，60 A保险未必动作。实体断电、残能处置和机械制动仍须实现。具体器件与附件见[选型依据](原理图准备/外围选型依据.md)，时序见[保护与固件约束](保护与固件约束.md)，阶段任务见[TODO](TODO.md)。
