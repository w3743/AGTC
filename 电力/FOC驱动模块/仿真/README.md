# FOC 仿真材料

本目录的[仿真说明.md](仿真说明.md)解释平均值母线模型、开关级模型和保护行为模型各自覆盖的范围，以及它们不能证明的事项。脚本位于[源码](源码/README.md)，结果文件位于`结果/`并作为模型运行输出/证据读取；结果不等同于完整闭环、电机安全工作区或实物验收。`tools/ngspice-47-portable/`为随目录保存的第三方ngspice发行包及示例，不在本项目源码说明范围内。
