# FOC 原理图准备

本目录保存FOC当前连接合同、外围候选与选型依据、电流检测窗口纸面核算，以及不计入板上原理图的装配采购补充。候选、条件估算与当前连接输入需按各文件中的状态字段及[FOC模块说明](../README.md)区分；它们不表示PCB或实物验收。

## 直接文件

| 文件 | 用途 |
|---|---|
| [当前原理图连接.json](当前原理图连接.json) | 记录FOC当前原理图页面及位号/引脚/网络连接合同。 |
| [外围选型依据.md](外围选型依据.md) | 说明驱动外围器件的当前原理选型依据与仍开放的电气资格项。 |
| [外围选型候选.json](外围选型候选.json) | 汇总外围器件候选、连接/采购信息、电气目标及待闭合项；按文件状态和候选字段使用。 |
| [电流窗口误差核算.md](电流窗口误差核算.md) | 说明G431/DRV8353双向电流检测窗口的纸面角落估算及限制。 |
| [电流窗口误差核算.py](电流窗口误差核算.py) | 复算电流窗口误差角落，并生成配套数值文件。 |
| [电流窗口误差核算.json](电流窗口误差核算.json) | 保存电流窗口误差估算的结构化假设、结果和建议。 |
| [装配采购补充.csv](装配采购补充.csv) | 登记板外装配采购配件及其数量、供应信息和状态；不属于PCB BOM。 |
