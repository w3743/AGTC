# 电力目录维护工具

本目录保存项目目录整理和 Markdown 链接检查脚本。它们服务于先前的整理流程，不是电气设计工具；部分脚本会读写 README、归档计划或清理文件。使用前必须核对 `../cleanup_*.json`、`归档/目录整理.json` 及源码中的路径/执行条件。

## 本目录直接文件

| 文件 | 用途与边界 |
|---|---|
| [检查目录入口.py](检查目录入口.py) | 只读扫描活动 Markdown 中的本地链接，并结合 `cleanup_link_baseline.json` 识别整理前已有的断链。 |
| [整理目录.py](整理目录.py) | 按显式清单生成目录整理归档；源码说明会逐文件计算/读回 SHA256，不修改 EDA。 |
| [统一目录说明.py](统一目录说明.py) | 根据已读回的归档记录更新模块 README 的当前入口和历史链接，不改电气设计或模型。 |
| [清理已校验原件.ps1](清理已校验原件.ps1) | 检查归档记录、ZIP 哈希和成员读回后清理清单内的原件；会删除文件，不要在未核对当前归档状态/保护清单时运行。 |

本 README 仅说明工具用途，不运行这些脚本，也不表示历史目录整理脚本适用于当前文件状态。
