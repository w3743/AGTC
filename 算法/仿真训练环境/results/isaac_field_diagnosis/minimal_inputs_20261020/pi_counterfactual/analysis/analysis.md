# P / PI 初始状态与响应核查

P(Ki=0) 与 PI(Ki=0.1) 两次原生运行本身均真实 exit 0，但比较器 exit 1，未生成 `pair_comparison.json`。比较器要求每个 case 的 settle 后状态逐字段完全一致；本核查保留该严格门禁，不做容差放宽，也不生成严格配对图。

运行配置匹配：源文件 SHA 映射 `True`；环境/reset 配置 `True`；v5 drive 配置 `True`；10 个动作 `True`；settle 控制策略 `True`。settle 后状态精确匹配 `0/10`。

10 个 case 中 settle 状态最大数值差为 **0.000813256512**（单位随字段）。差值最大的字段如下：

| 字段 | 最大绝对差 |
|---|---:|
| `wheel_actual_qd_rad_s[8]` | 0.000813256512 |
| `wheel_actual_qd_rad_s[9]` | 0.000813155557 |
| `wheel_actual_qd_rad_s[12]` | 0.000813030436 |
| `wheel_actual_qd_rad_s[11]` | 0.000812929969 |
| `wheel_actual_qd_rad_s[13]` | 0.000812857475 |
| `wheel_actual_qd_rad_s[7]` | 0.000812549041 |
| `wheel_actual_qd_rad_s[1]` | 0.000812535625 |
| `wheel_actual_qd_rad_s[3]` | 0.000812415813 |

位置与零目标命令可保持精确相同；姿态、底盘速度、root 高度和轮速存在小量非位级差异。因此比较器失败是精确值门禁所致，差异量级很小，但不能仅凭现有记录断言它们全是浮点舍入。两组 source hash、仿真/reset配置、动作和 settle 控制策略均匹配。

## 制动响应（描述性并列，不是严格配对）

| case | 控制器 | 末0.3 s均值 v (m/s) | 末0.3 s均值 w (rad/s) | 末track command (m/s) | 末0.3 s阈值 |
|---|---|---:|---:|---|---|
| 直行 | P / Ki=0 | -0.0000 | -0.0000 | +0.000, +0.000 | True |
| 直行 | PI / Ki=.1 | -0.0025 | 0.0000 | +0.000, +0.000 | True |
| 差速 | P / Ki=0 | -0.0033 | -0.0273 | +0.333, -0.333 | True |
| 差速 | PI / Ki=.1 | -0.0118 | -0.1154 | +0.333, -0.333 | True |

直行制动末端命令已为 0；差速制动的 2 s 零 normalized action 后，命令仍约为 ±0.333 m/s，因为 1.5 m/s² 的加速度限幅还未降至 0。故差速制动末0.3 s低速阈值不等于从零命令停车，也不能据此排除积分残留。

Ki=.1 是未标定的仿真假设；这些 proxy wheel effort 数值不代表实测电机扭矩。本结果不支持生产采用、导航成功、避障或作物安全结论。逐 case 完整差值及输入 JSONL 哈希见 `initial_state_differences.json`。
