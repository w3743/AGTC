# Minimal input v6 test validation

Scope: test and fixture migration only; no training, GUI, production, or legacy-result changes in this validation. The helper invokes the repository's official `scripts/isaaclab_python.sh` under Ubuntu-24.04 with `CUDA_VISIBLE_DEVICES` empty and records the pytest process exit code in each uniquely named log.

The v6 regressions cover the 1x400 normalized lidar channel and valid-hit saturation versus explicit-invalid finite-range zero; 16x8 detections with positive-width/height presence and all-zero padding; a real box whose negative noisy range remains independent of candidate presence; rejection of malformed zero-width candidates; the 33-value mode/goal/heading/previous-action layout; 37-value feedback layout and validity/age offsets; v5 observation/encoder rejection; and the 9-input Netron wrapper (all five sensor inputs, including feedback) against policy prediction/distribution/value paths over 3x3 runtime cases.

- Full CPU suite: `full_cpu_pytest_attempt1.log`, exit 0, 231 passed, 11 skipped. It preceded that last test-only assertion strengthening; the final focused run includes and passes the strengthened test.
