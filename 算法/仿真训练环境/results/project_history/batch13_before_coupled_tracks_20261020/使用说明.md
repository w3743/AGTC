## 安装

Windows 上双击项目根目录的 `安装IsaacLab.cmd`。也可以在 Ubuntu-24.04 WSL 中进入本项目目录后运行：

```bash
bash scripts/install_isaaclab.sh
```

安装脚本使用固定版本的 `external/IsaacLab` checkout 和 Python 3.12 环境。安装完成后，WSL 命令在项目根目录执行；Windows 启动器会自动转换路径并调用 WSL。
