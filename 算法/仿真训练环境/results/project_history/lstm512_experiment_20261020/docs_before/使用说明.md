# Isaac Lab 使用说明

## 运行环境与当前检查页

使用Ubuntu-24.04，在项目根目录执行Bash命令。`scripts/isaaclab_python.sh` 复用已有Isaac Lab Python环境；Windows入口为根目录的安装/启动cmd。共享运行时和 `external/IsaacLab` 不属于清理对象。

当前带前导向轮的手动检查命令：

```bash
bash scripts/isaaclab_python.sh -m isaac_field viewer --mode goto \
  --plants 0 --rock-density 0 --front-guides --body-stability \
  --max-time 60 --seed 80003 --episode-seed 87001 \
  --reward-profile protect_plants --port 8781
```

车辆页为 `http://127.0.0.1:8781/`，相邻8782为二维网络服务。该场景不加载旧checkpoint，初始手动、暂停；无策略时没有训练网络实时激活。旧8769/8770属于原14轮几何的模型回放，不替代新几何检查。运行中的服务状态以本轮验收记录为准，历史PID不能直接复用。

不指定 `--goal-distance`，每回合在全场有效区域独立采样起点、朝向和目标；不传 `--flat`，启用崎岖地形。显式 `--rock-density 0` 先排除独立岩石，植物为0。CLI默认岩石密度仍为0.01，故检查时保留这个参数。

## 前导向轮的逻辑

`--front-guides` 左右各增加一只半径45 mm、宽60 mm的轮，轮心前420 mm、比支撑轮轴高50 mm。两轮质量从车体扣除，总质量仍30 kg。原14个负重轮执行器及每轮2 Nm限幅保持，没有新增导向轮电机、PID或扭矩额度。

控制链为：四维策略动作→左右履带目标速度→原有轮执行器→本侧轮0与负重轮/导向轮的Newton等式传动→接触求解。每侧六条负重轮关系加一条导向轮关系，合计14条/环境；各world相互隔离。导向轮角速度为本侧轮0的 `R负重轮/R导向轮` 倍，当前同为45 mm，比例1∶1。半径不同应保持圆周速度一致。

资产、环境、约束、metadata与实验合同统一读取 `FrontGuideSpec`。配置经普通dict传给Isaac configclass，环境恢复只读规格。自由转动模式仅用于诊断对照；不启用前导向轮时，旧资产和12条关系保持兼容。

抬高轮仍是离散接触代理，没有连续履带斜段或张紧系统。实际台阶接触、车体是否完全越过及测试失败均单独记录；不能由几何外观推定越障高度。

## 车身稳定目标

`--body-stability` 启用以下每策略步惩罚：

`dt × [2 × max(0, 总倾角−35°)² + 0.02 × (ω车体X²+ω车体Y²)]`

总倾角为车体上方向与世界竖直的夹角。正常沿坡行驶不因偏离水平就受到倾角项惩罚；角速度项减少俯仰/侧倾摆动。35°和系数是试验设置，尚非实车标定。原roll/pitch 1.2 rad硬终止保持，边界和姿态原因分别保存。

奖励和统计使用仿真车体真值，云台IMU仍按实车安装建模；不增加策略观测。报告包括最大roll/pitch/总倾角、超阈时长、角速度RMS和惩罚和；均为策略步采样统计，不冒称物理子步极值。

## 当前新初始化训练方案

`scripts/train_isaac_foundation_fresh.py --profile random_rough` 复用RecurrentPPO和现有环境，配置如下：

| 内容 | 当前设置 |
|---|---|
| 任务 | goto，全场随机起点、朝向和目标，不限制附近 |
| 地形 | 100×100 m，幅值预算0.35 m，波长4–10 m |
| 障碍 | 植物0、独立岩石0 |
| 车辆 | 同侧联动前导向轮，车身稳定奖励启用 |
| 回合 | 最长60秒，原0.4 m/低速hold0.3秒到点标准 |
| 采样 | 4环境，seed69009，总196608 transition |
| 初始化 | 新随机policy和Adam，正式0步baseline；不续用旧几何权重 |
| 开发配对 | 地形80003/80004，回合87001–4/82001–4 |

每次运行固定一份实际地形，各回合只重新随机车辆和目标；并非每回合重新生成地形。训练总步数为全部环境transition之和，不是物理子步或单车步数。

流程：

1. 先完成资产、联动、接触、局部reset、姿态奖励和CPU回归，prepare保存协议、源码快照/SHA、依赖和规格。
2. preflight核验当前源码和冻结协议，拒绝重复目录或配置漂移；实际仿真启动后还核实际drive、机器人与地形资产。
3. 创建正式0步随机baseline。每环境收集128步，4环境共512条transition后更新PPO；batch128、最多5 epochs、学习率3e-4、gamma0.995、GAE λ0.95、target KL0.03。
4. 策略训练时采样连续四维动作；LSTM在回合内保持记忆，对应环境reset时清空。每新增8192条transition保存checkpoint，权重与Adam一并保留。
5. 自然完成后核父shell实际退出、final步数、源码/协议、权重与Adam有限性；状态文件单独不能证明进程已经结束。
6. 在两份地形上分别对正式0步baseline和final做相同配置/相同初态开发配对。强制核实际USD路径/SHA/字节数、地形seed、起点/目标及姿态统计；缺失或非有限则拒绝比较。无损成功增加且损伤/碰撞不恶化，姿态/边界失败不恶化，才能称该开发集提升。

已使用的新输出目录不可重复prepare：

```bash
bash scripts/isaaclab_python.sh scripts/train_isaac_foundation_fresh.py \
  --prepare --profile random_rough \
  --output results/isaac_field_improvement/random_global_rough_coupled_guides_20261020
bash scripts/isaaclab_python.sh scripts/train_isaac_foundation_fresh.py \
  --preflight --output results/isaac_field_improvement/random_global_rough_coupled_guides_20261020
```

prepare/preflight与正式训练是不同阶段。本轮是否已准备、启动或完成，以 [整理记录](results/project_history/front_guide_coupled_cleanup_20261020/README.md) 的真实退出为准。源码变化后另建独立实验，不覆盖旧协议。旧近距离四阶段保留为 `legacy_foundation`，当前不作为训练题目。

## 网络与可视化

| 分支 | 形状 | 说明 |
|---|---|---|
| LiDAR | 1×400 | 环形Conv1d编码 |
| 深度 | 1×160×88 | 单通道轴向深度，无效值0，无重复mask |
| 检测 | 16×8 | 最多16个槽位；plants0阶段没有检测学习证据 |
| 状态 | 33 | 目标、定位、任务状态和上一动作等 |
| 反馈 | 37 | IMU/磁场/四元数、云台角度与速率、左右等效Iq/RPM及有效性/时龄 |
| 动作 | 4 | 左右履带目标速度、云台偏航/俯仰速率，归一化[-1,1] |

schema为 `sensor-minimal-v6`，编码器 `depth64-lidar-single1d-minimal-v3`，五路融合192→LSTM128；动作 `direct-track-speed-v1`。新增机械关系不增加网络节点或动作维度。ATK-IMU901随云台偏航/俯仰，不能直接视为车体IMU；气压/海拔/温度/重复欧拉角不入策略，磁场保留。仿真Iq/RPM为轮力矩/轮速的等效换算，尚非实机测量或接触力传感器。

界面固定深色，只保留完整二维网络与车辆三维。60张卡片涵盖采集输入、可学习模块、LSTM诊断及critic旁路，60不是神经层数。曲线保留箭头和分支色，选层/悬停不点亮或压暗。主图按整帧采集激活和参数的完整有限值最大绝对值统一±色标，扩大立即、缩小平滑，0同色；不做百分位截断。

右侧单图预览默认独立自动色标，按所选激活/weight/bias的完整有限值计算±范围；全零/无有限值退回±1。可取消勾选，改用全局范围。详情独立色标不改变主图；不同独立预览应先看色条再比较。Netron仅作静态结构/参数浏览，不能替代实时激活。

## 独立训练方法与历史实验

`scripts/train_isaac_mastery.py` / `scripts/run_isaac_mastery.sh` 提供固定课表、能力课程和单变量GAE对照，复用RecurrentPPO与原始奖励。课程由近距离转向逐步到plants2/8/16，独立16-seed探针连续两次无损成功≥80%且零损伤/碰撞才晋级；旧任务通过重新采集on-policy轨迹复习，非旧rollout重放。32个固定开发场景按8类分别验收，全部类别不退步、总无损成功严格增加且损伤/碰撞不恶化才更新best；latest与best分别保存。

方法入口与当前全场rough方案独立，不把两种变更混为单变量对照。此前 `method_control_v2_20261020`、`method_mastery_v2_20261020`、`method_lambda099_v2_20261020` 准备后共享源码已改变，不可直接启动或修改旧协议。需要使用新的output重新prepare，先用 `--help` 核入口。方法诊断记录奖励分项、动作、PPO标量和真实终止信息，尚未引入特权critic或新的RL算法。旧方法详细命令与依据保存在本轮 [原说明备份](results/project_history/front_guide_coupled_cleanup_20261020/docs_before/使用说明.md) 和 `results/project_history/training_method_solutions_20261020/`。

原14轮物理的fresh196608步和60秒续训393216步均已真实完成。续训保留父policy与Adam，但重置环境/RNG/LSTM回合状态；同60秒开发重评free成功1/4→1/4、field1/4→0/4，未通过提升门槛。它们不证明新导向轮或新地形能力；旧模型/协议/源码快照/成绩保留，勿在已完成目录重新launch。详见 [项目状态](ISAAC_LAB.md)。
