# 真实FOC设计与仿真电驱能力边界审计

2026-10-20。用户要求保持当前摩擦系数0.8，并查项目真实FOC驱动文件判断限速、限功率和能力边界。本次只读查看当前硬件/软件/模型和已准备的rough协议，没有修改硬件、45份冻结源、协议、模型或历史成绩，也没有启动新训练。下文分开记录用户选型、设计候选、器件级计算和整板实测证据。

## 结论

当前文件可确定的是设计输入和可测试的候选工作包络，**尚不能确定本车电机/FOC的连续实测功率、电流和转矩额定值**。当前软件目录只有通信/反馈主机codec和测试，没有可构建的G431完整FOC/HAL/PWM电流环固件；不能把模型限幅当作已经在MCU上执行。

当前仿真有左右速度命令及斜坡、14个代理轮各2Nm的执行器限幅，但没有电机总电功率、母线电流、电压/电池、热过程和再生吸能约束。因此现有仿真尚不是完整的实车电驱能力模型。

## 当前器件身份与热条件

当前BOM的主桥Q1–Q6是6只Infineon IPT015N10N5ATMA1；Q7的IRLB4030PBF属于泄放支路。早期IRLB4030/STL130六管桥比较不作为当前主桥结论。现行IPT015热筛使用120A相峰值、20kHz、假定开关边沿和热态Rds，并要求全脉冲壳温≤60°C；它不能证明环境60°C下整板达到相同能力。

当前RSU/RSV/RSW为KOA PSF4NTEBL500F，BOM标注0.5mΩ/5W。某相持续100A时I²R=5W，120A时7.2W；这是损耗换算，不能只比较瓦数就判定1秒脉冲合格或失效，须核器件短时过载条件、端子温度、实际PCB热路径与重复率。三只外置BUS电容为每只10mF；容量和MOS的100V标注也不证明板级工作电压、回馈能量或过压安全边界。

BOM中的100A主保险和60A泄放保险不是精密运行限流。过压泄放约43.4V开启/41.4V释放是候选阈值，不是实测最高安全BUS电压；SAFE_5V失电时的真实吸能/隔离路径仍未闭合。

## 当前仿真限制实际相当于什么

在每侧7轮、每轮2Nm、代理轮半径45mm、链轮半径30mm、减速4:1、效率1及Kt=.035Nm/A这些现有假设下：

| 量 | 每侧/每台电机 |
|---|---:|
| 代理轮力矩之和 | 14Nm |
| 等效链轮输出扭矩 | 9.333Nm |
| 等效电机轴扭矩 | 2.333Nm |
| 代码换算的等效Iq | 66.67A |
| 15km/h目标对应电机转速 | 5305.16rpm |
| 同时达到目标速度和扭矩上限时的机械算术值 | 1.296kW，双侧2.593kW |

这些不是实测电机性能。66.67A不能直接与卖家80A或参考模型±100A比较，Kt和dq/反电势电流口径尚未确认；2.593kW不是输入功率上限，也不是连续额定。15km/h仅限制可请求速度，1.5m/s²仅限制命令变化；不能保证车体实际达到或不超过该速度。配置中的110rad/s关节速度上限本次只确认配置值，没有额外证明solver硬夹限。

现有驱动不会因为母线低压、过温、吸能额度过期或超过真实输入功率而自动缩小可用扭矩。堵转时机械功率接近0仍可能有大电流/发热，单加一个瓦数限制也不能替代电流/热限制。详细公式、源码行号和数值见 [simulation_limits.md](simulation_limits.md) 与 [simulation_limit_audit.json](simulation_limit_audit.json)。

台阶低速固定动作中观察到的最大单轮effort约.933Nm，小于2Nm上限；该次没有越过台阶，不能只归咎于2Nm限幅或15km/h速度限制，也不能用提高电流上限替代接触模型排查。

## 能用于下一步的边界

1. 保持摩擦系数.8及已验证的同侧机械联动。
2. 电驱约束以每台真实电机的总转矩/电流/输入功率包络表示，再分配给代理轮；不要把14个代理轮限幅直接标成实机额定。
3. ±100A、5000A/s、1.8kW输入/单次1s可登记为有明确假设的候选试验包络，不能直接作为连续训练能力或实车运行许可。持续功率、持续相电流、热降额和重复脉冲条件仍缺实物证据。
4. 电机R/L、Kt及电流/电压定义、堵转与温升、实际供电/吸能额度、PCB/端子热条件和完整固件限制确认后，才能收紧成可信的实车包络。未资格的回馈预算不填成无限大。
5. 当前rough协议继续保留prepared/0步；若据本审计修改电驱源，必须另建独立实验和协议快照，不改写现有45源协议或混算旧成绩。
