# 前抬高导向轮试验资产

本目录属于 2026-10-20 用户提出的“车体前方加一个抬高轮子”建模试验，保存资产阶段证据。后续环境接入已完成，新增原生专项2项和既有native14项真实通过，见相邻 `front_guide_integration_20261020/REPORT.md`。这些通过不等于证明连续履带翻越能力，固定台阶接触结果另见 `front_guide_step_probe_20261020/`。

## 当前试验参数

左右履带各一只独立、无驱动、可绕 Y 轴自由转动的圆柱轮。轮心相对车体原点 X=0.42m、Y=±0.205m，较支撑轮轴高 0.05m；半径 0.045m、宽 0.06m、每只质量 0.25kg。这些尺寸是试验假设，未按实车测量标定。两只轮的质量从车体扣除，重算车体惯量和 COM，装配总质量仍为 30kg。

启用时使用包含导向轮规格的独立资产哈希与目录；未启用时保留既有 14 轮资产路径、哈希与控制关节。导向轮关节命名不匹配驱动轮正则，不增加驱动执行器或同侧传动约束。

## 几何限制

平地初始姿态下，主轮圆心高 45mm，导向轮圆心高 95mm、最低点离地 50mm。最前主轮 X=0.2975m，两圆心水平差 122.5mm、竖直差 50mm，中心距约 132.311mm。轮廓之间仍有 32.5mm 水平空档，最短表面间隙约 42.311mm。两轮中心连线约 22.2°，但该连线没有碰撞面，不能当成连续履带前斜段。

固定初始姿态下，台阶角点只有在约 50–140mm 的高度区间才可能碰到导向轮圆周；其中 50–95mm 区间接触法线才有向上分量。这只是几何接触范围，不是可爬高度、通过率或实车性能。

该模型近似前方被动滚轮。没有连续履带带面、履带张力或斜段切向牵引力，也没有悬架。能否实际越障必须进一步检查动态接触、驱动推力、车身姿态和通过结果。
