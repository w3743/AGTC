# Isaac 迁移前旧内容归档

本目录保存从项目根目录移入的旧后端、相关实验资料及独立网页。此次采用移动归档，没有删除数据；归档内保留原相对目录结构。

归档内容包括 FieldSim、Gazebo 农田仿真、旧 ROS/Gazebo 映射与 PX4 无人机、MuJoCo 学习入口及其脚本、配置、运行环境、发布包和测试；也包括对应的旧模型、实验结果、地图与视觉记录，以及独立页面 `pelican-bicycle.html`。

`archive_manifest.json` 是本次归档的清单和校验记录：共移动58个根路径，包含2754个文件、总计1,292,302,871字节；归档后 SHA-256 核验全部匹配，40个受保护源码文件保持不变。实验结果、模型和协议内容未改写，历史文档中记录的旧路径也未重写。

需要恢复时，先停止对应的旧流程，再检查项目原路径不存在同名项。根据 `archive_manifest.json` 中 `entries[].relative` 指定的相对路径，将所需内容移回项目根目录；不要覆盖已有文件。旧虚拟环境、运行时和部分脚本可能依赖原绝对路径，恢复后可能需要重建环境或调整路径配置，不能保证在归档目录中直接运行。

归档中的 `ISAAC_CLEANUP_CANDIDATES.json` 是此前的 review-only 历史候选清单，不再是待执行的删除计划；本次移动记录以 `archive_manifest.json` 为准。
