# MJW v6 multi-world physics gate (prepared, not run)

This is a new, external preparation package at the request of the coordinator. It is not an acceptance result and has not been run. The existing candidate probe remains unchanged. The prepared driver derives from that probe but removes its fixed three-world restriction and registers explicit 1, 3, and 64 world cases.

The preregistration fixes 20 policy steps at 1 ms × 50 substeps per case, ordinary eager execution, deterministic mode unspecified, warning mask 3071, seeded controls split into 4 zero, 8 fixed, and 8 ramped policy steps; partial reset occurs just before the first ramp step. The 12-step zero/fixed settling window is the contact-gate window. Policy trajectory and diagnostic substep counts are separate. Acceptance thresholds are: per-world contact observed, penetration no deeper than 0.015 m, continuous raw mimic residual no greater than 0.001 rad in stored Newton reduced joint coordinates and actual MuJoCo Warp qpos, zero contact/constraint capacity overflow, finite state and effort, measured wheel/gimbal actuator clamp 2/1 Nm within 1e-5, and untouched-world byte identity through partial reset and its next substep/policy step. No contact is required immediately after the reset pose; reset continuation must remain finite and accept the next ramp control. Cross-world readback distinction is N/A at one world and required at 3/64 worlds.

The driver was prepared from probe_dynamics_v4b.py and mjw_backend_candidate_v4.py; it requests the same active native backend dependencies by absolute proto path. The input_snapshot/source directory contains byte copies of the active repository dependency files and the unmodified earlier candidate sources. manifest.json hashes the prepared driver, runner, preregistration, command template and source snapshot. Source files were captured before any run and are not evidence that a run passed.

The runner is a command template only. It has not started Python, CUDA, a probe, or created an attempt result. Root must authorize and schedule execution after the shared GPU is released.
