# 训练结果汇总

**整理日期：2026-10-28**。本报告汇总 `results/` 中的主要策略训练、配对评估与性能实验，并补充 Native V2 验收记录。本报告用于清理训练结果目录后仅保留汇总；标注“已删除”的原始路径只用于说明来源，清理后不再保留相应日志、模型、评估 JSON 与快照。

## 结论摘要

- 仿真训练与吞吐链路已有多项真实完成记录；部分局部开发集配对评估显示改善信号，但仍有安全权衡、样本少或评估范围窄的问题。
- 当前没有证据证明履带底盘已具备整田可靠导航、稳定避苗或实车能力。项目验收状态仍为 `capability_metrics_allowed=false`；吞吐、训练步数、checkpoint 有限和物理冒烟通过都不能替代策略能力评估。
- Native V2 的 1/3/64-world 物理前置门、同身份恢复与 strict-eval smoke 已通过。正式 300 轮 run 的最后书面状态（10 月 25 日）为运行中，尚无最终通过记录。10 月 28 日在当前工作树未找到该 trial 的运行目录或 Windows 侧训练进程；`Ubuntu-24.04-Arm64` 在 WSL 列表中为 `Stopped`，启动该发行版读取进程时因 `C:\pioneer\wsl-native\Ubuntu2404\ext4.vhdx` 返回 `ERROR_PATH_NOT_FOUND`，无法检查发行版内状态。因此当前正式 run 状态**无法从这份 checkout 核实**，不能据旧状态当作仍运行或已完成。

## 原生栈与物理验收

### Native V2 主线

- 冻结身份：Native V2 协议 SHA `83db5a6e…f92f87e`、task SHA `20901690…ecbc1b2`，Newton MuJoCo Warp V6；训练配方为 64 env × 32 steps × 300 iterations（目标 614,400 samples），LSTM-512 / PPO、1 ms × 50、普通 eager GPU。
- 1、3、64 worlds 的冻结物理门通过；同身份 checkpoint 续训 iteration 7 → 8（Adam 28 → 32）以及 64→1 strict-eval smoke 通过。这些证明验收输入和恢复/评估链路，不证明导航能力。
- 正式 run `native_v2_formal_v6_live_20261025_224005` 最后记录为 10 月 25 日启动后仍运行，尚待完整 300 轮、零异常/容量溢出、指标与 checkpoint 审计。当前工作树没有该正式 trial 目录；`Ubuntu-24.04-Arm64` 为停止状态，无法挂载其 WSL 虚拟磁盘读取内部进程；Windows 侧也未见对应训练进程。状态仍未知。避免在确认真实训练主机和输出目录前重复启动或终止该 run。
- 独立短训吞吐（64 env × 32 steps；每次 2 warmup + 5 measured iteration）不是正式训练成绩：

  | 组别 | rep01：iteration window / full-launch all samples | rep02：iteration window / full-launch all samples | 按总样本/总时间加权 |
  |---|---:|---:|---:|
  | warning-enabled | 112.036 / 84.178 | 89.540 / 78.313 | 99.533 / 81.139 samples/s |
  | quiet | 170.946 / 136.085 | 175.633 / 143.581 | 173.258 / 139.733 samples/s |

  四次 run 均成功退出，检查点张量有限；非有限环境/动作、capacity overflow 和 outer iteration limit 均为 0。line-search-limit 事件仍存在：按完整 7 轮统计，eager 为 77,102 / 76,988，quiet 为 76,971 / 76,974。warning-enabled 与 quiet 使用不同 source commit/manifest，吞吐差异不能归因于静音；计时是 host wall-clock，不是 CUDA kernel time。详细复现记录见 [MIGRATION_ACCEPTANCE.md](native/MIGRATION_ACCEPTANCE.md) 与 [PERF_SUMMARY.md](PERF_SUMMARY.md)。这些 native/acceptance 原始目录为历史来源（已删除）：`native/acceptance/20261025_mjw_training_repro/`、`20261025_mjw_eager_rep01/`、`20261025_mjw_eager_rep02/`、`20261025_mjw_quiet_rep01/`、`20261025_mjw_quiet_rep02/`。
- checkpoint/eval smoke：从 quiet rep02 的 iteration 7 checkpoint 恢复到 iteration 8，Adam step 28 → 32，wall 16.736 s，132 个 checkpoint tensor 均有限；未保存 RNG，因此不证明随机流或逐位连续。随后单 seed 87010、1 env、32 steps 的 strict-match eval 以 `time_limit` 结束，成功 0/1、末距 34.723 m。二者只证明 load/resume/eval 链路。历史来源（已删除）：`native/acceptance/20261025_mjw_quiet_resume/`、`native/acceptance/20261025_mjw_quiet_eval/`。

## 解读口径

1. 不跨不同物理后端、任务合同、成功判据、地形、传感器模式或样本规模合并成功率与吞吐。
2. “训练自然完成”“物理/数值门通过”“策略能力通过”是不同结论；只有第三项才能支持导航能力陈述。
3. 代理车体、flat-plane/解析传感器与实车、Isaac RTX 场景仍有域差；实车串口/CAN/HAL 联调和整田闭环验收未完成。
