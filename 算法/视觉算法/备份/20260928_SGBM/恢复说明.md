# 双目 SGBM 成果备份

备份日期：2026-09-28。此目录冻结当前成果，LightStereo 实验位于 `软件/LightStereo实验`。

- `project.zip`：完整 stereo 程序、说明、标定与诊断结果、70组无损原图，以及根目录启动器；不包含 Python 缓存。解压即可还原原有目录结构。
- `board-runtime.tar.gz`：板端正在使用的程序、标定、隔离依赖 vendor、systemd 服务单元。不是整机系统镜像，不含 Wi-Fi 密钥或系统网络配置。
- `manifest.json`：归档大小、SHA256、文件及照片组数。project.zip 已逐项CRC校验。

当前基线：360×640米制伪彩深度，SGBM左右一致性检查，自动/固定色标；观察约6帧/秒。最新标定为 软件/stereo/calibration/current/parameters.npz，基线96.2866 mm，几何验收通过，实物距离及建图精度尚未验证。

恢复到同一块板：先解压 project.zip，执行解压后的双目试验.cmd，会部署旧程序及当前标定并重启服务。只有板端依赖也损坏时，才需停止 rk-stereo.service 后将 board-runtime.tar.gz 上传并解压至 /，再执行 systemctl daemon-reload 和 systemctl restart rk-stereo.service。不需要改变热点配置。
