# LightStereo RK3588 交付版

固定使用 LightStereo FP16 NPU 模型，输入宽352×高640：校正、转正后两侧各裁4列，无输入补边。交付包含运行程序、网页、模型、当前双目标定、ARM64 Python依赖和隔离版RKNN运行库及验收样例。默认打开伪彩色深度页；拍照页保留双路预览和手动拍照。

## 部署

适用当前RK3588开发板：Debian 11 ARM64、Python 3.9、NPU驱动0.9.6，摄像头 `/dev/video33` 与 `/dev/video42`。包内自带NumPy/OpenCV/RKNN Lite2；GStreamer、PyGObject和相机/NPU驱动来自板上现有系统。部署会检查依赖，不自动安装系统软件或改网络配置。

Windows上把 `LightStereo-RK3588.zip` 与 `部署.cmd` 放在一起，USB连接开发板后双击 `部署.cmd`。需要电脑已有ADB，默认设备序号为当前板子的 `b1371e33e9f6e49e`；换板可运行 `部署.cmd 设备序号`。

部署脚本会先检查包和NPU，再启动LightStereo、停止旧SGBM服务并设置LightStereo开机启动。程序放在 `/opt/rk-lightstereo`；旧 `/opt/rk-stereo` 程序和照片保留。若目标目录已存在，脚本停止，不覆盖。新服务启动失败时尝试恢复原来正在运行的服务。

部署后电脑打开 `http://127.0.0.1:8877/`；手机连接开发板原有热点，打开 `http://10.42.0.1:8088/`。日常运行不需要电脑。算法目录下的 `视觉算法/软件/旧版SGBM启动.cmd` 会重新启动旧服务，使用本版本时请使用本交付包的入口。

手动部署：把ZIP解压到 `/opt/rk-lightstereo`，以root执行 `sh /opt/rk-lightstereo/install.sh`。这会切换在线服务。

## 板端常用命令

```sh
# 完整性与系统依赖检查
python3 -B /opt/rk-lightstereo/verify.py --system
# NPU正反向数值与保存照片全流程自检，不打开摄像头
sh /opt/rk-lightstereo/run.sh self-test --runs 10
# 服务管理及最近日志
systemctl status rk-lightstereo.service
systemctl restart rk-lightstereo.service
journalctl -u rk-lightstereo.service -n 50 --no-pager
```

## 版本与验证范围

当前相机标定ID为 `fc0ee7b44fe5`，原图3840×2160，求解基线约96.287mm。相机相对位置、焦距或分辨率改变后，需重新标定并生成对应裁剪投影参数，不能只替换一个NPZ。

模型来源 `https://github.com/zz990099/lightstereo_cpp`，固定提交 `1c192984f60e76c4628075888b053a508797229d`。由SceneFlow预训练模型调整空间尺寸，251个浮点权重张量未改变；转换工具为RKNN Toolkit2 2.3.2，板端运行库为2.3.2，隔离加载，不替换系统库。仅保留640×352这一种正式输入尺寸的ONNX和RKNN模型。

实验中5组照片平均有效覆盖47.60%。当前版本用两个独立NPU会话并行执行正反向推理（核心掩码1和2），同输入基准的双方向耗时中位数从417.5ms降至288.9ms，输出与串行逐像素一致。现场网页约2.3帧/秒（之前约1.8），输入尺寸和模型保持不变；帧率随采集、负载和温度变化。深度经过双路有效区域、1像素左右一致性及0.3–5m范围筛选。没有SGBM回退或填洞。

初版打包验证记录位于 `evidence/package-check.json`。并行更新的数值对比见 `evidence/parallel-npu.json`，上线观测见 `evidence/optimization-live.json`；本次已经更新板端服务，没有新增标定照片。当前场景的对齐复查发现约5像素竖直残差，仍需棋盘格复核；尚未修改标定或自动平移画面。相机同步仍为软件时间戳配对，实际距离精度未完成独立实测。

`manifest.json` 记录包内文件的SHA256。外部 `SHA256SUMS.txt` 用于检查ZIP与部署脚本。第三方依赖的原始dist-info/许可证随运行库保留；上游来源和版本记录在清单中。

## 恢复旧服务

```sh
systemctl disable --now rk-lightstereo.service
systemctl enable --now rk-stereo.service
```
