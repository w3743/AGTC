# AGTC 田间双目行为规划仿真

此目录包含开发机上的 MuJoCo 仿真、合成双目采集、三模型检查点和本地续训工作台。场景为 48 × 32 m 的麦田，包含规则田垄、杂草和实体岩块。

## 本地启动

两份仿真模型权重随此目录提供。Windows 工作台需要 Python 3.12、Node.js 和 Chrome 或 Edge。在本目录运行以下命令安装 Python 依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

双击 `本地训练\打开本地训练.cmd` 打开工作台。也可直接运行 `.\.venv\Scripts\python.exe -B offroad_server.py` 启动仿真。

| 地址 | 功能 |
| --- | --- |
| http://127.0.0.1:8922/ | 三维参考、二维通行地图、左右相机和建图操作 |
| http://127.0.0.1:8922/think | 实时神经网络和规划状态 |
| http://127.0.0.1:8924/ | 训练设备、回合指标和当前检查点试跑 |

## 建图与导航

- 在二维图双击可通行的位置设定目标。田垄以黄色显示，换通道时从地头绕行。岩石占据格禁止通行，相邻格通过软代价避让。
- 手动建图支持方向键、WASD 或屏幕遥控。半自动建图沿指定通道记录，到尽头停车。全自动优先探索可达通道，发现重复经过且没有明显新增观测时结束。
- 地图记忆存储二维栅格，三维测点用于参考。任务继续用实时双目和地形、局部神经元及 RNN 模型判断风险。车体受困时先尝试沿已走路径退出，失败后发布本地告警。

## 模型与续训

随附两份检查点仅包含续训入选权重。训练以仿真时间 30 Hz 渲染每眼 3840 × 2160 图像，再缩至 1024 × 576 做双目匹配。设备选择按 NPU、GPU、CPU 顺序运行前向、反向和更新探针。使用 NVIDIA GPU 续训时，安装适配当前驱动的 CUDA 版 PyTorch。 [PyTorch 安装说明](https://pytorch.org/get-started/locally/)

MuJoCo 底盘来自本仓库的仿真训练环境。局部神经元规则来自本仓库的 `局部神经元MNIST实验`。本目录的 Python 和 Node.js 程序用于离线开发机仿真与训练，RK3588 板端部署和实车验收另行进行。
