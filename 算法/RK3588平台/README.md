# RK3588 双目部署资料

当前板端 `rk-lightstereo.service` 使用 CPU SGBM 提供单一实时深度输出；两路 ISP 主采集节点直出640×360 NV12、约30 FPS/眼，持续4K编码已关闭，标注框、点云、独立远距/NPU预览已移除。传感器原生仍为4K模式，标定/手动拍摄可按需使用原始分辨率。当前版本、数值接口、真实fixture与回滚信息以[部署说明](../视觉算法/软件/数值深度接口候选/README.md)为准；[原始完整备份](../视觉算法/备份/RK3588_当前运行算法_20261021_011952/README_备份与恢复.md)仅作为早期恢复基线。
