# 全连接拓扑演化实验

全部模型从同一个 47 → 96 → 96 → 96 → 2 全连接 ReLU 网络起步。没有注意力头、记忆槽或专用读写模块。甲乙记录各占输入的一段，每段四条记录的顺序独立打乱。最终问题指定键及所问内容。训练与测试按两段记录的排列组合隔离，留出集每类 512 组。每组必须答对原题、翻转甲值、翻转乙值和翻转无关值。

## 连接怎样变化

学习组按权重绝对值断边，并按当前训练批次的损失梯度恢复原本关闭的边。断开与恢复时清零边权和对应的 AdamW 动量。随机组按同样的时间、每层密度和重连数随机断边与恢复。全连接组保持全部边。各组的训练批次、初始权重与更新次数相同。早断边版本先全连接训练 400 次，随后学习重连组的留出双证据成绩为 26.17%。延后版本的稠密期延长到 2,400 次，其他阶段长度保持不变。

## 结果

| 延后版本 | 活跃连接数 | 双证据联合正确率 |
| --- | ---: | ---: |
| 全连接 | 23,136 | 99.09% |
| 随机重连 | 6,942 | 6.45% |
| 学习重连 | 6,942 | 100% |
| 只按权重剪枝 | 6,942 | 100% |

学习重连组三个种子均为 100%。每个种子执行 35,166 次断边和 18,972 次重新启用，次数包括同一位置在不同时刻的变化。冻结最终连接掩码并重新初始化权重，在另一批留出布局上，学习掩码和随机掩码分别为 97.79% 和 37.83%。

在开发集选隐藏层之间的断边组合，再测留出集。学习组的甲敏感切法平均使甲、乙、双证据成绩分别降低 73.11、0.85、59.51 个百分点。乙敏感切法分别降低 0.78、98.70、76.69 个百分点。全连接组也出现选择性损失，分工可以在稠密阶段形成。只剪枝达到相同成绩，重连的独立必要性尚未得到支持。

本实验可改变相邻层之间的边，候选层数、神经元和运算固定。甲乙记录在输入中已有位置分组。当前以稠密算子实现连接掩码，活跃边数反映拓扑规模。
