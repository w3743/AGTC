# 多目标中断记忆世界

首版为低维、部分可观测事件流。每条事件流含多个独立任务上下文。模型看到切换、写入、操作和规则事件，以及最后的目标上下文和问题。模型接口没有特权状态、专家划分或模块标签。当前由外部生成轨迹，真实导航和控制留在后续环境。

## 三个独立因素

| 因素 | 当前审计范围 |
| --- | --- |
| 记忆间隔 | 64、256、1,024、2,048、8,192、12,000 步 |
| 中断频率 | 每 256 步 4、16、64 次，按实际事件计数 |
| 并存任务数 | 2、4、8 个 |

每个任务保存旧检查点、累积操作、最近状态和规则。旧检查点跨越整个间隔，最近状态在末尾以随机任务顺序更新。累积操作和规则事件的数量只由间隔决定，发生时归属于当前上下文。切换频率只统计中间保留区间。训练组合由一项或两项因素组成，测试组合增加到三项或四项。每个问题的四个选择标志都在训练中出现过，留出组合没有新符号。

每组改变一个相关写入，或改变一次决定后续操作归属的切换。无关任务的单处改动用于检验答案是否保持。用独立回放器核对所有标签。固定最近 32 或 256 步的条件下，若同组两题的可见输入完全相同而答案不同，则确定性模型不可能在该组全部答对。这个指标是题组级上界。

## 演化能力的后续证据

先让固定结构基线学会训练分布，再评价长延迟和留出组合。功能模块需要开发集选出的失活方案和独立留出复验。推理时模块激活、训练中拓扑变更、任务切换后的恢复速度分别记录。公开外部验证依次考虑 POPGym Arcade 的部分可观测对照、Memory Maze 9×9 的离线探针和 Continual World 的旧任务保留。
