# 长程记忆与处理评测

2026-11-04。当前全输入源记忆模型参与评测。每道题的状态从零开始，题与题之间保留模型权重。测试冻结权重；每个答案必须从已经输入的线索、干扰和查询中推断。

| 任务 | 输入 | 预测目标 |
| --- | --- | --- |
| 延迟复述 | `6 值` → 干扰 → `9` | 原来的值 |
| 按键查值 | 三组乱序的键值对，键为 `6/7/8` → 干扰 → `9 键` | 指定键关联的值 |
| 模 4 加减 | `6 A 7 B` → 干扰 → `9 运算符` | `0` 表示 `(A+B) mod 4`，`1` 表示 `(A−B) mod 4` |

答案均为0–3，干扰由4和5独立随机生成。训练长度为8、32、64、128步干扰，每个种子每任务480题。测试新增256步未见长度，每个任务每档64个平衡原题，外加64道配对题。配对只将正确答案所依赖的一个早期值加1取模，查询和干扰完全相同。训练输入与任何原题、配对题均不重复。三组种子使用同一套测试题，因此种子间范围反映初始化和训练样本变化。

所有模型看同一序列，在最终查询处收到一次监督，使用10类输出。普通RNN、GRU、LSTM及其余基线通过反向传播训练，全输入源模型保持原 RTRL 梯度、输入近端更新及保留率规则。统一使用 Adam 基础学习率0.015、梯度范数上限1。每种架构各使用一组配置，参数量相近。MLP只读最近32位，是有限窗口对照；TCN感受野512位；Transformer处理全部题目输入。算力、状态容量、上下文访问方式和超参数适配程度有差异。本实验的处理任务只覆盖四值模运算和给定查询形式。

可视化上排为原题准确率，下排为成对两题均正确的比例。均匀独立四类猜测的期望分别为25%和6.25%。报告提供同一对输入的可切换示例、各模型对正确答案的概率和完整成绩。`scores.csv` 给出按长度聚合的准确率、成对准确率、负对数似然、线索效应和参数量；`per_seed.csv` 给出每个种子的成绩。线索效应取正确概率随线索变化的有向移动量，正值代表平均朝正确方向移动。

## 实测成绩

本次完成63次独立训练，共核对40,320次冻结测试预测和105行聚合成绩。下表为256步干扰的准确率，每格合计192次原题预测，同一组64道题在三个训练种子上复用。

| 模型 | 参数数 | 延迟复述 | 按键查值 | 模 4 加减 |
| --- | ---: | ---: | ---: | ---: |
| 全输入源 RTRL | 1,481 | 25.5% | 25.5% | 28.1% |
| 普通 RNN | 1,489 | 25.0% | 25.0% | 25.0% |
| GRU | 1,514 | 100.0% | 28.1% | 23.4% |
| LSTM | 1,440 | 25.0% | 25.0% | 25.0% |
| MLP-32 | 1,334 | 26.6% | 25.0% | 25.0% |
| TCN-512 | 1,402 | 22.4% | 25.0% | 25.0% |
| Transformer | 1,546 | 25.0% | 25.0% | 25.0% |

GRU 的复述在全部长度和种子上达到100%，修改早期线索后的配对题也全部答对。TCN 在8–128步复述为67.2%–83.9%，到未见的256步降至22.4%。全输入源模型在256步的成对正确率依次为0%、0%、0.5%，没有显示可靠的长程记忆或处理能力。所有模型在按键查值和模 4 加减上的成对正确率最高仅4.2%。这些成绩适用于本次训练题数和每种架构的一组超参数配置。

## 复现

在本研究目录运行。训练需要 `requirements.txt` 中的 PyTorch，制图另需 Matplotlib。

```powershell
python .\experiments\long_memory_eval.py --output C:\pinoeer\AGTC\算法\rnn研究\runs\long_memory_new --workers 9
python .\experiments\long_memory_report.py C:\pinoeer\AGTC\算法\rnn研究\runs\long_memory_new
```

输出包含训练曲线、测试概率、冻结权重、源码快照和协议。报告脚本重算分数、核对不同模型和种子使用的同一测试题、检验符号规则与配对变化，并生成文件散列。每个全输入源模型运行中，每档各抽查一个原题和配对题，对照批量评估路径与项目原始逐位前向路径。

任务借鉴了受控长延迟的实验思路，网络实现和成绩来自本项目。参考 [LSTM 长时间间隔实验](https://papers.neurips.cc/paper_files/paper/1996/hash/a4d2f0d23dcc84ce983ff9157f8b7f88-Abstract.html) 和 [TCN 序列建模比较](https://arxiv.org/abs/1803.01271)。
