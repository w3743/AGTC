# 标准模型公平对照

本轮只训练六种标准模型。每种都运行约 1,500 参数与约 10 万参数两档，大档接近 1,024 神经元稀疏原型的 99,349 参数。小型 Transformer 使用两层，大型使用三层。MLP 的窗口保持 32 位，TCN 使用 512 位感受野，两个配置用于区分有限上下文与实际长程学习。

每个模型、参数档、任务和训练长度条件都在相同验证题上筛选 0.001、0.003、0.01，筛选种子独立于正式三个种子。以验证集成对正确率排序，同分时比较负对数似然，再比较学习率。选定后用相同的 AdamW、每批 16 题和三个种子训练，报告同一条轨迹的 480 题和 2,000 题检查点。每个检查点的训练题数与更新数跨模型一致，架构计算开销有差异。

外推组训练干扰长度为 0、8、32、64、128，见过 256 步的组把 128 步训练题替换为 256 步训练题。两组共用相同测试集并对比 0、8、32、64、128、256 步。验证和测试使用各自独立题目，除 0 步诊断外，训练题、验证题和测试题及配对不重叠。0 步输入空间有限，用于诊断是否学到任务规则，允许重复。外推组的调参验证不包含 256 步。

GRU 是本轮长程复述的稳定基线。TCN 在大档的 256 步复述从 480 题时的 5.2% 成对正确率升到 2,000 题时的 100%，而外推条件的成对正确率为零。它的查值和 GRU 都有改善，但仍不稳定。小型 Transformer 在训练覆盖 256 步时达到 100% 复述单题和成对正确率，扩大参数规模未带来一致收益。模 4 加减的 0 步成对正确率仍很低，说明当前训练条件下，运算规则本身也尚未学稳。

本轮使用新训练分布、新测试题和验证选参。旧 480 题结果保留为历史低预算实验；当前稀疏模型没有在新协议下训练，因此这两批成绩分开解读。
