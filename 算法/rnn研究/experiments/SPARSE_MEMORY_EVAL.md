# 1024 神经元稀疏记忆原型

原型把 1024 个神经元分成 32 块。每块从固定的四个 8 单元子块接收循环输入，每个神经元恰有 32 条入边。循环权重和动态连接痕迹各存 32,768 个值，活动摘要沿同一稀疏拓扑读取。每个神经元及每路外部输入仍保留一个独立摘要，共 1,034 路。模型有 99,349 个可训练参数，不启用活动保留。

每题的活动、连接痕迹和摘要从零开始。完整输入从线索到查询连续进入模型，计算图贯穿整题，查询处计算一次交叉熵后反向传播。与原评测使用相同的 480 道训练题、三组种子和冻结测试题。为提高 CPU 吞吐量，原型按序列长度分组，每批 8 题，共 60 次 Adam 更新；20 神经元版和六个标准模型的既有成绩每题更新一次。各模型参数量和优化方式有差异，本实验比较实际配置的表现。

| 任务 | 8 步单题 / 成对 | 32 步 | 64 步 | 128 步 | 256 步 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 延迟复述 | 45.31% / 22.40% | 22.92% / 0.52% | 33.85% / 9.90% | 23.44% / 0.00% | 24.48% / 0.00% |
| 按键查值 | 25.52% / 0.52% | 24.48% / 0.00% | 29.17% / 0.00% | 24.48% / 0.00% | 26.04% / 0.00% |
| 模 4 加减 | 25.00% / 0.00% | 25.00% / 0.00% | 23.96% / 0.00% | 23.96% / 0.00% | 24.48% / 0.00% |

256 步未参与训练。原型的三项结果均接近四类均匀猜测的 25%，三项配对均未答对。20 神经元版同期为 25.52%、25.52%、28.12%，成对为 0%、0%、0.52%。GRU 在同样的 256 步复述任务中单题和成对均为 100%。本轮新增 9 次训练，共重算和核对 72 次训练记录中的 46,080 次测试预测。63 份参考成绩及其权重文件与旧核验记录的散列一致。

单线程 CPU，各模型和模式分别在新进程中测量。推理使用 256 步干扰复述题，训练使用 128 步干扰复述题，包含前向、梯度和参数更新。表中为预热后中位耗时除以输入位数，批量为 1。峰值为进程驻留内存高水位，含 Python、PyTorch 和模型。稀疏原型另测实际训练批量 8，耗时 0.9174 毫秒/输入位，峰值 913.3 MiB。20 神经元推理使用评测中的冻结前向路径。

## 每题更新一次的复测

将批量从 8 改为 1，按原有批次和批内顺序逐题展开。模型、初始化种子、训练题、测试题、基础学习率与完整 BPTT 保持一致。三项任务各跑三个种子，每次使用 480 道训练题并完成 480 次更新。比较前核对了模型与题目生成源码散列、每次运行的更新数、所有测试题与配对标签，以及复用的 63 份参考预测与权重。

| 256 步干扰 | 单题准确率：60 次 → 480 次 | 成对正确率：60 次 → 480 次 |
| --- | ---: | ---: |
| 延迟复述 | 24.48% → 25.52% | 0.00% → 3.65% |
| 按键查值 | 26.04% → 24.48% | 0.00% → 1.56% |
| 模 4 加减 | 24.48% → 20.31% | 0.00% → 1.04% |

本轮未见稳定的长程成绩提升。256 步复述的 7 对正确样本集中在种子 20261027，另外两个种子对 64 道原题全部预测为数字 2。8 步复述的单题准确率从 45.31% 降至 25.00%，成对正确率从 22.40% 降至 0%。批量从 8 变为 1 同时改变梯度平均方式，因此这组结果描述逐题更新配置的实际变化。

## 每题更新，学习率 0.003

保持每题一次更新和原序列顺序，唯一训练配置变化是 Adam 学习率 0.015 → 0.003。三个任务、三个种子各训练 480 题。九组首题更新前的交叉熵与 0.015 版逐值相同。饱和探针在每档选固定的前 16 对输入，在查询处统计 `|h| > 0.95` 的神经元比例。

| 任务 | 末 80 题平均训练交叉熵 | 256 步查询处饱和比例 | 256 步单题 | 256 步成对 |
| --- | ---: | ---: | ---: | ---: |
| 延迟复述 | 13.03 → 1.82 | 64.79% → 0.41% | 25.52% → 10.94% | 3.65% → 0.00% |
| 按键查值 | 9.80 → 1.79 | 55.70% → 0.02% | 24.48% → 27.60% | 1.56% → 5.73% |
| 模 4 加减 | 10.84 → 1.66 | 55.56% → 0.03% | 20.31% → 25.52% | 1.04% → 0.00% |

低学习率显著降低损失和饱和。复述在 8、32、64 步的单题准确率达到 73.96%、50.00%、38.54%，成对达到 55.73%、25.00%、14.06%。128 步成对提高到 9.38%，原题为 26.04%，存在明显种子差异。256 步复述三个种子分别答对 4/64、1/64、16/64 道原题，配对均为零。查值在 256 步略升，模 4 加减在各档成对均为零。本次改善集中于较短、训练见过的复述长度。
