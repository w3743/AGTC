# 整车电力硬件公共资料

本仓库仅维护可复用的元器件信息、器件来源资料和封装库数据，不包含单板原理图、位号绑定、板级集成记录或原理图生成工具。

## 目录

- [`库/元器件目录.json`](库/元器件目录.json) 与 [`库/元器件目录.csv`](库/元器件目录.csv)：型号、制造商、供应商目录编号、目录封装和来源链接。表内不保留设计位号。
- [`库/型号封装关联.json`](库/型号封装关联.json)：按精确型号整理的封装候选、供应商标识、针脚映射候选及来源。多个候选并存时不指定优先项；只有归档成员与来源记录 SHA-256 完全一致时才标记为当前库文件。
- [`库/可导入封装库.zip`](库/可导入封装库.zip)：350 个标准封装 JSON 和随包导入说明。
- [`库/嘉立创库数据.zip`](库/嘉立创库数据.zip)：供应商目录原始元件数据。
- [`库/封装补充依据.json`](库/封装补充依据.json)：60 条精确型号封装定义、201 条型号级厂商几何记录（其中53个型号重叠）、引脚编号/几何别名，以及2项明确标记为未放行的共享型号候选。保留厂商来源和可用的来源哈希。
- [`库/封装焊盘尺寸.csv`](库/封装焊盘尺寸.csv)：封装焊盘的几何尺寸表；[`库/封装核对图.png`](库/封装核对图.png)是静态几何图示。
- [`数据手册/`](数据手册/)：器件数据手册、厂商封装图和相关机械资料；[`数据手册/索引.json`](数据手册/索引.json)按型号和文件列出制造商、来源链接、SHA-256、页数和版本信息，不含本机缓存路径或设计位号。另有4项旧存档文件仅记录归档字节 SHA-256，原资料未提供上游 URL。

## 使用边界

封装映射是来源资料中的候选关系，不等于某块电路板的最终选型。存在多个封装候选时，需结合目标器件精确型号和厂商资料自行审查。归档文件的哈希匹配只说明文件内容与归档成员一致，不代表针脚功能、电气适用性、目标板设计、PCB制造或实物装配已验证。共享型号候选仍保持未放行状态。

本仓库没有统一的 `LICENSE` 文件。请依据各器件厂商和供应商的来源页面及发布条款使用对应资料；来源链接与已有哈希应一并保留和核对。
