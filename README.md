# 整车电力设计：硬件公共资源

本仓库收录整车电力设计中可复用的公共硬件资料、器件库和工程工具。

## 内容

- `库/`：公共器件与封装资料、库数据和核对文件。
- `数据手册/`：器件数据手册、机械图和相关原厂资料。
- `工具/`：共享的 EasyEDA Pro 数据处理、原理图集成与核验工具。

发布内容保留源目录中的当前文件和带日期的封装绑定版本；本地项目历史缓存与 Python 编译缓存未纳入。

## 资源索引

- [器件库与封装资料](库/)：包含器件匹配表、封装绑定与补充依据、可导入封装库和核对资料。
- [数据手册与原厂资料](数据手册/)：按器件型号归档；[索引.json](数据手册/索引.json)记录型号、关联位号、来源、文件校验值和覆盖说明。
- [工具目录](工具/)：按项目工作区消费的脚本，不是独立安装的通用 Python 包。

索引中的 `refs` 用来关联型号与设计资料。若一个位号关联多个物料或包含装配附件，不能只凭索引推断 BOM 器件身份；请对照对应版本的原始 BOM/装配资料。索引的覆盖说明、数据源和文件哈希应一并核对。

## 工具用途

| 脚本 | 用途与边界 |
| --- | --- |
| [原理图交付.py](工具/原理图交付.py) | 构建/规范化 EasyEDA Pro 工程并进行本机核验。`--客户端`可指定客户端可执行文件；默认值是 `D:/lceda-pro/lceda-pro.exe`。 |
| [核验交换原理图.py](工具/核验交换原理图.py) | 被上层流程调用的交换记录与网表核验模块；调用方须传入同版源、器件清单和核验约束。 |
| [生成可编辑原理图.py](工具/生成可编辑原理图.py) | 从已审定的连接表生成候选原理图；`--输出目录`和`--核验目录`可指定输出位置。转换器、Node 运行时路径目前写在脚本中。 |
| [获取嘉立创元件.py](工具/获取嘉立创元件.py) | 查询嘉立创公开元件目录并更新匹配表；需要网络和 `requests`。脚本说明其不下单、不使用账号凭据，也不替换元件。 |
| [补齐封装.py](工具/补齐封装.py) | 离线生成标准版封装 JSON、封装导出包和逐位号绑定；会写入共享库数据。脚本说明不调用 EDA，也不执行 ERC/DRC 或制造验收。 |
| [集成E4功能区.py](工具/集成E4功能区.py) | 由原理图流程导入的分区适配器；消费既有器件清单，不独立读取或修改电气源。 |
| [集成板级原理图.py](工具/集成板级原理图.py) | 面向脚本内列出的板型和冻结输入执行库增量、工程生成及同版核验；它依赖对应项目源与本机客户端版本，不是通用板级导入器。 |

## 本地目录与运行要求

这些脚本按既有项目树解析输入和输出路径。多数工具以 `Path(__file__).resolve().parents[2]` 定位工作区，并在工作区下查找 `公共/库` 与 `FOC驱动与储能`；因此仓库根目录应位于该工作区的 `公共/`，旁边需要存在对应消费项目。示意：

```text
<工作区>/
├─ 公共/                 # 本仓库
│  ├─ 工具/
│  ├─ 库/
│  └─ 数据手册/
└─ FOC驱动与储能/        # 消费项目；其文档、工具、导出和核验目录由各脚本使用
```

此示意不覆盖所有板型：`集成板级原理图.py`另有板型配置、源文件哈希和路径规则。仅克隆到任意目录并不能让这些路径自动迁移；运行前应检查脚本顶部的路径常量及板型配置，并确认目标消费项目就是预期版本。

脚本使用 Python 标准库；`获取嘉立创元件.py`和`集成板级原理图.py`还导入第三方 `requests`。仓库目前没有统一的依赖清单。需要 EasyEDA Pro 的流程还依赖本机 Windows 客户端和随客户端安装的内部转换器文件；`生成可编辑原理图.py`另外查找用户目录下的 Node 运行时。当前只有`原理图交付.py`提供`--客户端`路径覆盖，不能假定其他工具可通过同一参数迁移安装路径。板级集成器还要求启动时未设置 `ELECTRON_RUN_AS_NODE`。

`python -m compileall -q 公共/工具`只检查 Python 语法；它不运行 EasyEDA 转换、工程回读、ERC/DRC 或制造核验。实际检查结果应按工具生成的报告和对应版本的工程源分别确认。
