# 电力硬件共用元件库

集中维护当前采用器件的准确型号、原生器件/符号/封装资产，以及相关厂商资料和封装候选。板级工程与位号在本地电力项目中维护。本仓库不提供整板原理图或PCB。

## 当前入口

- [当前型号与原生资产](库/当前型号与原生资产.json)：197个按制造商与完整MPN保守区分的器件身份，引用423份原生资产；另列原生BOM之外的现行采购型号及原始候选状态。
- `库/原生片段/`：原生器件、符号与封装内容，文件名为内容SHA256。JSONL片段用于精确追溯，不能直接当作独立可导入库包。
- `库/元器件目录.json`、`库/型号封装关联.json`及`数据手册/索引.json`：旧资料按现行型号筛选后的补充证据；与当前原生资产的状态分开。
- `库/可导入封装库.zip`、`库/嘉立创库数据.zip`：保留被补充索引明确引用的成员及其依赖。成员内容保持原字节，引用记录保留原SHA256。

## 复用规则

满足各板电气、封装及机械要求后优先统一精确型号；新差异先登记候选，核对通过再替换。相同封装名、相同数值或相近型号不能作为等效证明。共用候选优先考虑国产，同时接受经核对的低价方案，比较到手单价、MOQ、供货和验证成本。未核实的厂家属性或价格明确标待核实/待询价。

实际采用MPN与CAD载体MPN分别记录；`target_differs_from_carrier`为真时，载体符号、焊盘或参数不得直接视为目标器件已验证。同一MPN若制造商字段不同或缺失，保守保留独立身份。不同UUID或不同内容的资产不按名字合并。

数据手册、供应商原始数据和封装候选用于查证。其存在不表示器件选型、电气功能、机械装配或实物验收通过；厂商资料的权利和适用条件归原来源。本次筛选未取得新的价格或国产来源证明。

## 维护

本地入口为电力项目的`元件封装库/README.md`。从已保存原生工程与现行BOM更新索引，校验源SHA256和引用覆盖后导出公共资产，再按型号引用清理本仓库。发布前检查Git差异及依赖闭合；没有现行引用的旧资料从当前分支移除，可从Git历史恢复。

历史版本中的封装图和模型集合不代表本分支当前采用状态；当前以准确型号索引、资产内容与保留的来源证据为准。
