# 输入记忆来源探索实验（2026-11-04）

在连续状态 RTRL 中比较无输入记忆、仅外部数字记忆与外部数字加神经元活动记忆。后两组均使用可学习的逐输入源保留率、零初始化的记忆读出权重；三组20个神经元、配对初始化、相同序列和种子，先预测计分，再学习并推进状态。每条600步、599次更新；3个种子为2、20261027、20261028。五项任务共45次运行、27,000次预测。这是探索性实验，任务选择针对先前结果，三个种子不足以推断普遍性。

| 任务 | 无输入记忆 | 仅外部数字 | 外部数字和神经元活动 |
| --- | ---: | ---: | ---: |
| 二进制三连 | 87.11% | 88.00% | 70.67% |
| 二进制周期16 | 43.94% | 40.28% | 41.72% |
| 十进制三连 | 40.72% | 69.00% | 34.56% |
| 十进制锯齿 | 70.11% | 89.78% | 80.56% |
| 十进制规则切换 | 64.72% | 68.06% | 69.94% |

每格为三个种子各600次预测的累计准确率。十进制三连中仅外部数字方案的三个种子分别为68.67%、72.00%、66.33%；其末100步合计准确率98.33%，基线为69.67%。周期16三个方案都未稳定学会；切换任务的仅外部数字方案三个种子差异较大（79.50%、71.67%、53.00%）。本轮支持进一步研究输入来源，但不能将变化单独归因于移除神经元活动记忆，因为同时改变了参数数和灵敏度规模，也没有相同计算预算或超参数搜索。

| 方案 | 参数数 | 灵敏度元素数 | 稳态每步算术代理 |
| --- | ---: | ---: | ---: |
| 无输入记忆 | 851 | 269,220 | 3,177,051 |
| 仅外部数字 | 1,061 | 365,930 | 4,580,875 |
| 全输入源 | 1,481 | 571,950 | 7,930,295 |

稳态代理不等于硬件 FLOPs 或耗时；仅外部数字组约为基线的1.44倍、全输入源组约为2.50倍。各组学习率与更新次数相同，不能称作等计算量比较。
