# 回到 0–9 猜下一位数字的六任务实验

2026-10-28，分支 `codex/retention-decay-ablation`。按用户要求，将上一轮二进制任务换回最早的0–9数字预测；规律由研究侧预先设计，不向模型提供任务标签、规则、切换时刻或未来数字。七种模型和尺寸完全沿用上一轮同计算预算对照。

## 六种数字流

每种600位，全部覆盖0–9，所有模型及模型种子在同一任务上接收同一条冻结序列。

| 任务 | 规则 | 主要考察 |
| --- | --- | --- |
| 顺序循环 | `0123456789`循环 | 学习直接后继关系 |
| 三连 | `000111222…999`循环 | 区分同一数字的重复次数 |
| 往返 | `012345678987654321`循环 | 根据上下文区分当前方向 |
| 前两位求和取个位 | 初值1、2；后续为前两位之和模10 | 学习含多位上下文的固定递推序列 |
| 中途换规律 | 1–200位顺序，201–400位倒序，401–600位按`0369258147`循环 | 对规则变化的适应 |
| 随机对照 | private Python Random seed=891732849，均匀抽取0–9 | 检查随机输入上的表现与置信度 |

切换边界不额外重置权重、优化器、历史窗口；仍然每次按最新最多32位从零重放。随机参考命中率的期望为10%，不是每段样本应精确达到的门槛。三个模型种子共用同一条600位随机数据，不能把汇总1800条当成1800个独立随机输入样本。递推只测初值1、2的一条序列，高分可能来自记住该序列，不能证明对新初值的加法泛化。

## 固定协议与计算预算

7模型×6任务×3模型种子，共126次独立训练、75600次预测。模型种子为2/20261027/20261028。每步先预测、冻结概率并评分，再读入正确答案训练。输出10类，冷启动均匀概率取最小argmax=0纳入成绩。每次600位后1797次优化器更新。

模型尺寸沿用上轮：当前PlasticRNN20神经元/642参数、RNN31隐藏/1653参数、GRU17隐藏/1659参数、LSTM15隐藏/1780参数、窗口MLP7/14隐藏/2509参数、时序卷积11/11/11/12通道/1781参数、单头Transformer d9/FFN36/1288参数。所有使用最多32位历史、每键3次Adam更新、lr0.015、普通参数WD1e-4、clip norm1；当前模型保留input prox0.02、20个遗忘参数免WD，标准基线没有该特定输入收缩。不是单因素架构消融，也没有逐模型调参。

先核对模型实现相关8个源码与上轮逐文件SHA256一致，再用7模型×6条十进制序列执行42组计数profile，预测及三次训练的运算预算与上轮完全一致。完整600次输入的软件标量运算预算最大偏差仍为4.8623%，全部在±5%内。这个proxy包含前向、反向、clip和Adam，矩阵MAC计2，基本非线性按每元素1，复合算子按文档公式；不等于硬件精确FLOPs。CPU延迟文件只是复制上轮相同实现的串行微基准，本轮未重测。
