## 实现

`streaming_rtrl.py` 提供 `StreamingRTRL`：每次只接收一位数字，常驻神经元活动 `h[20]` 和快速连接痕迹 `F[20,20]`；二者只在创建实验时初始化，之后不按32位窗口清空或重放。原有20个接收神经元各自的保留参数、独立线性输出层和851个参数保持不变。

先用已封存预测对当前答案评分；再用当前答案做一次参数更新；最后把这个数字作为新输入推进一次状态，生成下一轮预测。600个数字推进600次状态、更新599次参数。模型没有历史数字列表，实验日志不参与模型输入。

```python
from streaming_rtrl import StreamingRTRL

model = StreamingRTRL(seed=2, credit="rtrl")
for digit in incoming_digits:
    probabilities_for_this_digit = model.predict()  # 在暴露答案前封存/评分
    statistics = model.learn_target(digit)           # 首位返回 None
    model.advance(digit)                            # 每位唯一一次状态推进
    probabilities_for_next_digit = model.predict()
```

也可调用 `model.observe(digit)` 完成学习与状态推进，返回下一位概率；评分应使用上次封存的预测。`state_payload` / `load_state_payload` 保存/载入权重、优化器、动态状态、灵敏度和计数。

活动及连接痕迹公式沿用旧模型。在线学习额外携带 `Eh[20,641]`、`EF[20,20,641]`，分别递推核心参数对当前活动和连接痕迹的影响。核心参数641个；输出层210个参数直接求梯度，无需历史灵敏度。两组灵敏度共269,220个float32、1,076,880字节，约1.03 MiB；另有小型固定缓存、模型和Adam状态。记录大小不随输入总长度增长。灵敏度是学习辅助记录，不是新增神经元，也不作为输出层输入。

结构化递推利用矩阵乘法、外积和稀疏参数索引，未建立420×420的通用稠密状态Jacobian。固定参数时，梯度与完整序列反向传播数值一致；在线每步改变参数时，沿用常规RTRL状态和灵敏度，不对整个Adam优化历史求导。灵敏度没有32步截断，也没有额外的裁剪或人为衰减；参数任务梯度仍全局裁剪至1。

学习率0.015，Adam普通参数WD=1e-4，20个保留参数WD=0；每次更新后输入权重软阈值收缩 `lr*0.02`。本轮只使用最初三个二进制周期任务，保留10输入/10类输出接口。空状态初始概率十类均匀、argmax固定0；有一个已观察输入后使用网络实际概率。后者与旧重放模型“尚未训练时持续均匀”的冷启动策略也有区别。

## 对照设计

三项固定任务 `01`、`000111`、`0000100110101111`，每项600位，种子 `[2,20261027,20261028]`。新增3变体×3任务×3种子=27次运行、16,200次预测。

1. **streaming_rtrl20**：连续数值状态与完整核心灵敏度递推。
2. **streaming_one_step20**：数值状态仍持续，但切断跨时刻灵敏度；保留参数没有任务梯度。它沿用同一状态容器，EF恒零，实际活动的灵敏度只有12,820个元素；这是机制控制，非最小内存实现。
3. **replay_lastpair20**：每次从零重放最近最多32个已观察数字，只用最后一个预测对新答案计算一次损失；同样599次更新，用来控制每次训练目标和更新次数。
