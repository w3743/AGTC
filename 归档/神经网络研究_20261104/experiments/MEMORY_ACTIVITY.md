# 全输入源记忆与活动保留组合实验

> 历史记录：该组合机制已从当前输入记忆模型移除。下述结构、成绩和测试描述对应本次运行的源码快照，并非当前模型的使用说明。

2026-11-04，在原全输入源、可学习输入保留率的 RTRL 上加入活动保留。数字输入（10路）和上一时刻神经元活动（20路）各保留一份摘要。每一步先使用旧记忆和旧活动计算候选，再混合旧活动和候选，最后以旧活动写入记忆：

```text
candidate = tanh(Win*x + (R + eta*F_prev)*h_prev + V*m_prev + b)
h_new = a*h_prev + (1-a)*candidate
m_new = rho*m_prev + (1-rho)*concat(x, h_prev)
```

连接痕迹仍按原公式更新，使用 `h_new` 和 `h_prev`。关闭活动保留相当于直接采用 candidate。固定版所有 `a=0.5`；可学习版每个神经元一个 `a=sigmoid(logit)`，初始化0.5。输入保留率 `rho` 和连接痕迹保留率、可学习活动保留率的 weight decay 均为0；其他训练规则沿用原实验。RTRL 对活动、连接痕迹、输入记忆三者递推灵敏度。固定参数时与完整序列自动微分比较；在线训练时不对优化器历史求导。

## 配对对照

三组均从头训练：全输入记忆、全输入记忆＋固定活动保留、全输入记忆＋可学习活动保留。20神经元，九个既有任务，种子2、20261027、20261028；每组每任务三次，每次600个数字，先评分再学习并推进状态，599次更新。共81次运行、48,600次预测。每格是三个种子累计准确率（1,800次预测）；末100和平均 NLL 保存在 `aggregate.json`。

| 任务 | 不加活动保留 | 固定0.5 | 可学习 |
| --- | ---: | ---: | ---: |
| 二进制交替 | 99.56% | 89.17% | 92.22% |
| 二进制三连 | 70.67% | 40.39% | 38.28% |
| 二进制周期16 | 41.72% | 41.28% | 41.22% |
| 十进制循环 | 91.50% | 61.00% | 88.22% |
| 十进制三连 | 34.56% | 50.67% | 42.28% |
| 十进制锯齿 | 80.56% | 79.56% | 78.78% |
| 十进制 Fibonacci mod 10 | 14.83% | 24.06% | 26.56% |
| 十进制规则切换 | 69.94% | 34.83% | 54.94% |
| 十进制独立随机 | 10.39% | 8.89% | 9.67% |

两个活动保留版本在十进制三连、Fibonacci 任务的累计准确率高于对照，但在二进制三连、十进制规则切换等任务明显下降。Fibonacci 即使提高到26.56%，仍不能称已学会；随机任务的差异不能证明可预测随机输入。二进制三连中两个活动保留版本的末100均为49.67%，基线为100%。每任务仅三个种子，且没有进行独立超参数搜索，不宜推广为一般结论。

| 方案 | 参数数 | 灵敏度元素数 | 稳态每步算术代理 |
| --- | ---: | ---: | ---: |
| 不加活动保留 | 1,481 | 571,950 | 7,930,334 |
| 固定0.5 | 1,481 | 571,950 | 8,006,694 |

代理是脚本计数的算术操作，非硬件 FLOPs 或实际延迟；三组相同输入和更新数，但计算预算并非完全相同。可学习活动保留在27次运行的最终 540 个系数范围为0.0333–0.7890，均值0.3984；其数值本身不能证明有效记忆更长。
