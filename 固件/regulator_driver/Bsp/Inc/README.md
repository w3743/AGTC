# 板级支持包头文件（Bsp/Inc）

板级支持包头文件；bsp_board.h 集中定义板卡引脚和 ADC 通道。

## 文件

- [bsp_adc.h](bsp_adc.h)：模数转换采样接口声明。
- [bsp_board.h](bsp_board.h)：板卡引脚及 ADC 通道定义。
- [bsp_bridge.h](bsp_bridge.h)：双向半桥接口声明。
- [bsp_callback.h](bsp_callback.h)：硬件回调处理接口声明。
- [bsp_can.h](bsp_can.h)：CAN 通信接口声明。
- [bsp_dump.h](bsp_dump.h)：泄放控制接口声明。
- [bsp_gpio.h](bsp_gpio.h)：通用输入输出接口声明。
