# 板级支持包（Bsp）

板级支持包，负责板卡引脚、外设驱动和初始化。

## 子目录

- [板级支持包头文件（Inc/）](Inc/README.md)：板级支持包头文件；bsp_board.h 集中定义板卡引脚和 ADC 通道。
- [板级驱动源代码（Src/）](Src/README.md)：板级外设驱动实现，按外设或功能分目录。

## 文件

- [bsp.c](bsp.c)：板级初始化入口。
- [bsp.h](bsp.h)：板级支持包公共接口。
