# 数据层源代码（DataLayer/Src）

数据层模块的实现。

## 文件

- [dl.c](dl.c)：数据层初始化与更新。
- [dl_bus.c](dl_bus.c)：母线及超容电压换算。
- [dl_can.c](dl_can.c)：CAN 数据处理。
- [dl_cell.c](dl_cell.c)：单体电压采样换算。
- [dl_power.c](dl_power.c)：电流和泄放功率估算。
- [dl_temp.c](dl_temp.c)：温度换算。
