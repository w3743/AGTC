# 数据层头文件（DataLayer/Inc）

数据层模块的接口声明。

## 文件

- [dl_bus.h](dl_bus.h)：母线及超容电压换算接口声明。
- [dl_can.h](dl_can.h)：CAN 数据处理接口声明。
- [dl_cell.h](dl_cell.h)：单体电压采样换算接口声明。
- [dl_power.h](dl_power.h)：电流和泄放功率估算接口声明。
- [dl_temp.h](dl_temp.h)：温度换算接口声明。
