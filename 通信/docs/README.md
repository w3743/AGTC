# 通信文档

本目录按用途组织 SLE 测距链路的设计资料、官方基线与硬件验收记录，以及算法和校准研究。

| 子目录 | 内容 |
|---|---|
| [`design/`](design/README.md) | 链路设计和从官方 sample 重构的说明。 |
| [`range_link/`](range_link/README.md) | 使用/校准说明、官方测距基线和硬件实测日志。 |
| [`research/`](research/README.md) | 官方算法行为、校准参数和 SLE 测距/定位资料调研。 |

固件二进制快照及其构建标识由上级 [`README.md`](../README.md) 说明；本目录的设计与研究文档用于解释工程决策和证据来源。
